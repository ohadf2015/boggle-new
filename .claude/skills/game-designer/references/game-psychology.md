# Game Psychology Reference

Understanding player motivation, behavior, and engagement psychology.

## The Hook Model (Nir Eyal)

### Trigger → Action → Variable Reward → Investment

**1. Trigger** (What brings players back)
- External: Notifications, emails, social mentions
- Internal: Boredom, curiosity, habit

**2. Action** (What players do)
- Must be simpler than motivation level
- Reduce friction to start
- Clear immediate goal

**3. Variable Reward** (Why players stay)
- Rewards of the Tribe: Social validation
- Rewards of the Hunt: Resource acquisition
- Rewards of the Self: Personal achievement

**4. Investment** (What keeps them coming back)
- Time invested (progress, stats)
- Data stored (history, preferences)
- Social connections (friends, reputation)
- Skill development (learning curve)

### LexiClash Hook Analysis

| Stage | Current | Enhancement |
|-------|---------|-------------|
| Trigger | Daily notification | Friend activity alerts |
| Action | Start game (1 tap) | Already optimized |
| Variable Reward | Scores, achievements | Add rarer discoveries |
| Investment | Streaks, levels | Add friend network |

## Flow State (Mihaly Csikszentmihalyi)

### Conditions for Flow
1. Clear goals
2. Immediate feedback
3. Balance of challenge and skill

### The Flow Channel
```
        ANXIETY
           ↑
Challenge  |    FLOW
   High    |   /
           |  /
           | /
   Low     |/______ BOREDOM
           ←------------------→
           Low              High
                 Skill
```

### Achieving Flow in LexiClash

**Clear goals**:
- Find words (immediate)
- Build combo (short-term)
- Beat score (session)
- Climb ranks (long-term)

**Immediate feedback**:
- Word validation instant
- Combo counter visible
- Score updates live
- Achievement pop-ups

**Challenge/skill balance**:
- Difficulty settings (5x5 to 9x9)
- Bot difficulty levels
- Ranked matchmaking
- Self-paced practice mode

### Flow Disruptors to Avoid
- Long load times
- Unclear feedback
- Unfair difficulty spikes
- Interrupting notifications
- Connection issues

## Self-Determination Theory

### Three Core Needs

**1. Autonomy** (Player choice)
- Multiple game modes
- Custom settings
- Play when wanted
- Choose difficulty

**2. Competence** (Mastery feeling)
- Clear skill progression
- Achievable challenges
- Learning curve
- Visible improvement

**3. Relatedness** (Social connection)
- Multiplayer modes
- Leaderboards
- Sharing features
- Friend systems

**Priority**: Improve Relatedness (friend system, challenges)

## Intrinsic vs Extrinsic Motivation

### Intrinsic Motivators (Sustainable)
- Enjoyment of word-finding
- Mastery of techniques
- Social connection
- Creative expression

### Extrinsic Motivators (Boost engagement)
- Achievements
- Leaderboard positions
- XP and levels
- Cosmetic rewards

### Balance Guidelines
- Extrinsic should enhance, not replace intrinsic
- Avoid over-justification effect
- Don't reward things players enjoy naturally
- Use extrinsic for onboarding, intrinsic for retention

## Loss Aversion

### Principle
Losses feel ~2x stronger than equivalent gains

### Healthy Applications
- Streak protection (don't want to lose streak)
- Rank maintenance (don't want to drop)
- Time investment (don't want to waste session)

### Implementation Guidelines
- Make losses recoverable
- Don't punish too severely
- Focus on potential gains
- Provide comeback mechanics

### LexiClash Applications
- Daily streak (existing) - good
- Combo timeout (8 sec) - creates tension
- Consider: Streak freeze tokens

## Social Comparison

### Upward Comparison
Comparing to better players

**Effects**:
- Can motivate improvement
- Can demotivate if gap too large
- Creates aspiration

**Design implications**:
- Show achievable nearby ranks
- Highlight improvement path
- Celebrate closing gaps

### Downward Comparison
Comparing to worse players

**Effects**:
- Provides confidence
- Validates effort
- Can reduce motivation if too easy

**Design implications**:
- Show percentile rankings
- Highlight wins over others
- Balanced matchmaking

### Lateral Comparison
Comparing to similar players

**Effects**:
- Creates healthy competition
- Feels fair and achievable
- Drives engagement

**Design implications**:
- Friend leaderboards
- Skill-based matchmaking
- "Players like you" sections

## The Endowment Effect

### Principle
People value things more once they own them

### Applications
- Player-created content (custom rooms)
- Earned achievements (not purchased)
- Built-up progress (levels, stats)
- Collected items (cosmetics, badges)

### LexiClash Opportunities
- Custom board creation (ownership)
- Earned titles (achievement-based)
- Player statistics (investment)
- Personal word history (unique data)

## Variable Ratio Reinforcement

### Most Addictive Schedule
Reward after unpredictable number of actions

### Examples in Games
- Loot drops
- Critical hits
- Rare word discoveries
- Achievement unlocks

### LexiClash Applications
- Legendary word discovery (random)
- Achievement unlock timing (variable)
- Fire round triggers (surprise)
- Rare opponent matching

### Ethical Considerations
- Don't exploit compulsive behavior
- Provide cool-down mechanisms
- Be transparent about randomness
- Avoid gambling-adjacent mechanics

## Cognitive Biases in Game Design

### Sunk Cost Fallacy
Players continue because of past investment

**Design implications**:
- Show total progress
- Display time invested
- Celebrate milestones
- Don't punish leaving

### Availability Heuristic
Recent/memorable events seem more common

**Design implications**:
- Celebrate wins visibly
- Make achievements memorable
- Highlight positive moments
- Reduce negative memory strength

### Anchoring Effect
First number influences subsequent judgments

**Design implications**:
- High score displays
- "Average" score anchors
- Percentile rankings
- Goal setting

### The Peak-End Rule
Experiences judged by peak and end moments

**Design implications**:
- Strong finish celebrations
- Memorable achievement moments
- Positive session endings
- Avoid ending on frustration

## Player Retention Psychology

### Day 1 Retention
First session is critical

**Requirements**:
- Immediate fun (no tutorials blocking)
- Early win experience
- Clear value proposition
- Low friction return

### Day 7 Retention
Habits forming

**Requirements**:
- Daily return reason (daily challenge)
- Progress visibility
- Social hooks activated
- Variety introduced

### Day 30 Retention
Long-term engagement

**Requirements**:
- Deep goals established
- Social investment made
- Mastery path clear
- New content flow

| Day | Primary Lever | Backup Lever |
|-----|---------------|--------------|
| 1 | Quick fun game | Achievement unlock |
| 7 | Daily streak | Friend challenge |
| 30 | Rank progression | Season rewards |

## Motivation Decay

### The Problem
Novelty wears off, motivation decreases

### Solutions
1. **Content refreshes**: New modes, events, themes
2. **Social deepening**: More friend features
3. **Mastery paths**: Advanced techniques to learn
4. **Meta-progression**: Seasonal ranks, prestige

### LexiClash Refresh Opportunities
- Seasonal themes
- Limited events
- New game modes
- Achievement expansions
- Leaderboard resets

## Player Segmentation

### By Engagement Level

**Whales** (Top 1%)
- Highly engaged
- Feature complete
- Content hungry
- Community leaders

**Dolphins** (Next 10%)
- Regular players
- Feature explorers
- Moderate investment
- Social connectors

**Minnows** (Next 30%)
- Casual players
- Core mode only
- Low investment
- Potential growth

**Tourists** (Bottom 60%)
- Try and leave
- Need better hook
- Conversion targets

### Design for Each Segment
- Whales: Depth, prestige, community
- Dolphins: Variety, social features
- Minnows: Simplicity, quick satisfaction
- Tourists: Onboarding, instant gratification
