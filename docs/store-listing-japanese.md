```
友達とリアルタイム単語バトル。4言語対応。待ち時間ゼロ。無料。
```

## Full Description
```
誰も見つけられなかった単語を見つけた瞬間の快感、知ってるでしょ？LexiClashはその気持ちのために作った。

文字をスワイプして、単語を作って、友達に勝つ。全部リアルタイムで起きる。「3時間後にあなたの番」じゃない。本物の対戦相手、本物のプレッシャー、みんなが「ねこ」で止まってる間に7文字の単語を叩き出す本物の達成感。

他と何が違うのか

ほとんどの単語ゲームは遅い。単語を置いて、スマホを置いて、おばあちゃんが来週の火曜に返すのを待つ。LexiClashはリアルタイム。全員が同じボード、同じ時計、同じパニック。クロスワードよりパーティーゲームに近い。

4言語、1つのゲーム

英語、ヘブライ語、スウェーデン語、日本語でプレイ。メニューの翻訳だけじゃない。各言語の本物の辞書を搭載。セッション中に言語を切り替えてもOK。スウェーデン人の友達と日本人の同僚が、どっちの語彙力が上か決着をつけられる。

ゲームモード

ワードアリーナ — ライブマルチプレイヤーバトルに参加。クイックスタートで数秒で対戦相手が見つかる。プライベートルームを作って知り合いと決着をつけることもできる。

デイリーチャレンジ — 毎日、全員が同じパズル。全プレイヤーとスコアを比較。エゴに良い。たまにエゴに悪い。

アドベンチャー — テーマ別ワールドで100以上のレベル（ルートケイブ、シノニムスプリング、アルファベットメドウ）。各ワールドが新しいルールを投げてくる。「単語を見つけるだけ」じゃない。重力、ロックタイル、その他の変化球も。

プラクティス — ソロモード。タイマーのプレッシャーなし。自分とグリッドだけ。ウォーミングアップに最適。

デザイン

ダークテーマ、太いボーダー、グラデーションゼロ。みんな同じ人がデザインしたようなアプリに飽きたなら、気に入るはず。ネオブルータリストと呼んでる。好きに呼んで。

あなたの進捗

グローバルリーダーボードとティアランキング（ブロンズからダイヤモンド）。ベストワード、最長ストリーク、最高スコアを追跡。1位を目指すもよし、ルームメイトに勝つだけでもよし。

本当に無料

レベルをブロックする課金壁なし。「広告を30回見て続ける」なし。1円も払わずにフルゲームをプレイできる。おしゃれしたいならオプションのコスメティックがあるけど、なくても全然遊べる。

ダウンロードして。単語を見つけて。友達に自慢して。
```
