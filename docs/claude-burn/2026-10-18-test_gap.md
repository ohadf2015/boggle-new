## 2. Hebrew punctuation is written in reverse under `direction: 'rtl'`
- **Where:** `SurvivalPromoVideoHe.tsx:348` (`?ניחוש…`), `:448` (`?ההתחלה`), `:496` (`.מצאו…`), `:920` (`...⚠️ …`), `:999`, `:1271` (`!שרדתם`), `:1406` and `:1422`.
- **Why it's a bug:** The strings put the punctuation first, as if the text were stored visually. Every one of these blocks also sets `direction: 'rtl'`. In an RTL paragraph a leading neutral character renders at the right, which is the start of the line. The `?`, `!` and `.` therefore appear on the wrong side, in the hero text of the Hebrew Reel.
- **Cost:** The Hebrew ad looks broken. Hebrew is one of the main locales, and the repo already guards bidi elsewhere (`towerArt.bidi.test.ts`).
- **Test:** same folder, `heBidiPunctuation.test.ts`
```ts
import { readFileSync } from 'fs';
import { join } from 'path';
import { describe, it, expect } from 'vitest';

describe('Hebrew promo strings are logical-order', () => {
  it.each(['SurvivalPromoVideoHe.tsx','WordHuntPromoVideoHe.tsx'])('%s', (f) => {
    const src = readFileSync(join(__dirname, '..', f), 'utf8');
    // JSX text or string literal starting with punctuation immediately followed by Hebrew
    const bad = src.split('\n').filter((l) => /(^|[>'"`\s])[?!.]+\s?(?:[^\x00-\x7F]*[\u0590-\u05FF])/.test(l) && /[?!.]+\s?[\u0590-\u05FF]/.test(l.trim().replace(/^[^?!.\u0590-\u05FF]*/, '')) && /^\s*(?:[>'"`])?\s*[?!.]/.test(l.trim().replace(/^[^\u0590-\u05FF?!.]*(?=[?!.])/, '')));
    expect(bad).toEqual([]);
  });
});
```
This regex is clumsy. Simpler and more robust is to assert there is no match for `/(?:^|[>'"`])\s*[?!.]+\s*[\u0590-\u05FF]/m` on lines containing Hebrew. If the current strings are intentional, flip the assertion and pin them. Either way it stops silent drift.

## 5. Hand-maintained duration maths and drift between English and Hebrew cuts
- **Where:** `WordHuntPromoVideo.tsx:764` and `WordHuntPromoVideoHe.tsx:717` hard-code `TOTAL_FRAMES = 462`, while the real length is `105+132+102+102+69 − 4×12`. The Survival files compute theirs, and the Wordle file does the same at `:1403`. The durations and transitions are duplicated across each English/Hebrew pair.
- **Cost:** Editing one scene length without updating the constant mis-times the audio fade-out. The Hebrew copy can also silently diverge from the English one.
- **Test:** `promoTiming.test.ts`
```ts
import { readFileSync } from 'fs';
import { join } from 'path';
import { describe, it, expect } from 'vitest';

const src = (f: string) => readFileSync(join(__dirname, '..', f), 'utf8');
const seqs = (s: string) => [...s.matchAll(/durationInFrames=\{(\d+)\}/g)].map((m) => Number(m[1]));

describe('WordHunt promo timing', () => {
  it.each(['WordHuntPromoVideo.tsx','WordHuntPromoVideoHe.tsx'])('%s TOTAL_FRAMES equals scene sum minus overlaps', (f) => {
    const s = src(f);
    const total = Number(s.match(/TOTAL_FRAMES = (\d+)/)![1]);
    const T = Number(s.match(/const T = (\d+)/)![1]);
    const sceneDurs = seqs(s).filter((n) => n !== T);
    expect(total).toBe(sceneDurs.reduce((a, b) => a + b, 0) - T * (sceneDurs.length - 1));
  });
  it('He and En scene durations match', () => {
    expect(seqs(src('WordHuntPromoVideoHe.tsx'))).toEqual(seqs(src('WordHuntPromoVideo.tsx')));
    expect(seqs(src('SurvivalPromoVideoHe.tsx'))).toEqual(seqs(src('SurvivalPromoVideo.tsx')));
  });
});
```
For the Survival files, `durationInFrames={SCENE_DURATIONS.x}` doesn't match the numeric regex, so the second test would compare empty lists there. To cover them, export `SCENE_DURATIONS` and compare it directly.
