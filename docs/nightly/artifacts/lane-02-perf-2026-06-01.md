## What was done

### Frontend fix: /en/leaderboard LCP 7132ms
Root cause: `PageClient.tsx` wrapped the `<h1>` in `<m.div initial={{ opacity: 0, y: -20 }}>`.
Next.js SSRs client components, but Framer Motion bakes the `initial` state as an inline style in the
SSR'd HTML — so the browser received `style="opacity:0"` on the heading. The browser's LCP algorithm
skips invisible elements, so LCP fired only after JS hydrated and Framer ran the animation.

Fix: Changed `initial={{ opacity: 0, y: -20 }}` → `initial={{ opacity: 1, y: 0 }}`. The heading is now
visible in the SSR'd HTML, giving the browser an immediate LCP candidate.

### Backend: no changes
- `word_review_state.lesson_id` FK index skipped: table has 0 rows, adding index is speculative per hard rules.
- `auth_db_connections_absolute`: cannot fix via SQL migration — requires Dashboard config change.
- `pg_stat_statements` top queries unchanged from prior baseline; no new regressions.

### Deferred (perf-watch.md)

  game-client hydration. Proper fix requires SSR skeleton + data prefetch — out of single-lane time budget.
