## Concrete improvements (ranked by impact × effort)
1. **Delete `_gate_ensure_bin`'s precondition guard and assert instead** — `rg "self-healing with|self-heal
   failed|missing dev-tool"` over all four run logs returns **zero matches**: the self-heal never ran. The
   guard `[ -e node_modules/.bin/<tool> ]` passes on symlinks the `cp -Rc` clone left unrunnable, so the gate
   sails past provisioning and dies on `command not found`. **Fix: after the clone, unconditionally run
   `./node_modules/.bin/eslint --version`; if it fails, `cp -a` `.bin` from the primary checkout and re-assert;
   if it still fails, abort loudly.** Editing the `npm rebuild` line alone changes nothing — it is unreachable.
   Effort: **S**. Impact: the single highest-value change in the loop.
   File: `scripts/nightly/lib/gate-isolated.sh:84-96` (guard) + `:459-464` (clone).
2. **Short-circuit the gate when `.bin` provisioning fails** — if the assert in #1 fails, go straight to
   in-place fallback + Telegram alert. Do not run four more full gates to rediscover a known-broken
   toolchain. Effort: **S**. Impact: −2h of nightly wall-clock on a bad night; nights finish before 04:00.
   File: `scripts/nightly/lib/gate-isolated.sh` (tier dispatcher, ~line 547).
3. **Union merge driver for the nightly artifacts** — add to `.gitattributes`:
   `docs/nightly/impact-ledger.ndjson merge=union`, same for `restore-queue.ndjson`; regenerate
   `perf-baseline.json` and `mode-readiness.md` post-merge instead of committing both sides. Effort: **S**.
   Impact: kills the isolated-ship conflict class and stops new stranded `refs/nightly-pending/*`.
4. **Make the preflight off-master retry real, or alert** — the 09-02/09-03 `re-running once in 180 min` line
   produced no second log. Either schedule it via `at`/launchd and log the schedule id, or make the abort
   send Telegram immediately. A retry that never runs is worse than no retry. Effort: **M**.
   Impact: 2 recovered nights per week. File: `scripts/nightly/lib/preflight.sh`.
5. **Emit `files_shipped=<n>` per lane after the gate** — lane rc cannot go red, so no dashboard can see a
   zero-code night. One line per lane in the run log turns "12 lanes succeeded" into "12 lanes succeeded,
   0 files shipped". Effort: **S**. Impact: lane 7 can attribute instead of grep-archaeology.
   File: `scripts/nightly/run.sh` (post-gate summary).
6. **Fix the double-tee in run.sh** — every log line is printed twice; logs are 1.2 MB for a 3 h night.
   Effort: **S**. Impact: halves every lane's log-read cost. File: `scripts/nightly/run.sh`.
7. **Hard-stop repeated-blocker lanes in the prompt** — "if your own prior artifact names the same blocker
   two nights running, you MUST spend tonight on the blocker or a different target." Written twice, obeyed
   zero times; needs to be a prompt hard-stop, not advice. Effort: **S**. Impact: ends the wheel-rush
   plateau. File: lane-11 prompt.
