## What's working well
- **The `baseline-gate` tier earns its keep.** 10-09 and 10-10 are a controlled experiment: same 23-file
  volume, same first-gate FAIL. 10-10 scoped a CLEAN-HEAD re-gate to the single failing test file, got
  PASS, ruled out a baseline red, and **shipped `88f710507`**. 10-09, without that tier, dropped 23 files.
- **Isolated ship protects founder work without exception.** Every shipped night logged
  `restoring local master to founder base … (commit + WIP byte-identical)`.
- **The lane time-guard holds.** `idle-kill @ 900-1500s, finalize @ +24m, backstop @ +30m, file-cap=8` fired
  on all 5 run-nights with zero half-written files attributed to a lane.
- **Lanes have learned to say "verified clean, no fix".** 10-12 lanes 02 and 11 both declined to fix
  something (stale FK-index advisor row; n=1 LCP sample) with file:line / query evidence. That is the
  correct behavior and it should not be read as a low-yield night.
- **The artifact floor works.** 10-12 wrote 7 lane artifacts before the gate ran.

  pre-dates isolated ship, which handles the identical case 20 lines below. Cost: all of 10-11.
- **Aborted nights leave nothing on disk.** Both 10-07 and 10-11 produced no report, no artifact. There is
  no `docs/nightly/reports/2026-10-11.md`; the night is invisible except in the raw log.
- **The gate is the loop's longest phase by 3×.** 43m / 70m / 4h09m / 2h49m. The two long ones were repair

## Concrete improvements (ranked by impact × effort)
1. **Delete the clean-tree divergence abort — route it into isolated ship.** On `git pull --ff-only`
   failure with non-docs local commits, set `NIGHTLY_ISOLATED_SHIP=1` + `NIGHTLY_FOUNDER_BASE` and continue
   instead of `return 1`. Effort: S. Impact: recovers ~1 night in 7 (10-11 = 0 of 21 authored files).
   File: `scripts/nightly/lib/preflight.sh:240-250`. **SHIPPED BY LANE 7 TONIGHT.**
2. **Make a gate PASS that commits nothing an ERROR.** 10-08's gate PASSED on 15 authored files, then logged
   `nothing to commit after excluding generated artifacts — treating as no-change` twice and shipped only
   residual docs (`c547ba1df`). No alert; the run reported success. If the gate passed on N>0 authored *code*
   files and the ship commits 0 of them, alert with the excluded-path list. Effort: S. Impact: recovers a
   second lost night per window (15 files). File: `scripts/nightly/run.sh` (ship/commit step).
3. **Debug the existing per-file bisect — do NOT rewrite it.** `nightly_bisect_offenders` is already built,
   wired and tested (`lib/gate-isolated.sh:373` ← `run.sh:1143`, `test/bisect-offenders.test.sh`). Logs show
   3 `bisect` lines on 10-10 (shipped) vs **1 on 10-09** (dropped 23), so the gap is one invocation that
   attributed nothing — likely its `quick` typecheck oracle going inconclusive under a `next build` TS wedge,
   not a missing feature. Effort: M. Impact: 10-09 ships 21-22 of 23. File: `lib/gate-isolated.sh`.
4. **Progress check on the gate repair loop.** Abort when attempt N's failing-file set is no smaller than
   N-1's, or after 2 attempts. Effort: S. Impact: reclaims ~3h of compute on a FAIL night and stops the
   TS2353↔TS2741 ping-pong. File: `scripts/nightly/run.sh`.
5. **Write `docs/nightly/artifacts/run-aborted-<date>.md` on every early exit** (preflight abort, spend cap,
   circuit breaker) with the cause + the exact unblock command, and commit it docs-only. Effort: S. Impact:
   two invisible nights per window become diagnosable in 10 seconds. Files: `scripts/nightly/lib/preflight.sh`,
   `run.sh` circuit-breaker path. Carried unfixed from 10-05 and 10-12's predecessor.
6. **`$host`-filter PostHog web-vitals inside the collector, not the lane.** Effort: S. Impact: gives lane 02
   back ~10 min/night it currently spends disproving imposketch.io rows, 5 nights running.
   File: the intel collector that emits the LCP top-5.
7. **`merge=union` in `.gitattributes` for `docs/nightly/impact-ledger.ndjson`, `mode-readiness.md`,
   `perf-baseline.json`.** Effort: M. Impact: unstrands 3 pending refs (~70 nights) and removes 3 WARN lines
   from every future run — and item 1 makes this MORE urgent: converting "abort" into "run + cherry-pick onto a diverged origin/master" raises conflict odds, and the conflict sink IS `refs/nightly-pending/` (0% recovery in ~70 nights). Treat 1 and 7 as coupled. File: `.gitattributes`.
8. **Prompt-only: stop re-auditing the blast reconnect MAJOR nightly.** It is 6 files + a gating condition +
   a TDD reconnect test — structurally impossible inside a 15-min lane, and lane 11 has now spent 3 nights
   confirming that. Move it to the human queue and let lane 11 rotate to `sealed-bid` / `brain-drill`.
   Effort: S. Impact: 3 wasted lane-nights/week recovered. File: lane 11 prompt in `run.sh`.
