## Concrete improvements (ranked by impact x effort)

1. **Ship heartbeat logging in `headless.sh`** — emit a timestamp+tool-name line every 60s during each lane's run. When a lane exits 124, the log shows which MCP call it hung on (Sentry? PostHog? Supabase?). Without this, we're debugging blind. Effort: S. Impact: diagnose 29% of lane-runs that currently produce zero output. File: `scripts/nightly/headless.sh`.

2. **Split file cap: code vs docs** — change the 8-file cap to 6 code + 4 doc (or 10 total with >=2 doc). Lanes with mandatory report/baseline output won't revert for writing their own report. Effort: S. Impact: recover 17% of lane-runs lost to cap reverts. File: `scripts/nightly/run.sh` (or wherever cap is enforced).

3. **Remove Reddit retry from lane 4 prompt** — hardcode in the prompt: "Reddit is IP-blocked. Do NOT attempt reddit.com, old.reddit.com, pullpush.io, or site:reddit.com WebSearch. Use only: WebSearch SERP (general queries), competitor sites, Discord." Saves ~60s and 3 wasted tool calls per night. Effort: S. Impact: lane 4 focuses on viable sources immediately. File: lane 4 prompt file.

4. **Fix getUpdates poller collision** — make the nightly run read from the daemon's NDJSON buffer file instead of opening its own Telegram long-poll. Or add exclusive lock so only one process polls at a time. Effort: M. Impact: unblock entire feedback signal (currently 5 nights of zero acks). File: `scripts/nightly/lib/feedback-poll.sh` + daemon script.

5. **Add per-MCP-call timeout (30s)** — wrap each MCP tool invocation in the headless runner with a 30s alarm. If a single call hangs, kill and retry once, then skip that data source and continue. Prevents the "one hung PostHog query kills the whole lane" failure mode. Effort: M. Impact: lanes degrade gracefully instead of producing zero output. File: `scripts/nightly/headless.sh`.

6. **Lane 4: cap ideas output to 1 file** — lane 4 generates ideas.md + reddit.md + competitor notes separately. Merge into a single `ideas/YYYY-MM-DD.md` to stay under file cap. Effort: S. Impact: prevent 05-23-style 17-file blowout. File: lane 4 prompt.
