## Concrete improvements (ranked by impact × effort)
1. **Per-file gate bisect instead of all-or-nothing.** On a gate FAIL, parse the file paths out of the
   `tsc`/vitest failure lines, move ONLY those authored files aside, re-gate once, ship the remainder.
   Effort: M. Impact: 10-09 ships 21–22 of 23 instead of 0 — recovers ~1 night in 6 and removes the
   retry storm's cause. File: `scripts/nightly/run.sh` (~L1000, beside the existing `drop-and-re-gate`
   hook, which today drops *lint*, not *files*). Metric: authored-files-shipped / authored-files-kept.
2. **Abort the repair loop when it stops making progress.** Cap at 2 attempts, or stop when attempt N's
   error-line count is ≥ attempt N-1's. Effort: S. Impact: reclaims ~2.5h of nightly compute and ends the
   run before dawn. File: `scripts/nightly/run.sh` gate block. Metric: gate phase wall-clock (3h07m → <45m).
3. **Prompt rule for every code lane: a copy/props key is a TWO-SITE edit.** Add to the shared lane
   preamble: *"adding a key to an object literal whose type is inferred inline → `rg` a sibling key and
   edit every site in the same edit, then `cd fe-next && npx tsc --noEmit`. `npx eslint` does not
   type-check."* Effort: S. Impact: removes the exact failure class that cost 10-09. File: lane prompts /
   `docs/nightly/learnings.md` preamble. Metric: gate FAIL rate on `error TS`.
4. **Pre-lane abort writes an artifact + one Telegram alert.** On rc=76 / any pre-lane abort, write
   `docs/nightly/artifacts/run-aborted-<date>.md` (reason + exact unblock command), commit docs-only, send
   one alert, exit. Effort: S. Impact: a dead night reads as dead on night 1 instead of being discovered a
   week later. File: `scripts/nightly/run.sh` circuit-breaker block. Carried unfixed from 10-05.
5. **Pin the MCP servers off `npx`.** `fail:transport(no response — npx boot/connect failed)` on 5/6
   nights matches the known "npx cold-boot hangs subagents" class. Install `@supabase/mcp-server` locally
   and point `.mcp.json` at the resolved binary. Effort: S/M. Impact: lanes 01/12 get real Supabase data
   instead of stale fallbacks. File: `.mcp.json`, `scripts/nightly/run.sh` probe.
6. **`merge=union` for the three append-only nightly artifacts.** `docs/nightly/impact-ledger.ndjson`,
   `mode-readiness.md`, `perf-baseline.json` conflict on every pending-ref retry — that is why
   `refs/nightly-pending/2026-08-03` has failed ~68 nights. Effort: M. Impact: 3 stranded nights land, and
   the warning stops firing nightly. File: `.gitattributes`.
7. **Report `files_shipped=` per lane after the gate, not `kept N`.** 10-09 logged "kept 23" and shipped 0.
   Effort: S. Impact: the nightly report stops over-claiming. File: `scripts/nightly/run.sh` post-gate.
