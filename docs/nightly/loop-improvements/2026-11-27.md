## What's working well
- **The lane layer is not the problem and has not been for 36 nights.** 6–8 lanes a night, 1–3 files each,
  no `exit 124`, no idle-kill. Every minute spent tuning lane prompts for reliability is misallocated.
- **The artifact floor is the only universally-completed step** — 56 files written across 11-19..11-27.
  (They are all untracked; see friction.)
- **The file-volume clamp holds.** 11-27 was 1/1/1/3/3 — no lane dominated.
- **The scheduler's zero-signal skipping is working as designed** and is honest: it dropped 04/08/09/10/12
  on 11-27 rather than burning budget on lanes with no input.
- **The `rc=2` → in-place-fallback design is correct.** It is the right answer to "the toolchain is broken,
  don't blame the code." It is simply never reached, for one grep's worth of reasons.

## Friction points
- **The gate's own dependency tree is broken and the gate cannot tell.** `_gate_ensure_bin` detects the empty
  `.bin` correctly on *every* unit, runs `npm rebuild`, and that rebuild **fails every time** — the log line
  `'npm rebuild' self-heal failed` appears on all 13 gate units of 11-26. Detection without a working remedy,
  13–29 times a night. Affects every code lane.
- **The linear peel is 30–55 min/night of pure waste.** 13–29 FAIL units all tracing to one empty directory.
- **`docs/nightly/feedback/` and `docs/nightly/reports/` are both gitignored** (`.gitignore:81,82`). A founder
  Telegram message landed 11-20 ("Fix them" / "And polish it more") and sat unread for 7 nights because last
  window's lane 7 read the directory listing as ending at 11-06. Ignored files are invisible to review.
- **`residual ship OK (6f09959c5)` is printed on nights with zero commits.** `6f09959c5` is local HEAD from
  11-19. Four nights this window reported success while shipping nothing.
- **A spend-cap abort prints `nightly-loop complete`.** 11-21: `rc=76` ×5 + breaker at 01:15, final log line
  `[01:16:05] nightly-loop complete`. Indistinguishable from a healthy run in the log and the card.
- **No lane can ship a fix to any of the above** — `scripts/` is dropped as code, carried 5 windows.

## Concrete improvements (ranked by impact × effort)
1. **Provision the tree, then refuse to gate an unprovisioned one.** `cd fe-next && npm ci --prefer-offline`
   (human, one time), then add a 4-line precheck at the top of the isolated gate returning `rc=2` when
   `ls fe-next/node_modules/.bin | wc -l` < 20. Effort: **S**. Impact: converts 13–29 nightly `drop-all`
   verdicts into real code verdicts; metric = *nightly commits/week, 0 → >0*. File: `scripts/nightly/lib/gate-isolated.sh` (~:518).
2. **Widen the SETUP classifier grep by one alternation.** Add `error TS2688|error TS2307|MODULE_NOT_FOUND|Cannot find module '`
   to `gate-isolated.sh:51`. Effort: **S**. Impact: belt-and-suspenders for #1; also catches the next spelling
   (the named lib changed from `aria-query` → `yauzl` → `zod`/`detect-libc` across four nights — the *name* is noise).
3. **Keep `scripts/nightly/` as docs, not code.** One entry beside the `docs/` keep logic at `run.sh:1116`.
   Effort: **S**. Impact: **unblocks #1, #2, #4, #5 ever shipping autonomously.** Gating item, carried 5 windows.
4. **Fast-forward `master` before lane 1, abort if it won't.** `git update-ref` (never `checkout`/`pull` — the
   founder worktree has 142 dirty files). Effort: **S**. Impact: lanes stop authoring against a tree missing
   148 merged commits; kills the duplicate-work class. File: `scripts/nightly/run.sh`, after the existing fetch.
5. **Make the log answer "which lane, how long, how much code."** Print `lane=<name> elapsed=<s> kept=<n> code=<n>`
   on lane exit, and assert the ship sha differs from pre-run HEAD before printing `residual ship OK`.
   Effort: **S**. Impact: this review can finally compute a success rate and a duration; and a 0-commit night
   stops reporting as a success. File: `scripts/nightly/run.sh`.
6. **Un-ignore `docs/nightly/feedback/` and commit `artifacts/` from an EXIT trap.** Effort: **M**. Impact:
   founder messages become reviewable (#H4 cost 7 nights); a run that dies post-lanes still leaves a record.
   Files: `.gitignore:81-82`, `scripts/nightly/run.sh` (trap).
7. **Distinguish a spend-cap abort from a complete run** — `run-aborted-<date>.md` + a distinct Telegram card
   on `rc=76`. Effort: **S**. Impact: a budget stop stops reading as a healthy night. Budget call, not a bug.
