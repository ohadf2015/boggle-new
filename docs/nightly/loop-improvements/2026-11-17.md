## What's working well
- **The lane layer is solved.** 8/8 ran on 11-16 at sane durations and sane file counts. Every hour spent
  tuning lane prompts for reliability since 10-23 has been wasted motion.
- **The gate's SETUP-reclassification is the best mechanism in the codebase.** `gate-isolated.sh:49-52` +
  `:624` already refuse to blame lane code for a missing `.bin` symlink, falling back to the in-place gate
  (rc=2) instead of dropping. It fired 82 times on 11-16. The whole fix below is making that one predicate wider.
- **The typecheck-tier-before-drop-all guard is correct.** It refuses to discard build-clean code on an
  undecidable red. It is not the problem; it just never gets a clean baseline to compare against.
- **Preflight divergence → isolated ship.** Founder WIP untouched 6/6 nights. Zero incidents in 6 windows.
- **The mandatory-artifact floor** is the only thing the loop reliably delivers — when a commit happens.

## Concrete improvements (ranked by impact × effort)
1. **Classify `TS2688` as a SETUP failure, not lane code** — add one grep to
   `nightly_gate_output_is_toolchain_error()`; a missing `@types` directory is the same class as a missing
   `.bin` symlink and is not authorable by any lane. Effort: **S (3 lines)**. Impact: turns 6/6 `drop-all`
   nights into real verdicts and saves ~32m of peel per night. File: `scripts/nightly/lib/gate-isolated.sh:51`.
   Exact patch is in `learnings.md` Headline 0.
2. **Verify the CoW clone, don't trust it** — extend `_gate_ensure_bin` to compare
   `ls node_modules/@types | wc -l` in the worktree against the source repo and `npm ci --prefer-offline`
   (or re-clone) on divergence. Effort: **M**. Impact: fixes the cause under #1 so the typecheck tier is
   actually usable rather than merely non-fatal. File: `scripts/nightly/lib/gate-isolated.sh:520-525, :101-116`.
3. **Add `scripts/nightly` to the keep set** — the loop still cannot ship its own repair, so #1 and #2 have
   to be applied by hand. It sits outside `fe-next/`, so it cannot change the app's lint/type/test/build
   verdict. Effort: **S**. Impact: every future lane-7 infra fix becomes self-applying. File:
   `scripts/nightly/run.sh` (~:1179, beside the `docs/` keep logic).
4. **Make "shipped" mean a SHA with code in it** — after the salvage commit, `git rev-parse` the result,
   print `lane=<name> kept=<n> code=<n>`, and `tg_alert` when `authored code > 0 && committed code == 0` OR
   when no SHA exists. Effort: **S**. Impact: kills the two reporting lies that let 45 silent days pass.
   File: `scripts/nightly/run.sh:1195-1215`.
5. **Give lane 7 a mandatory first command** — `rg -No 'error TS[0-9]+' <newest gated log> | sort | uniq -c
   | sort -rn | head` before writing a single line, with an explicit prompt instruction that last night's
   headline is a hypothesis to retest, never a fact to inherit. Effort: **S (prompt-only)**. Impact: prevents
   another 6-window stale root cause. File: lane 07 prompt in `scripts/nightly/lanes/`.
6. **Give every proposing lane a master-awareness line** — `git log --since="7 days ago" --oneline master |
   rg -i '<keyword>'` before proposing work. Effort: **S (prompt-only)**. Impact: stops lanes 04/09/11
   re-proposing what #1973–#1994 already shipped. File: lane prompts.
7. **Create `.gitattributes`** with `merge=union` for `impact-ledger.ndjson`, `mode-readiness.md`,
   `perf-baseline.json`, `restore-queue.ndjson`; `refs/nightly-pending/` is now **10** stranded refs (was 9).
