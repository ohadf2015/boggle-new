## Concrete improvements (ranked by impact × effort)
1. **Widen the toolchain-error predicate to the whole missing-dependency class** — the single highest-value change in
   the loop. Effort: **S** (3 lines). Impact: converts gate `drop-all` into a `rc=2 SETUP` + in-place re-gate, so
   authored code gets a real verdict; also skips the 30–55m peel. Metric: nightly `code committed` 0 → >0.
   File: `scripts/nightly/lib/gate-isolated.sh:51`.
   ```sh
   LC_ALL=C grep -qaE 'command not found|[^[:alnum:]_]not found$' "$out" 2>/dev/null && return 0
   # Missing provisioned dependency in the CoW clone — NEVER authorable by a lane.
   LC_ALL=C grep -qaE "error TS2688|MODULE_NOT_FOUND|Cannot find module '" "$out" 2>/dev/null
   ```
2. **Verify the clone instead of trusting `cp`** — after the clone, assert `ls node_modules/@types | wc -l` matches the
   source repo and `node -e "require.resolve('eslint')"` succeeds; on divergence `npm ci --prefer-offline`, or stop
   copying and bind/symlink `node_modules` read-only. Effort: **M**. Impact: removes the root cause rather than
   reclassifying it. Metric: `isolated-gate: FAIL` count 7/7 → ~0 for environment reasons.
   File: `scripts/nightly/lib/gate-isolated.sh:520-525` + `_gate_ensure_bin`.
3. **Add `scripts/nightly` to the ship keep-set** so the loop can land its own repairs. Effort: **S**. Impact: ends the
   hand-apply dependency; `scripts/` is outside `fe-next/` so it cannot alter the app's gate verdict.
   File: `scripts/nightly/run.sh` (~:1179, beside the `docs/` keep logic).
4. **Make the ship report provable, and never claim a foreign sha.** After the salvage/ship step, `git rev-parse` the
   created sha, assert `git log -1 --format=%s` starts with `chore(nightly)`, count `fe-next/` paths, and print
   `lane=<name> kept=<n> code=<n> sha=<sha>`. `tg_alert` when authored-code > 0 and committed-code = 0, or when
   0 files were authored yet a ship was reported. Effort: **S**. Impact: ends 9 windows of false-success reporting.
   File: `scripts/nightly/run.sh` (integration + summary).
5. **Trap-commit the artifact floor on ANY exit.** 11-20 died inside lane 2 and lost lane 01's 7 kept files plus every
   artifact; 11-21's spend cap did the same. A `trap` that commits `docs/nightly/artifacts/` + a
   `run-aborted-<date>.md` on EXIT/TERM makes the floor actually a floor. Effort: **M**. Impact: 4 no-commit nights
   this window → 0. File: `scripts/nightly/run.sh`.
6. **Make the spend cap a distinct, loud outcome.** `rc=76` currently flows into the normal summary path. It needs its
   own Telegram card ("SPEND CAP — N lanes deferred") and `run-aborted-<date>.md`. Effort: **S**. Impact: the founder
   learns a budget decision is blocking whole nights instead of reading a green card. File: `scripts/nightly/run.sh`.
7. **Un-ignore `docs/nightly/reports/` or delete STEP 6 from all 12 prompts.** Today both the write and the prompt
   text are pure waste. Effort: **S**. Impact: removes a dead step from every lane's budget.
   File: `.gitignore:82` (or the 12 lane prompts).
