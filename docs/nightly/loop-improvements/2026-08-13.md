## Concrete improvements (ranked by impact × effort)

1. **Run the night in a worktree pinned to `origin/master` instead of demanding a clean master checkout.**
   Preflight creates/reuses `~/lexi-nightly-wt` at `origin/master` and runs every lane there; the
   founder's primary checkout is never touched. Effort: M. Impact: recovers **3 of 7 nights** — the
   largest single loss in the loop. File: `scripts/nightly/run.sh` (preflight block).
   *Caveat, do not skip:* project memory says a symlinked `node_modules` breaks turbopack (`next build
   --webpack` is required) and `npx vitest` from a worktree root loads the wrong config. Prototype the
   gate inside the worktree before switching the loop over.

2. **Make the preflight abort LOUD.** One `telegram.sh msg` on any preflight abort, naming the branch and
   the dirty paths. Effort: **S** (3 lines). Impact: converts a 3-night silent loss into a 1-night loss —
   the founder switches branch and the next run works. This is the cheapest item on the list and should
   ship even if #1 does not. File: `scripts/nightly/run.sh`.

3. **Instrument the gate wedge before trying to fix it.** On the 2700s idle kill, log the last 40 lines of
   the tier's output plus its rc, to `/tmp/nightly-wedge-<tag>.log`. Effort: S. Impact: turns the #2 cause
   of code drops from "unknown" into a diagnosable bug. Metric: gating nights ending in docs-only salvage
   (currently 3/3). File: `scripts/nightly/lib/gate-isolated.sh`.

4. **Replace the `npm rebuild` self-heal with a `.bin` copy from the primary checkout.**
   `cp -R <primary>/fe-next/node_modules/.bin <tmp>/fe-next/node_modules/.bin` — the primary's `.bin`
   demonstrably works (lanes run in-place fine). Effort: S. Impact: removes one of the two stacked
   failures; on its own it would NOT have saved any of this week's nights. File:
   `scripts/nightly/lib/gate-isolated.sh:76` (`_gate_ensure_bin`).

5. **Enforce the escalate-after-2-identical-verdicts rule in the lane 11 prompt itself.** If the prior 2
   reports carry the same blocker string, the lane must spend the night on the BLOCKER (pre-seed the
   consent cookie) and is forbidden from re-auditing code. Effort: S (prompt edit). Impact: unblocks
   wheel-rush readiness AND lane 02's Layout-Shifts capture — one fix, two lanes, 10+ nights stalled.

6. **Add the lane-12 idempotence guard.** Skip a lane whose `### Lane N` header already exists in tonight's
   report. Effort: S. Impact: prevents the duplicate-run waste seen on 07-30. File: `scripts/nightly/run.sh`.
