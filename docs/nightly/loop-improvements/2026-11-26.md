## Friction points
1. **The checkout is 134 commits behind `origin/master` and the loop never fast-forwards** (local HEAD
   `6f09959c5`, 11-19; origin `c8682142b`, 11-25; `FETCH_HEAD` stamped Nov 26 01:00 — it fetches, never merges).
   Affects **every lane**: they author against a tree missing 165 merged commits, so duplicated work is
   mechanically guaranteed, and a push from that branch is non-fast-forward.
2. **`residual ship OK (6f09959c5)` is stale local HEAD, printed as a success on 4 of 7 nights** with zero
   commits. Last window read this as "the loop claimed a foreign commit"; it is simpler and still wrong.
3. **TS2688 is 100% of all gate errors** (11-23: 276, 11-24: 1932, 11-25: 1035; **nothing else**), the named type
   lib changes night to night (`yauzl`, then `aria-query`), and `gate-isolated.sh:51` still greps only
   `command not found|not found$` — so 15–28 FAIL verdicts/night blame lane code for an absent `@types` dir.
4. **Two nights died after the lanes and before integration** — 11-20 inside lane 2, and 11-23 with
   `isolated-gate: FAIL` as the literal last log line. Not even the artifact floor shipped on those nights.
5. **`lane N` is positional over a nightly-varying set.** 11-26's scheduler skipped `04-competitor`, yet
   `lane 4 — kept 3` printed. Every per-lane number in this table is therefore best-effort.
6. **The linear peel burned 28 FAIL units on 11-22 and 11-24** for one missing `@types` directory — 30–55 min
   that taught nothing.
7. **`scripts/` is dropped as code**, so none of 1/3/4 can be fixed by the loop itself. Carried 4 windows.

## Concrete improvements (ranked by impact × effort)
1. **Fast-forward `master` to `origin/master` before lane 1, and abort loudly if it cannot.** Insert after the
   existing `git fetch`, before the WIP snapshot. Use `git update-ref refs/heads/master origin/master` guarded by
   `git merge-base --is-ancestor` — never `checkout`/`pull`, so the dirty founder worktree is untouched. On
   divergence, `tg_alert` + `exit 3`. Effort: **S**. Impact: lanes see current code; a passing gate becomes a
   landable push. Metric: nightly commits on `origin/master` per week, currently **0**. File: `scripts/nightly/run.sh`.
2. **Widen the SETUP predicate by three strings.** Add
   `LC_ALL=C grep -qaE "error TS2688|MODULE_NOT_FOUND|Cannot find module '"` beside the existing grep. Routes the
   night's only error class to rc=2 SETUP → the in-place fallback at `:624` → authored files get a real verdict.
   Effort: **S**. Impact: converts 15–28 false FAILs/night into one honest verdict and skips the peel. Metric:
   `isolated-gate: FAIL` count/night, currently 15–28. File: `scripts/nightly/lib/gate-isolated.sh:51`.
3. **Add `scripts/nightly` to the integration keep-set** beside the `docs/` logic (~`run.sh:1179`). It is outside
   `fe-next/`, so it cannot change the app's lint/type/test/build verdict. Effort: **S**. Impact: unblocks #1, #2,
   #4, #5 — the loop can finally ship its own repair. Metric: lane-7 patches landed, currently 0 of ~12 emitted.
4. **Make `residual ship OK` assert a real ship.** Capture `PRE_HEAD` before lane 1; before printing success,
   require `sha != PRE_HEAD` **and** `git log -1 --format=%s <sha>` starting `chore(nightly)`; otherwise
   `tg_alert "nightly: 0 commits, N files authored"` and exit non-zero. Effort: **S**. Impact: a zero-code night
   stops reading as a success, which is what hid this for 55 days. File: `scripts/nightly/run.sh`.
5. **Commit `docs/nightly/artifacts/` from an EXIT trap.** `trap '_nightly_ship_artifacts' EXIT INT TERM` so the
   floor survives a mid-lane death or a gate-line exit. Effort: **M**. Impact: the only change that guarantees a
   non-empty night, independent of the gate AND of the stale checkout — all 55 artifacts from 11-19..11-26 are
   currently untracked (see Late finding). **Promote above #4.** File: `scripts/nightly/run.sh`.
6. **Print `lane=<name> kept=<n> code=<n>` instead of `lane N — kept M`.** Carries the scheduler's real lane id and
   splits code from docs. Effort: **S**. Impact: every future lane-7 table becomes fact instead of inference.
7. **Create `.gitattributes`** (verified MISSING) with `merge=union` for `impact-ledger.ndjson`,
   `mode-readiness.md`, `perf-baseline.json`, `restore-queue.ndjson`, and drain the **10** stranded
   `refs/nightly-pending/` refs (oldest `2026-08-03`). Effort: **M**. Impact: removes the integration-conflict
   class that strands pending refs.
