## Friction points
- **MCP silent hangs burn 24% of lane-runs.** Sentry/Supabase MCP calls block without timeout. PostHog REST helper fixed one provider; two remain. A lane burns 900-1500s emitting zero bytes.
- **Heartbeat logging proposed 3 nights, unshipped.** Without it, MCP hangs are diagnosed post-mortem from timing alone. No visibility into which specific call blocks.
- **Lane 03 needs funnel data but MCP hangs fetching it.** When it ships, output is high-value (funnel cliffs, experiment proposals). Pre-fetch via REST would decouple from MCP.
- **Telegram feedback near-zero.** 6 total taps in 5 nights (5 smoke). Self-critique trigger never fired. Either digests aren't being read, or button UX isn't compelling.
- **Admin sessions pollute perf baselines.** `/he/daily` CLS 0.882 and `/ja` LCP 8775ms are admin-only. Lane 02 wastes time triaging false regressions.
