  fixed the set's one real error (`RunPageClient.tsx` TS2322, resolved by `CardPickScreen.tsx` in the same

## Friction points
- **The gate's oracle is poisoned every night by one gitignored file.** 75 `TS2307` lines across 7 logs,
  all `@/lib/i18n/messagesManifest.json`, failing a file no lane authored → `unattributable gate failure`
  → `docs-only salvage`. `rg -c 'build:i18n' scripts/nightly/lib/gate-isolated.sh` → no match. Affects
  **all lanes, 7/7 nights.**
- **The salvage prints success before it has a commit.** 11-06 logged "shipping (16 docs)" at 04:55:59;
  `git log --all --grep="improvement loop 2026-11-06"` is empty and the docs are uncommitted in the tree.
  Every reader of that log — including this lane for a full window — believed the floor held.
- **~70 min/night of bisect burns to a foregone conclusion.** 3–8 of 21–77 planned calls at ~580–700s
  each; the budget is 3600s and the need is ~12h. It has never once reached a verdict.
- **The lane-attribution lines are unusable as stats.** `kept N authored file(s)` is a total, not a code
  count, and `lane N` is positional over a nightly-varying selected set.
- **The checkout the lanes run in was 20 commits behind `origin/master`** at lane time tonight, and 9
  `refs/nightly-pending/` refs (3 from August, 6 new from 10-28..11-02) fail `cherry-pick/push` on every

## Concrete improvements (ranked by impact × effort)
1. **Run `build:i18n` in the gate's typecheck chain** — one `cp` from the 10-23 backup restores it.
   Effort: S. Impact: unblocks the gate oracle; it is the sole cause of all 7 drops and 35 zero-code days.
   File: `scripts/nightly/lib/gate-isolated.sh`. Command verbatim in learnings Headline 1.
2. **Keep `scripts/nightly/**` in the docs-only salvage set** — same gate-neutral rationale as `docs/`
   (both sit outside `fe-next/`, so neither can change the app's lint/type/test/build verdict). Effort: S.
   Impact: the loop becomes able to ship its own repair; without it #1 is lost again on the night it lands.
   File: `scripts/nightly/run.sh` (~:1179, beside the `docs-only` keep logic).
3. **Make the salvage assert its own commit, and make a zero-code ship a loud ERROR.** After the salvage
   commit, `git rev-parse` the SHA; if absent, print `SALVAGE COMMIT FAILED` and send it in the Telegram
   card. In the same card, when `authored CODE files > 0 && committed code files == 0`, print ERROR with
   the dropped-path list and the salvage stamp. Effort: S. Impact: ends the class where a log line stands
   in for a result — 11-06 and five prior dropped nights all read as good runs. File: `scripts/nightly/run.sh`.
4. **Replace the global peel with per-lane gate calls (8, not 2N−7), and enforce `file-cap=8` on the keep
   path.** Budget sized to 8 × per-call. Effort: M. Impact: one lane's 35 files stops discarding seven
   other lanes' clean work; the bisect gets a verdict inside budget instead of 0/7. Files:
   `scripts/nightly/run.sh`, `scripts/nightly/lib/gate-isolated.sh`. Do after #1 — a poisoned oracle fails
   per-lane calls too.
5. **`git fetch origin` + fast-forward check immediately before the salvage commit, and add
   `.gitattributes` with `merge=union`** for `impact-ledger.ndjson`, `mode-readiness.md`,
   `perf-baseline.json`. Effort: M. Impact: clears 9 stranded `refs/nightly-pending/` refs whose
   auto-recovery has failed on every run for ~95 nights, and stops a 20-commit-stale checkout from
   producing a commit that cannot push. Files: `.gitattributes` (new), `scripts/nightly/run.sh` preflight.
6. **Print `lane=<name> kept=<n> code=<n>` instead of `lane N — kept M authored file(s)`, and un-ignore
   `docs/nightly/reports/`** (`.gitignore:82`). Effort: S. Impact: makes per-lane attribution real and
   stops telling lanes that a gitignored file is their report of record. Files: `scripts/nightly/run.sh`,
   `.gitignore`.
7. **Tell every lane that a 0-count on tonight's log is not a result.** One line in the shared preamble:
   lane 07 runs ~02:10, the gate ~03:30 — only count errors in a log whose run reached its gate. Effort: S.
   Impact: removes the false-green class that cost this lane most of a window. File: this learnings preamble (done).

  reached its gate (so an in-flight log is never read as clean). Kills avoid-#5 and avoid-#5-prior
  (prose-grep false negative) mechanically. Called from the lane-07 prompt. Effort: S.
