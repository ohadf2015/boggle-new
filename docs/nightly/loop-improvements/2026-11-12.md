## What's working well
- **Lane execution is a solved problem.** 20 consecutive nights with no `exit 124`, no idle-kill, every
  selected lane `rc=0`. Zero remaining value in tuning lane prompts for *reliability*.
- **The mandatory-artifact floor is the loop's only reliable output.** 8/8 artifacts on 11-11, all 8
  committed in `0ee614272`. It converted "a timed-out lane ships nothing" into "a timed-out lane ships
  its findings". Keep it as every lane's first action.
- **The file-volume clamp worked and is now proven irrelevant.** Totals halved (50 → 16/27/20/23) and the
  gate failed identically. Useful discipline, wrong theory.
- **The circuit breaker made the right call on 11-09** — one `rc=76` stopped the run instead of burning 8
  identical failures. Only its reporting is broken.
- **The pre-drop-all typecheck tier is sound** — it refuses to discard build-clean code on an undecidable
  red. It is the guard that recorded the evidence in #1 below.

## Friction points
- **The gate's verdict is not about lane code at all (all lanes).** 11-11 ran `gating 1 authored file(s)`
  → `FAIL` **six times on six different single files**. `HEAD + 1 file` is red, so the oracle is broken and
  the bisect is mathematically forced to `drop-all`. 11-07's `NO PASSING SUBSET — all 6 units failed` was
  the same signal. This has cost **40 consecutive days of zero code**.
- **One gitignored module causes it (all lanes).** 11 identical TS2307 lines on 11-11, 54 across 5 gated
  logs: `app/[locale]/layout.tsx(4,31): Cannot find module '@/lib/i18n/messagesManifest.json'`.
- **The loop cannot ship its own repair (lane 07).** `rg -n 'scripts/nightly' scripts/nightly/run.sh`
  returns only `_restore_cmd` strings — no keep-set entry — so lane 7 can only emit patches, never edits.
- **The bisect is the single most expensive step and buys nothing** — ~115m/night, 6–7 of 21–63 calls at
  ~600–700s each, over-budget 5/5 nights, always ending in `GAVE UP → docs-only drop-all`.
- **A zero-code night is indistinguishable from a healthy docs night** in the Telegram card (`residual
  ship OK`, `nightly-loop complete`), and 11-09's spend-cap abort printed exactly the same lines.
- **Real lane bugs are invisible under the noise (lane 03/05).** 11-11's set had 6 genuine errors, all one
  class: a new identifier added at one site only (experiment id, `GrowthEvent`, component prop). Nobody can
  see them while the baseline is red.

## Concrete improvements (ranked by impact × effort)
1. **Delta-gating against a baseline probe** — gate the **empty** authored set (just the clean HEAD
   checkout) as the gate's first call and record its error set. Then gate the authored set and
   **subtract the baseline errors. Ship iff the delta is empty.** If the baseline is red at all, also
   emit `GATE INOPERABLE: baseline red (<n> pre-existing errors)` + a Telegram alert naming them and
   **skip the bisect** — but judge the delta, never skip judgment. On 11-11 this yields exactly the right
   answer: 11 TS2307 subtracted as baseline, the 6 Word Tower errors remain in the delta → lane code
   correctly rejected, bisect correctly skipped, ~115m saved, alert names the real cause. (Do **not**
   "ship unjudged" on a red baseline — 11-11's authored set would have pushed a non-compiling tree.)
   Effort: S. Impact: unblocks the 40-day zero-code streak on any night whose delta is clean, *and*
   saves ~115m/night of pointless peel. File: `scripts/nightly/lib/gate-isolated.sh` + `run.sh` (~:1179).
2. **`npm run build:i18n` in the gate's typecheck chain** — the one-line cause of the red baseline.
   Restore the already-correct file: `cp ~/logs/lexi-nightly/salvaged-code-20261023-010005/scripts/nightly/lib/gate-isolated.sh scripts/nightly/lib/gate-isolated.sh`
   (`build:i18n` = `tsx scripts/build-i18n-assets.ts`, `fe-next/package.json:15`). Effort: S (one `cp`).
   Impact: removes 54 TS2307 lines; metric = `rg -Nc TS2307 <tonight's log>` goes 11 → 0.
   **Carried 6 windows. FOUNDER ACTION.** File: `scripts/nightly/lib/gate-isolated.sh`.
3. **Add `scripts/nightly` to the salvage keep-set** — same rationale as `docs/`: outside `fe-next/`, so
   it cannot change the app's lint/type/test/build verdict. Without it the loop can never fix itself.
   Effort: S. Impact: #1 and #4 become shippable by lane 7 instead of by hand. File: `scripts/nightly/run.sh` (~:1179).
4. **Make a zero-code ship and a spend-cap abort LOUD** — when `authored CODE files > 0 && committed code
   files == 0`, the Telegram card says `ERROR` with the dropped paths + salvage stamp; on `rc=76` write
   `docs/nightly/artifacts/run-aborted-<date>.md` and a card that says SPEND CAP, not `complete`. Also
   print the created SHA and fail when `git rev-parse` finds none (11-06 and 11-07 printed the salvage
   line and created no commit). Effort: S. Impact: the 40-day streak would have been visible on night 2.
   File: `scripts/nightly/run.sh`.
5. **Print `lane=<name> kept=<n> code=<n>`** instead of `lane N — kept M authored file(s)` (positional
   index over a nightly-varying set, so every attribution in 7 windows of reports is suspect). Effort: S.
   Impact: the skills table in learnings.md becomes fact instead of best-effort. File: `scripts/nightly/run.sh`.
6. **Make `artifacts/` the sole report contract** — `docs/nightly/reports/` is gitignored (`.gitignore:82`),
   so every lane's STEP-6 `### Lane N` append is discarded while its artifact ships. Either un-ignore
   `reports/` or drop STEP 6 from all lane prompts and fold its fields into the artifact. Effort: S.
   Impact: removes a step 10 lanes perform nightly for nothing. Files: `.gitignore`, all lane prompts.
7. **Three-site rule in every code lane's prompt** — "a new experiment id needs the union in
   `lib/experiments.ts`; a new event needs the `GrowthEvent` union; a new prop needs the props interface
   AND every call site. `npx eslint` type-checks nothing." Effort: S. Impact: removes the 6 real TS errors
   11-11 authored — the work that matters once #1/#2 land. Files: lane 03/05/09/11 prompts.
