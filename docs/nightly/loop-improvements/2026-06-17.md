## Concrete improvements (ranked by impact × effort)
1. **Scope gate tests to changed-cone.** Replace the gate's full `npm run test` with `vitest related $(git diff --name-only <base>)` (or the project's `test:changed`). Effort: M. Impact: converts ~5/6 docs-only salvage nights into real code-ship; directly recovers the loop's #1 loss. File(s): `scripts/nightly/run.sh` (gate step) + the 4 chronic-red suites get quarantined via `test.skip` w/ a tracking comment.
2. **Replace blind-retry push recovery with inspect-or-drop.** When cherry-pick of `refs/nightly-pending/<date>` fails, stop retrying: emit a one-line "STRANDED PUSH NEEDS HUMAN: <ref> <conflict files>" to the digest and move the ref to `refs/nightly-stranded/<date>` so it stops re-firing nightly. Effort: S. Impact: kills 4-night repeat noise + gives user a clear action. File(s): `scripts/nightly/run.sh` push-recovery block.
3. **Single machine-readable handoff queue.** New `docs/nightly/human-queue.md` (table: type | item | since | one-action). Lanes 01/03 append rows (Supabase migration / PostHog flag) instead of burying in prose. Lane 07 prunes cleared rows. Effort: S. Impact: collapses 2 recurring human-blocked seams into one glanceable file; should shrink flag latency from 7+ nights. File(s): new doc + 1 line in lane 01/03 prompts.
4. **Lane 05 hard scope guard in prompt.** Add explicit STEP-0 rule: "Pick ONE polish. Write all 5 locale strings FIRST. If page-wiring won't fit the budget, ship the hook + tests and defer wiring — never start wiring you can't finish." Effort: S. Impact: turns 2 partials/week into clean ships. File(s): lane 05 prompt.

Either move it to first-half of the run order or give it a hard `LEXI_LANE_BUDGET_S` cap. Effort: S. Impact: frees budget for the gate to finish. File(s): `scripts/nightly/run.sh` lane ordering.
