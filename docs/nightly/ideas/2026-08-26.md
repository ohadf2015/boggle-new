# Competitor + viral concepts — 2026-08-26

## Concepts worth borrowing

- **"13 Words" — full-hand-upfront pacing + mid-game surprise reveal** — source: https://www.reddit.com/r/wordgames/comments/1vv2j6m/im_a_game_designer_and_just_created_13_words_a/
  - Solo dev Scrabble-style game: you're dealt all your tiles at the start (40 of 80 in the game), 13 fixed turns, and a hidden "Magic Word" is revealed once 20 tiles have been played — forces players to plan pacing instead of playing turn-by-turn.
  - Works because it turns a static resource (your tiles) into a timing decision, and the mid-run reveal creates a spike of attention right when engagement would otherwise dip.
  - Fits LexiClash: word-craft (`?mode=cards`) already deals a hand up front — add a hidden bonus card that flips face-up mid-run once a play-count threshold is hit. New mechanic family (not the existing dice-bonus pitch from 07-09).
  - Effort: S (session-state flag + one reveal animation, no economy change).
  - Risk: low — cosmetic/pacing only, no reward-value change.

- **Gimkit/Blooket — async "assignment" mode for classrooms** — source: WebSearch (triviamaker.com/blooket-vs-gimkit-vs-kahoot, learnclash.com/blog/blooket-vs-gimkit)
  - Both platforms let a teacher assign a question set for students to complete on their own schedule (not live-only), then the teacher sees a completion dashboard. Gimkit adds a light in-game economy (currency → power-ups) on top of correct answers.
  - Works because it removes the "everyone must be online at once" friction that kills classroom game-based tools, and gives teachers a low-effort proof-of-engagement artifact.
  - Fits LexiClash education growth goal directly: `/teacher` dashboard already creates classrooms (see memory: creation flow is healthy, discovery/activation was the bug). An async "assign a word-list drill, see who finished" view is a acquisition/retention lever distinct from live multiplayer classroom games — worth a product discussion, not a code pitch tonight (out of scope for admin-beta-mode rotation).
  - Effort: L (new teacher-facing surface).
  - Risk: scope — flag for founder/product, not a nightly-lane build target.

- **Petalgrams — pangram-centric daily, explicit NYT Spelling Bee positioning** — source: https://www.reddit.com/r/wordgames/comments/1vtn7hu/petalgrams_a_pangramcentric_daily_word_game_for/
  - A solo-dev daily built specifically "for fans of NYT Spelling Bee" — leans on an existing audience's vocabulary instead of inventing a new one.
  - Works because it borrows a proven daily-habit audience rather than competing for attention from scratch.
  - Fits LexiClash: the education module already has `/education/spelling-bee-practice` — competitor positioning language ("for Spelling Bee fans") is a directly reusable SEO/acquisition angle for that page's copy (content lane, not a code change tonight).
  - Effort: S (copy only, different lane).
  - Risk: none.

- **Beyond Words — Scrabble + roguelike run structure (shipped indie title, April 2026)** — source: WebSearch (Wikipedia)
  - Full roguelike meta over a word game: runs, permadeck-style upgrades, released on Switch/PS5/Xbox/Windows. Reviews praised the gameplay loop, criticized the (AI-assisted) art.
  - Confirms the "word game + roguelike run structure" pairing has commercial traction beyond just our own word-craft-run mode — validates the mode's core premise, no new mechanic to lift (our mode already covers this shape).
  - Effort: n/a (validation signal, not a pitch).
  - Risk: n/a.

## What other word-game sites do well
- CrazyGames' word-game category page leans hard on genre-recognizable names in titles ("Word Wipe" = Boggle-alike, "Wordmeister" = Scrabble-alike) — every listed game signals its mechanic in the name itself, which reduces the click-to-understand gap on a browse page. Our own mode names (Blast, Word Tower, Wheel Rush) don't do this — a landing-page/SEO consideration, not a code change.
