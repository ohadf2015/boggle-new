# Competitor + viral concepts — 2026-08-08

## Concepts worth borrowing
- **Kahoot "Accuracy Mode"** — source: search results (triviamaker.com/gimkit-alternatives, 2026)
  - Kahoot shipped a mode that drops the speed timer entirely — correctness decides the score, not reflex.
  - Works because it removes anxiety for slower/ESL readers while keeping the game live-competitive; teachers cite it as the fix for "fast kids always win."
  - Fit: education module + classroom mode of Word Craft (gems/cards). A teacher-facing toggle "accuracy mode" (no per-answer clock) would directly serve the ESL/classroom audience the education hub targets.
  - Effort: S (client-side timer gate + one teacher-dashboard toggle)
  - Risk: none — additive toggle, doesn't touch existing scoring math (hard line: never touch coin/score economy — this only disables the OPTIONAL time bonus, doesn't invent new reward values)

- **Gimkit "correct answer → resource/upgrade choice"** — source: triviamaker.com/blooket-vs-gimkit-vs-kahoot (2026)
  - Correct answers convert into an in-game currency the player then spends on a small upgrade CHOICE (not auto-applied) — turns quiz correctness into a strategic decision point.
  - Emotional hook: agency. Getting the answer right isn't the end of the loop, it's the START of a mini-decision.
  - Fit: Word Craft gems mode already has a resource (gems) — the missing piece is spending it on a CHOICE mid-run rather than a fixed shop. Matches admin-beta polish target already flagged for lane 05.
  - Effort: M
  - Risk: low — purely client-side run-state, no economy value change

- **Blooket "Gold Quest" reward-roll on correct answer** — source: triviamaker.com/gimkit-alternatives (2026)
  - Correct answer triggers a randomized reward roll (small/med/large) instead of a fixed point value — classic variable-reward.
  - Fit: word-craft gems/cards mode's per-word reward could roll a small multiplier band instead of a flat gem count PER-RUN (not touching the underlying coin economy, purely a run-scoped cosmetic/gem-count variance).
  - Effort: S
  - Risk: MED if it touches actual coin economy — must stay scoped to run-local gems only, never persisted currency. Flag for founder review before shipping if unclear.

- **"Beyond Words" (MindFuel Games, PQube, released 2026-04-09)** — source: WebSearch/Wikipedia
  - Scrabble-based roguelike: build a word-tile "deck" across runs, mixed/average reviews, art (partly AI-generated) drew criticism.
  - Lesson, not a mechanic to copy: reviewers praised the roguelike-word-deck loop itself but penalized AI-generated art hard. Confirms word-craft's card-run direction is the right genre bet; reinforces we should NOT lean on obviously-AI art for any admin-beta mode about to graduate.
  - Effort: N/A (learning only)
  - Risk: N/A

## What other word-game sites do well
- Kahoot/Blooket/Gimkit (classroom space): all three ship an explicit **teacher-facing mode toggle** (speed vs accuracy, solo vs team) rather than one fixed ruleset — the toggle itself is the retention lever for the education audience, not new content.
