# Competitor + viral concepts — 2026-10-18

## Concepts worth borrowing

- **WordCast (Discord) / SpellFast (Steam)** — spiritual successors to Discord's shut-down SpellCast
  - what it does: turn-based PvP boggle-like 1-4 players; players spend an in-match coin currency to buy one-shot abilities — change a tile's letter, swap two adjacent tiles, shuffle the whole board.
  - why it works: a pure word-search grid has one lever (find more words). Spending a scarce currency mid-round to reshape the board adds a tactical decision layer and a reason to keep an eye on your coin total — variable-reward, not just skill.
  - fit for LexiClash: no direct Sealed Bid analog survives (that mode was removed — verified via `rg -l SealedBid` returning nothing in `fe-next/app` + `fe-next/components`, and memory confirms "Sealed Bid removed" 2026-10-08). The mechanic maps cleanly onto **Wheel Rush** instead — give the wheel-spin currency a mid-round spend option (reroll one bad letter / peek the next spin) rather than pure RNG consumption. See game-mode-idea block in the report for the concrete slice.
  - effort: M (new currency + 1 UI control + server-side spend validation)
  - risk: must not touch coin economy values (hard line) — spend a NEW cosmetic/round-local token, not real coins.

- **Beyond Words** (MindFuel Games, released April 2026) — Scrabble + roguelike run-based deckbuilding on Switch/PS5/Xbox/PC
  - what it does: build a run of word-scoring power-ups across escalating boards, roguelike-style.
  - why it works: validates the exact direction Word Craft — Run already took (power-card draft, shipped 2026-10-17). Mixed/average reviews on PC, generally favorable on Switch; the AI-art criticism is the one risk signal worth noting if we ever generate card art with AI.
  - fit: no new work — this is confirmation lane 05's current Word Craft Run bet is on-trend. Don't re-pitch the same mechanic.
  - effort: — (reference only)
  - risk: AI-generated art drew specific negative feedback in reviews — keep human-made/hand-tuned art for any card-based mode.

- **Spinonym** (new indie, r/wordgames this week) — daily word puzzle where you spin hexagon dials to line up letters instead of typing them
  - what it does: same "same puzzle for everyone" daily format as Wordle, but the INPUT is a spin-dial instead of a keyboard, and it shows you vs the daily average move-count.
  - why it works: differentiates a saturated daily-puzzle space purely through input feel, and the "vs daily average" comparator gives weaker players a non-leaderboard way to feel good.
  - fit for LexiClash: a light idea for Daily Challenge's result screen — add "vs today's average" alongside the existing rank, cheap social-proof framing that doesn't require a new input mechanic.
  - effort: S (one stat line, data already collected server-side for daily results)
  - risk: none — purely additive framing.

## Education competitor — Gimkit / Blooket (standing founder priority)

- **Gimkit's KitCollab** lets students submit their own quiz questions into a shared "kit" the teacher then runs live — collaborative content creation, not just teacher-authored content.
- **Blooket × Khanmigo (Khan Academy) AI question-generator partnership** — teachers paste source material and get an AI-generated question set instantly, cutting classroom-game setup time to near zero.
- Why this matters for LexiClash: memory's teacher-activation root-cause finding (2026-10-16) says the #1 blocker is teachers never getting past class creation (50/71 never made a class; 46 never returned). An AI-assisted "paste your spelling list / topic → auto-build a word set" wizard at the first HQ screen directly attacks that setup-friction root cause, the same lever Blooket just shipped.
- Effort: L (new AI-generation endpoint + review step) — not a one-night slice, flag for lane 09/human queue, not lane 05.
- Risk: AI-generated word lists need a dictionary-validity check before a teacher can assign them (same class of bug as prior "AI fabricates non-English word lists" pitfall).

## What other word-game sites do well
- r/wordgames this week is almost entirely solo indie-dev "I made X" showcases (ChainWhich, Triangulate, Five in Five, ShiftPuzzle) — no single breakout mechanic, but the volume confirms daily-word-puzzle is still the most crowded sub-genre to launch into. Reinforces: differentiate via feel/input (Spinonym) or classroom distribution (education), not via "another Wordle clone."
