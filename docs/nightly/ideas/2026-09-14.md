# Competitor + viral concepts — 2026-09-14

## Concepts worth borrowing
- **Beyond Words (Scrabble-roguelike, PQube/MindFuel, Apr 2026)** — source: https://en.wikipedia.org/wiki/Beyond_Words_(video_game)
  - Scrabble base rules + roguelike run structure: escalating boards, card-style power-ups drafted between rounds.
  - Works because each run feels different (variable-reward via power-up draft) while the core word-forming skill stays familiar — low relearn cost, high replay variety.
  - Fit: word-craft's `?mode=cards` submode already has a card idiom — add a between-round power-up DRAFT (pick 1 of 3) instead of a fixed upgrade path.
  - Effort: M. Risk: none (not Wordle-adjacent, no trademark exposure).

- **Blooket/Gimkit multi-mode vocabulary wrapper** — source: https://classroomreview.games/top-10-games-like-blooket/, https://spellingjoy.com/best-apps/gimkit-alternatives
  - Same imported word/vocab list, replayed through different game "skins" (tower defense, racing, gold quest) so repeated drilling doesn't feel repetitive.
  - Works because the teacher does ONE import, students get variety for free — the variety is in the WRAPPER, not new content.
  - Fit: education module — teacher word-lists already feed the classroom game; a "play this list as a different mode" picker on the student dashboard would reuse existing content across brain-drill / wheel-rush without a content-authoring cost.
  - Effort: M (UI picker + list-plumbing into a second mode's session start).
  - Risk: low — no gameplay change, just cross-wiring an existing list into an existing mode's entry point.

- **Word Club (Scripps Spelling Bee) 5 spelling + 3 vocab modes bundle** — source: https://spellingbee.com/word-club
  - Official spelling-bee brand bundles multiple short mode variants under one word list so a kid doesn't get bored of one drill type.
  - Fit: same "one list, many replay shapes" pattern as Blooket above — reinforces it's a proven education-market pattern, not a one-off.
  - Effort: S (evidence only, folds into the Blooket idea above).
