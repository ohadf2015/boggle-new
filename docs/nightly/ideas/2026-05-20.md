## Concepts worth borrowing

### 1. Ghost Hint Mode (deception tile)
- **Source:** Fibble (https://fibble.xyz) — "one lie per row" variant of Wordle; also Absurdle (adversarial target-switching)
- **What it does:** Fibble gives accurate color feedback except for one randomly chosen tile per guess row — that tile's color is inverted. Players know a lie exists but not where. Absurdle goes further and changes the target word when you close in.
- **Why it works:** Breaks the Pavlovian "green = done" loop. Players talk about it because they're angry and confused in a fun way. The paranoia is social — "wait, do you trust that yellow?" It's the same reason poker beats solitaire.
- **How it fits LexiClash:** WheelRush or a dedicated daily challenge variant: one letter's "found!" glow per round is a Ghost (false positive). Could also work as an admin-gated "Liar's Round" multiplayer mode where both players get the same ghost placement — leveling the field and adding read-the-opponent meta. No new game mode architecture needed, just a flag + UI tell ("ghost letters exist this round").
- **Effort:** S–M (flag in scoring logic + UI indicator that ghosts are active, no new layout)
- **Risk:** Low. Casual players need the "ghosts active" banner to be unmissable or they'll think the game is broken. Not a trademark risk.

### 2. Battle Royale word survival (Squabble mechanic)
- **Source:** Squabble (https://squabble.me) — real-time Battle Royale Wordle, 2–99 players
- **What it does:** Everyone solves the same word simultaneously. Wrong guesses cost HP. Die before solving = eliminated. Last survivor wins. Lobby fills in 30 seconds, full round is 3–5 min.
- **Why it works:** Transforms a solitary puzzle into a live event with stakes. Watching someone's HP bar drain while yours is full is a genuinely different emotional register than leaderboard scores. It creates "one more round" pull because rounds are short and the tension is high.
- **How it fits LexiClash:** LexiClash already has real-time MP rooms — this would be a "Survival Room" variant of WheelRush: shared letter wheel, found words = shield points, time running out = HP drain. The last player standing wins the pot. Fits the existing room-based MP architecture without a full rewrite. The hub tile would be admin-only (per learnings.md experimental gate rule).
- **Effort:** M (HP + elimination system on top of existing room logic; needs spectator state for eliminated players)
- **Risk:** Medium. Squabble is free and popular in the exact overlap audience. Differentiation must come from the wheel + multiplayer language-mixing angle, which Squabble doesn't have.

### 3. Themed daily challenge week
- **Source:** Grid Genius AI crossword (https://gridgenius.app) — AI-generates crosswords on any topic. Also player behavior signal: Grid Genius blog notes players combine 10–20 min of multiple games daily rather than going deep on one.
- **What it does:** Grid Genius lets players pick "generate a crossword about chemistry" or "Star Wars." Personalization trades shared social proof (everyone solving the same puzzle) for personal relevance. Their blog confirms the "daily rotation of 3–4 short games" is now a standard casual play session.
- **Why it works:** Theme weeks give returning players a reason to come back even if they're bored of the core loop. "Food Week" where every daily word set is culinary terms is cheap to produce and creates collector behavior ("I want to complete the full food week streak").
- **How it fits LexiClash:** Admin-curated word lists by theme (no AI needed). The daily challenge word pool for a given week draws only from that theme's list. A small "🍕 Food Week" banner on the daily card is the only UI change. Themes rotate weekly. Works across all 5 locales if the word lists are pre-translated — or falls back to EN word set with a translation flag.
- **Effort:** S (admin panel for theme tag on word lists + banner string + 5 locale word pool curation per theme)
- **Risk:** Very low. Content moderation: themed word lists need a manual pass (e.g. "body words" theme could sneak vulgar terms).

### 4. Warm/cold semantic scoring (Semantle mechanic)
- **Source:** Semantle (https://semantle.com) — guesses scored by Word2Vec cosine similarity to answer, not letter position
- **What it does:** Instead of "right letter, wrong position," every guess returns a score from 1–1000 based on how semantically close the word is to the answer. Players describe paths like "ocean → wave → surf → beach → sand → dune" closing in by association. No letter feedback at all.
- **Why it works:** Completely different cognitive mode — vocabulary depth and semantic intuition replace spelling/pattern skills. Extremely high shareability: "I had 47 guesses and my closest was 'thunderstorm' — answer was 'lightning'" is a natural story. Also accessible across skill levels because vocabulary width matters more than English spelling tricks.
- **How it fits LexiClash:** A "Word Drift" daily mode — guess the hidden word via semantic proximity. Distinct from all current modes. Has a real multilingual angle: semantic models exist for EN/ES/SV (quality good), HE (quality acceptable), JA (decent for nouns). Would need a small embedding API call per guess. Could run as a solo daily alongside the existing daily challenge.
- **Effort:** L (embedding model integration, latency budget for guess scoring, HE/JA model evaluation, new UI for proximity meter)
- **Risk:** Medium-high. Hebrew semantic model is sparse for modern slang; JA tokenization is nontrivial. Backend cost per guess needs profiling. Shelve until engagement metrics justify the infra spend.

## What other word-game sites do well

- **Poki:** "Click and play in 2 seconds" — zero friction is their actual product. No account, no modal, no tutorial wall. LexiClash's CG modal blocking 19/20 portal users (per PostHog memory) is the same anti-pattern.
- **CrazyGames:** Genre fusion works (Word Wipe = Boggle + sliding puzzle). Pure-genre titles lose to hybrids on portals because hybrid = broader search surface.
- **Nanagrams.io:** Real-time Bananagrams for 1–8 players, browser, no login. The only credible real-time word race competitor outside LexiClash. Their weakness: English only, no daily challenge, no streak.
- **GridGenius:** The "personalized AI puzzle" angle gets press coverage from tech-adjacent publications (not just gaming outlets). Worth watching for their SEO moat.
