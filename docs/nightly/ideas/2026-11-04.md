# Competitor + viral concepts — 2026-11-04

## Concepts worth borrowing
- **Chain-clear cascade scoring** — source: https://www.reddit.com/r/wordgames/comments/1xm8cjf/i_made_a_word_game_where_clearing_a_word_makes/
  - clearing one word drops letters into a new arrangement that can immediately form another word — a visible chain reaction.
  - works because each clear teases the next, turning one move into a combo streak (same dopamine loop as match-3 cascades).
  - fits word-craft: a consecutive-clear combo multiplier (see Top game-mode improvement idea below) — distinct from the already-pitched steal-pile (shared resource) and sound-sort (category mini-game) mechanics.
  - effort: S
  - risk: none — pure UI/scoring layer, no new content needed.

- **"App vs web browser" preference thread** — source: https://www.reddit.com/r/wordgames/comments/1xizpkh/app_vs_web_browser/
  - a dev asking players whether they prefer an installed app or a browser link for daily word games.
  - signal, not a mechanic: several top replies in-thread lean "browser, no install friction" — matches LexiClash's web-first positioning already.
  - action: no build needed, just confirms current strategy; worth a line in SEO/landing copy ("play instantly, no app store, no account").
  - effort: — (positioning note only)
  - risk: none.

- **Quizlet Live / Wordwall-style classroom matching** — source: triviamaker.com/blooket-alternatives, zykostudy.com/blog/gimkit-alternatives (EDUCATION competitor sweep)
  - live team-matching rounds (term↔definition) plus free-forever teacher tier with no student login — the two things teachers cite most for adoption.
  - works because the teacher's only cost is a join code, and Blooket's free K-8 tier removes the "is this a trial" hesitation entirely.
  - fits LexiClash education module: memory already flags teacher-activation as the real bottleneck (50/71 teachers never make a class) — the acquisition tactic worth stealing isn't a new mechanic, it's making the "always free, students never sign in" promise as loud on `/education/for-schools` as Blooket makes it on its own landing page.
  - effort: S (copy/positioning, not code — no-code lane, logged for lane 05/09 to action)
  - risk: none.
