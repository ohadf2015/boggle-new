## Source-Code-Based Meta Audit (Oct 4 Scan)

### Root Cause Discovery: Previous fixes targeted wrong file

Previous daily PRs (#1213, #1216, Oct 2–3) fixed `dailySeo.data.ts` — but that file feeds **JSON-LD schema names** (structured data), not HTML `<title>` / `<meta name="description">`. The actual HTML meta tags for the `/[locale]/daily` page come from the **translations** (`fe-next/translations/*.js` → `seo.daily.title` / `seo.daily.description`), loaded via `loadTranslation()` in `daily/layout.tsx`.

The translation `seo.daily` fields were never audited until today.
