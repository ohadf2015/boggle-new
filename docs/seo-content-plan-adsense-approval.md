## 3. GOOGLE ADSENSE APPROVAL REQUIREMENTS

### AdSense Typical Concerns for Game Sites

1. **Thin Content** - Lack of original, unique text content
   - Game UI ≠ crawlable text
   - Ad-heavy pages without substantial content

2. **User Value Clarity** - Why should users visit?
   - Need clear value propositions
   - Educational or entertainment claim

3. **Content Depth** - Does content merit ad placement?
   - Minimum: 2,000-5,000 unique words per main page
   - Optimal: 5,000-10,000 words

4. **Authority (E-E-A-T)**
   - ✅ LexiClash has good author bios
   - ✅ Research citations in blog posts
   - ⚠️ Missing author expertise credentials
   - ⚠️ No "written by" schema on articles

5. **Keyword Targeting** - Does content target user search intent?
   - ✅ Blog posts target informational queries
   - ⚠️ Limited beginner/how-to content
   - ⚠️ No glossary of word game terms

## 7. IMPLEMENTATION STRATEGY

### Content Management
- **Folder Structure:**
  ```
  app/[locale]/guides/
    ├── beginners-guide/
    ├── glossary/
    ├── daily-challenge-strategy/
    └── [more guides...]
  ```

- **Reuse Blog Component:**
  - Leverage existing `PageClient.tsx` pattern
  - Create `content.ts` for each guide (localized)
  - Use same styling system (neo-brutalist)

- **Metadata & Schema:**
  - Add `BlogPosting` schema for new blog posts
  - Add `HowTo` schema for guides
  - Add `FAQPage` schema for glossary items
  - Ensure hreflang for all 5 languages

### SEO Best Practices to Implement

1. **Title Tags** (50-60 chars)
   - Example: "Beginner's Guide to LexiClash | How to Play"

2. **Meta Descriptions** (150-160 chars)
   - Example: "Learn how to play LexiClash with this comprehensive beginner's guide. Tips, strategies, and game modes explained."

3. **H1 Structure**
   - One H1 per page
   - Clear hierarchy (H1 → H2 → H3)

4. **Internal Linking**
   - Each guide links to related blog posts
   - Blog posts link to guides
   - All game modes link to rules/guides
   - Anchor text: descriptive, keyword-rich

5. **Image Optimization**
   - Add alt text to all screenshots
   - Use descriptive filenames
   - Compress to <200KB (WebP format)
   - Example alt: "LexiClash daily challenge interface showing 3x3 letter grid and timer"

6. **Readability Signals**
   - Subheadings every 100-150 words
   - Short paragraphs (2-3 sentences)
   - Bullet points for lists
   - Code/schema snippets in separate blocks
