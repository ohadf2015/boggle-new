## P0 Epics (ship first)

### E1. Multi-server rate limit gap (B225)
`backend/utils/rateLimiter.ts` sync API = in-memory only. Horizontal scale = each pod independent counter. DDoS shield ineffective past pod #1.
**Fix:** Promote async/Redis path to default. Deprecate sync. Lua script for atomic incr+expire.

### E2. Schema source duplication (B229, B222)
`socketValidation.ts` falls back to `require('../dist/...')` at runtime. Duel `types.ts` DuelClientEvents diverges from lifecycle/realtime runtime Zod schemas.
**Fix:** Single schema source. Generate TS types from Zod via `z.infer<>`. Delete compiled-fallback branch.

### E3. Module-level singleton state (B247, B250, multiple)
`requestCoalescing.ts`, `gameStartCoordinator.ts`, `apiRateLimiter.ts`, `timerManager.ts` = module-load singletons. SSR crash, HMR leak, test pollution, no multi-server share.
**Fix:** Factory pattern + DI. Unified `shutdownAll()` on SIGTERM.

### E4. Feature flag DB hammer (B267)
`canAccessFeature` = 1-2 Supabase roundtrips per call, no cache. Hot path on every gated render.
**Fix:** In-memory TTL cache 60s, keyed `flagName+userId`. Invalidate on write.

### E5. Daily-challenge RMW race
Frontend reads streak → increments → writes. Two tabs = one streak lost.
**Fix:** Supabase RPC with atomic `UPDATE ... RETURNING`.

### E6. DoS: duel:submit-score
`handlers/duel/lifecycle.ts submitScore` validates up to 500 words sequentially against dictionary. No per-socket bound on concurrent submits.
**Fix:** Cap batch, background validate, reject oversize early.

### E7. i18n leaks (60+ sites, B263 canonical)
Handlers emit English literals as `error.message`. `errorHandler.ts` legacy branch permits raw strings.
**Fix:** Force `ErrorCodes` enum path. Client maps code → `t(key)`. Delete legacy string branch.

### E8. File size breaches
`backend/handlers/gameLifecycleHandler.ts` 679L · `hooks/useMultiplayerSocket.ts` 603L. Both > 500L rule in `CLAUDE.md`.
**Fix:** Split by phase (pre-game / in-game / post-game) or by concern (connection / state / events).

### E9. globalThis escape hatches in prod
`timerManager` `__clearAllGameTimers`, `socketHelpers` `_resetBroadcastThrottle`, plus one more. Test-only but shipped.
**Fix:** Guard `if (process.env.NODE_ENV === 'test')` or strip via build.
