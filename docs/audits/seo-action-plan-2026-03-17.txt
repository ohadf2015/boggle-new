Task 2.1: Localize Font Preloading
Priority: HIGH | Time: 45 min | Impact: +50-100ms LCP improvement

Current issue: All users preload both Hebrew AND Latin fonts (60-80KB waste)
Solution: Load only relevant fonts per locale

File: /app/[locale]/layout.tsx line 21-22

Change imports from:
```
import { fredoka, rubik } from '../fonts';
```

To:
```
import {
  fredokaLatin, fredokaHebrew,
  rubikLatin, rubikHebrew
} from '../fonts';
```

Then in LocaleLayout function:
```
const selectedFredoka = validLocale === 'he' ? fredokaHebrew : fredokaLatin;
const selectedRubik = validLocale === 'he' ? rubikHebrew : rubikLatin;

return (
  <html
    className={`dark ${selectedFredoka.variable || ''} ${selectedRubik.variable || ''}`}
    ...
  >
```

Expected savings:
- Hebrew pages: Save 60-80KB Latin fonts
- Latin pages: Save 60-80KB Hebrew fonts
- LCP improvement: 50-100ms

Task 3.2: Expand Breadcrumb Schema to All Deep Pages
Priority: MEDIUM | Time: 60 min

Current: Only home page has breadcrumb (1 item)
Target: All pages with parents have breadcrumbs

Pages to add breadcrumbs:
- /blog/[article] → Home > Blog > Article Title
- /guides/[slug] → Home > Guides > Guide Name
- /tools/word-solver → Home > Tools > Word Solver
- /faq → Home > FAQ
- /legal/[page] → Home > Legal > Page Name

Create helper file: /components/seo/generateBreadcrumbSchema.ts

Function:
```typescript
export function generateBreadcrumbSchema(items: { name: string; url: string }[]) {
  return {
    '@context': 'https://schema.org',
    '@type': 'BreadcrumbList',
    itemListElement: items.map((item, idx) => ({
      '@type': 'ListItem',
      position: idx + 1,
      name: item.name,
      item: item.url,
    })),
  };
}
```
