**BUGF-02 fix — Prism→Lightning chain (lines 686-716):**
In the prism cross-clear loops (both row and column), after clearing a tile, add a lightning check:
```
if (target.type === 'lightning') {
  // Trigger lightning's column-clear inline
  for (let lr = 0; lr < gridSize; lr++) {
    if (lr === target.row) continue;  // skip self (for row-clear hit)
    // or: if (lr === r) continue;  // for column-clear hit
    const ltarget = next[lr][target.col];  // lightning always clears its own column
    if (ltarget.isCleared) continue;
    if (isMultiHitAlive(ltarget)) {
      hitMultiHitTile(ltarget);
    } else {
      markCleared(ltarget);
      if (ltarget.type === 'bomb' && !processedBombs.has(`${lr},${target.col}`)) {
        processedBombs.add(`${lr},${target.col}`);
        bombQueue.push({ row: lr, col: target.col, depth: 0 });
      }
    }
  }
}
```
Use a `processedLightning` Set to avoid re-triggering the same lightning tile from both row and column sweeps.
