**BUGF-03 fix — Bomb double-BFS:**
In the combo switch cases (bomb_bomb, bomb_lightning, bomb_prism), after processing area clears, add the combo bomb positions to `processedBombs` set. This prevents the main path loop from re-queuing them:
```typescript
// After combo bomb_bomb processing:
for (const tile of combo.tiles) {
  if (tile.tileType === 'bomb') {
    processedBombs.add(`${tile.row},${tile.col}`);
  }
}
```
Apply same pattern to bomb_lightning and bomb_prism cases.

**BUGF-04 fix — Cascade word deduplication:**
In `handleCascadeComplete` (line ~299), change the word filter:
```typescript
// OLD: const foundSet = new Set(gameStateRef.current.wordsFound);
// NEW: Don't filter cascade words by previously found words.
// Cascade words should always score — they're new formations after gravity.
const foundSet = new Set<string>(); // Empty set = no dedup for cascades
```
Alternatively, if some dedup is desired within a single cascade level, track only words found in the CURRENT cascade chain (not all game words).

**BUGF-05 fix — Frozen tile cascade blocking:**
In the cascade tile clearing loop (line ~346-353), change the clearing logic:
```typescript
for (const cell of vw.path) {
  const t = nextTileStates[cell.row][cell.col];
  if (!t.isCleared) {
    if (t.type === 'frozen' && t.hitsRemaining > 1) {
      // Crack frozen tile instead of clearing
      t.hitsRemaining--;
      t.activationEffect = 'frozen-crack';
    } else if (t.type === 'ice' && t.hitsRemaining > 1) {
      t.hitsRemaining--;
      t.activationEffect = 'ice-crack';
    } else {
      t.isCleared = true;
      newlyClearedCount++;
      cascadeClearedTypes[t.type] = (cascadeClearedTypes[t.type] || 0) + 1;
    }
  }
}
```

**BUGF-06 fix — Gold stacking multiplicative:**
In the main path loop gold case (line ~632-650), change from additive to multiplicative:
```typescript
// Track gold multiplier across all gold tiles in word
// Before the path loop, initialize: let goldMultiplier = 1;
// In gold case: goldMultiplier *= GOLD_MULTIPLIER;
// After the path loop: bonusScore += baseScore * (goldMultiplier - 1);
```
Remove the per-tile `bonusScore += baseScore * (GOLD_MULTIPLIER - 1)` inside the case.

**BUGF-07 fix — Cascade stale state:**
In the highlight timer callback (line ~337), use ref instead of closure:
```typescript
// OLD: const nextTileStates = newTileStates.map(row => row.map(tile => ({ ...tile })));
// NEW: const nextTileStates = tileStatesRef.current.map(row => row.map(tile => ({ ...tile })));
```
Add a `tileStatesRef` (if not already present) that tracks the latest tileStates value.
