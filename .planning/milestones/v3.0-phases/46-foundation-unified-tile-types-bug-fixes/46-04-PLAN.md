**BUGF-08 fix — Fisher-Yates shuffle:**
After building `standardPositions` array (line ~55-62), shuffle it with Fisher-Yates:
```typescript
// Fisher-Yates shuffle to distribute objective tiles randomly
for (let i = standardPositions.length - 1; i > 0; i--) {
  const j = Math.floor(Math.random() * (i + 1));
  [standardPositions[i], standardPositions[j]] = [standardPositions[j], standardPositions[i]];
}
```
This ensures objective tile placement is distributed across the board, not clustered top-left.

**BUGF-09 fix — Minimum standard tile ratio:**
Add a constant and budget check before placement:
```typescript
const MIN_STANDARD_RATIO = 0.6; // 60% of tiles must remain standard
const totalTiles = result.length * result[0].length;
const minStandardCount = Math.ceil(totalTiles * MIN_STANDARD_RATIO);

// Count current standard tiles
let currentStandard = standardPositions.length;

// Calculate budget: how many standard tiles we can convert
const conversionBudget = Math.max(0, currentStandard - minStandardCount);
```

Then in the placement loop, cap `toPlace` at remaining budget:
```typescript
const toPlace = Math.min(deficit, conversionBudget - totalPlaced);
```

If budget is exhausted but objectives still need tiles, try converting non-objective special tiles back to standard first, then re-convert to objective type.

Export `MIN_STANDARD_RATIO` for test verification.
