  <behavior>
    Pure DDA state machine (blastDDA.ts):
    - BlastDDAState: { recentResults: ('success' | 'fail')[], consecutiveFails: number }
    - createDDAState() returns initial state (empty results, 0 fails)
    - updateDDA(state, result: 'success' | 'fail') returns new BlastDDAState
      - Appends result to recentResults (capped at last 5)
      - If result is 'fail': increment consecutiveFails
      - If result is 'success': reset consecutiveFails to 0
    - getDDASpawnModifier(state) returns number:
      - If consecutiveFails >= 3: return +0.15 (DDA_BOOST_PERCENT)
      - If successRate > 0.8 over last 5 and recentResults.length >= 5: return -0.10 (DDA_REDUCE_PERCENT)
      - Otherwise: return 0 (no modification)
    - DDA_BOOST_PERCENT = 0.15, DDA_REDUCE_PERCENT = -0.10
    - Pure functions, no side effects, fully immutable state transitions

    blastLetterGenerator.ts modification:
    - rollSpecialType gains optional 3rd param: spawnModifier: number = 0
    - Effective chance = Math.min(0.95, Math.max(0.05, specialTileChance + spawnModifier))
    - Clamped to [0.05, 0.95] to prevent 0% or 100% special tiles

    useBlastGame.ts wiring:
    - Add ddaStateRef = useRef(createDDAState())
    - On word accepted (in clearTilesForWord success path): ddaStateRef.current = updateDDA(state, 'success')
    - Need a word rejection tracking point — add to BlastGame or useBlastGame
      - When word submission fails (not in dictionary / too short): ddaStateRef.current = updateDDA(state, 'fail')
    - When gravity refill calls rollSpecialType: pass getDDASpawnModifier(ddaStateRef.current) as spawnModifier
    - Reset ddaStateRef on new wave (createDDAState())
  </behavior>
