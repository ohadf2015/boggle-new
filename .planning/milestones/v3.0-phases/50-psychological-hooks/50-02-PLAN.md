  <behavior>
    Pure logic (blastNearMiss.ts):
    - detectNearMiss(submittedPath, grid, tileStates, gridSize) returns NearMissResult
    - NearMissResult: { cells: {row, col}[], type: 'combo' | 'cascade' } | null
    - Scans 1-cell radius around each path cell for uncleared special tiles NOT in the path
    - If 2+ adjacent specials found that would form a combo pair -> return those cells (max 3)
    - If a partial vertical word (3+ letters) exists in an adjacent column -> return those cells (max 3)
    - Returns null if no near-miss detected
    - Caps returned cells at 3 to avoid visual clutter
    - Does NOT trigger if the submitted word already included a combo

    Hook (useBlastNearMiss.ts):
    - shimmerCells: {row: number, col: number}[] state (empty = no shimmer)
    - check(path, grid, tileStates, gridSize, hadCombo): void — runs detectNearMiss, sets shimmerCells
    - Auto-clears shimmerCells after 1500ms via setTimeout
    - Cleans up timer on unmount
    - If hadCombo is true, skips detection (player already got the combo)

    Wiring:
    - BlastGame.tsx: after handleWordAccepted, call nearMiss.check() with lastPathRef.current
    - BlastGameLayout.tsx: receive shimmerCells prop, pass to GridComponent
    - GridComponent (or BlastGameLayout inline): shimmerCells tiles get CSS class "near-miss-pulse" with 1.5s animation
  </behavior>
  <implementation>
    1. Create blastNearMiss.ts — pure detectNearMiss function scanning adjacent cells for special tile pairs or vertical word fragments
    2. Create useBlastNearMiss.ts — thin hook wrapping detectNearMiss with 1500ms auto-clear
    3. Wire into BlastGame.tsx — call nearMiss.check after word accepted
    4. Add shimmerCells rendering in BlastGameLayout — overlay pulse animation on shimmer cells
    5. CSS: Add @keyframes near-miss-pulse (scale 1->1.15->1, opacity pulse) in blast styles or Tailwind config
  </implementation>
</feature>
