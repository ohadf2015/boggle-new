<objective>
Replace cascade refill Math.random() with seeded random for multiplayer determinism.

Purpose: In multiplayer, board refills after cascades use Math.random(), making tile generation non-deterministic across clients. By introducing a seedable PRNG (Mulberry32) and threading an optional `rng` parameter through generateBlastLetter, rollSpecialType, and computeGravityResult, multiplayer games can use a shared seed to produce identical refills. Singleplayer behavior is unchanged (defaults to Math.random).
Output: Seeded PRNG utility, rng-parameterized generation functions, seed in BlastModeState, client receives and uses seed.
</objective>

Research-provided Mulberry32 implementation:
```typescript
export function createSeededRandom(seed: number): () => number {
  let s = seed >>> 0;
  return function mulberry32(): number {
    s |= 0; s = s + 0x6D2B79F5 | 0;
    let t = Math.imul(s ^ (s >>> 15), 1 | s);
    t = t + Math.imul(t ^ (t >>> 7), 61 | t) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}
```
