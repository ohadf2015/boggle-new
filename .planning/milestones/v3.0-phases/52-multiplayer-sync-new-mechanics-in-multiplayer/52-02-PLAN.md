<objective>
Synchronize combination effect dispatch deterministically across clients.

Purpose: Currently each client independently detects combos client-side — Player B never sees Player A's combo flash. By having the submitting client report its detected comboType in the submitWord payload, the server can re-broadcast it to the room, so all clients fire identical BlastComboFlash overlays.
Output: Updated socket types, server re-broadcast handler, client listener, synced combo visuals.
</objective>
