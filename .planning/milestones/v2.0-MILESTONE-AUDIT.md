## Tech Debt

### 1. Practice XP Not Awarded Server-Side

**Severity:** ⚠️ Medium
**Location:** `fe-next/app/api/education/practice/route.ts` PATCH handler (lines 259-329)
**Issue:** Route updates practice_sessions table but does NOT call `educationXpManager.awardEducationXp()`. XP is calculated client-side only in `usePracticeSessionNew` hook.
**Impact:** XP field written to practice_sessions but not persisted to student_progress.total_xp via authoritative server function.
**Fix:** Import `awardEducationXp` from `educationXpManager` and call after session completion in PATCH handler. Low complexity (~5 lines).
**Contrast:** Duel handlers correctly import and use EDUCATION_XP_CONFIG (gameplay.ts, realtime.ts, disconnection.ts).

### 2. Stale Verification Reports

**Severity:** ℹ️ Low
**Phases:** 40, 43
**Issue:** VERIFICATION.md files report gaps_found from before gap closure plans executed. Were not re-run afterward.
**Impact:** Misleading if read in isolation. Phase 41 verification and plan SUMMARYs confirm gaps were closed.
**Fix:** Re-run verification for Phases 40 and 43 (cosmetic, not blocking).

### 3. MotionValue Exception (By Design)

**Severity:** ℹ️ Info
**Location:** FlashcardSwipeStack.tsx, SwipeFeedbackOverlay.tsx
**Issue:** Keep raw `motion.div` and `MotionValue`/`useTransform` imports instead of AdaptiveMotion.
**Reason:** AdaptiveMotion doesn't wrap drag binding primitives. Documented in 43-04-SUMMARY as intentional exception.

### Total: 3 items (0 blockers, 1 medium, 1 low, 1 info)
