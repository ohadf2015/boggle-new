    **Step 1: Run systematic grep audit to identify violations.**

    Search for these anti-patterns across components/education/, components/student/, components/teacher/:

    1. **Generic shadows (should be shadow-hard-*):**
       `grep -rn "shadow-sm\|shadow-md\|shadow-lg\|shadow-xl\|shadow-2xl" --include="*.tsx"`
       Exception: `drop-shadow-*` for text effects is acceptable.

    2. **Generic text colors (should be text-neo-*):**
       `grep -rn "text-slate-\|text-gray-\|text-zinc-\|text-neutral-\|text-stone-" --include="*.tsx"`
       Replace with neo equivalents: text-slate-400/text-gray-400 -> text-neo-white/60, text-slate-500/text-gray-500 -> text-neo-white/40, text-slate-300 -> text-neo-white/80

    3. **Generic borders (should be border-neo or border-neo-thick):**
       `grep -rn "border-2\b\|border-\[" --include="*.tsx"`
       Exception: border-neo-black, border-neo-green, border-neo-pink etc. are correct. Only plain `border-2` without neo- is wrong.

    4. **Generic border radius (should be rounded-neo or rounded-neo-lg):**
       `grep -rn "rounded-md\|rounded-lg\b\|rounded-xl\|rounded-2xl" --include="*.tsx"`
       Exception: `rounded-full` is acceptable for circular elements (badges, avatars).

    5. **Generic fonts (should be font-neo-display or font-neo-body):**
       `grep -rn "font-sans\|font-serif\|font-mono" --include="*.tsx"`
       Exception: `font-mono` in hint displays (SpellingChallenge) is acceptable for monospace letter spacing.

    6. **Generic bg colors (should use neo- palette):**
       `grep -rn "bg-slate-\|bg-gray-\|bg-zinc-" --include="*.tsx"`
