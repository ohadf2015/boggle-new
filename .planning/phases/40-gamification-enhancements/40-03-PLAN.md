     ],

   **Functions:**

   `getDailyChallenges(playerId: string, date?: string)`:
   - Query daily_challenges WHERE player_id = playerId AND challenge_date = date (default today)
   - Return typed DailyChallengeRow[]
   - Handle Supabase not configured case

   `getWeeklyQuests(playerId: string, weekStart?: string)`:
   - Query weekly_quests WHERE player_id = playerId AND week_start = weekStart (default current Monday)
   - Return typed WeeklyQuestRow[]

   `assignDailyChallenges(playerId: string)`:
   - Check if challenges already exist for today (avoid duplicates)
   - If not, pick 1 random from each tier (easy, medium, hard)
   - Insert 3 rows into daily_challenges with today's date
   - Use bonus_reward: { coins: 10 } for easy, { coins: 25 } for medium, { coins: 50 } for hard
   - Return the 3 created challenges

   `claimChallengeReward(challengeId: string, playerId: string)`:
   - Fetch challenge, verify player_id matches
   - Verify completed = true
   - Verify claimed = false
   - Update claimed = true, claimed_at = now
   - Return { xpReward, bonusReward } for UI to display

   `claimQuestReward(questId: string, playerId: string)`:
   - Same pattern as claimChallengeReward but for weekly_quests

   Helper `getCurrentWeekStart()`:
   - Returns Monday of current week as 'YYYY-MM-DD' string

4. Update index.ts barrel export to include `'./challenges'`.
