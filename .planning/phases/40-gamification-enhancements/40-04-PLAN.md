3. Create milestones.ts (GREEN phase):

   Import from xpManager: `getXpForLevel, getLevelFromXp, getXpProgress, LEVEL_TITLES`

   **Constants:**
   ```typescript
   // Major milestones that trigger celebration cinematic
   export const MAJOR_MILESTONES = [5, 10, 25, 50, 100] as const;

   // Minor milestones that trigger subtle badge pulse
   export const MINOR_MILESTONES = [3, 7, 15, 20, 30, 35, 40, 60, 75, 90] as const;

   // All milestones combined and sorted
   export const ALL_MILESTONES = [...MAJOR_MILESTONES, ...MINOR_MILESTONES].sort((a, b) => a - b);

   // Milestone rewards scale with level
   const MILESTONE_REWARDS: Record<number, { xpBonus: number; coinBonus: number }> = {
     5: { xpBonus: 100, coinBonus: 25 },
     10: { xpBonus: 250, coinBonus: 50 },
     25: { xpBonus: 500, coinBonus: 100 },
     50: { xpBonus: 1000, coinBonus: 250 },
     100: { xpBonus: 5000, coinBonus: 1000 },
   };
   ```

   **Functions:**

   `getMilestones(): MilestoneLevel[]`:
   - Return all milestone levels with title (from LEVEL_TITLES) and isMajor flag

   `checkMilestoneCrossed(oldLevel: number, newLevel: number): MilestoneLevel | null`:
   - Find the first milestone in ALL_MILESTONES where oldLevel < milestone <= newLevel
   - Return milestone info (level, title, isMajor) or null if none crossed
   - If multiple milestones crossed (rare), return the highest one (most significant)

   `getMilestoneRewards(milestoneLevel: number): { xpBonus: number; coinBonus: number; title: string | null }`:
   - Lookup MILESTONE_REWARDS for exact match
   - For minor milestones: return { xpBonus: milestoneLevel * 5, coinBonus: milestoneLevel, title: null }
   - Include title from LEVEL_TITLES if one exists at this level

   `getNextMilestoneForLevel(currentLevel: number): { level: number; isMajor: boolean; xpNeeded: number; title: string | null } | null`:
   - Find first milestone in ALL_MILESTONES where milestone > currentLevel
   - Return null if currentLevel >= 100

   `getMilestoneProgress(totalXp: number): { currentLevel: number; nextMilestone: number; progressPercent: number; xpToNextMilestone: number }`:
   - Uses getLevelFromXp for current level
   - Uses getNextMilestoneForLevel for next milestone
   - Calculates XP progress between current level and next milestone level
   - Returns percentage (0-100)

4. Update index.ts barrel export to include `'./milestones'`.

5. Run tests - verify PASS (GREEN).
