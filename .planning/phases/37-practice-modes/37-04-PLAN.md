  <behavior>
    **useBlitzGame hook:**
    - Input: VocabularyWord[] (words with definitions), totalTime = 60
    - Shuffles words randomly, cycles through them (wraps around if all seen)
    - Timer: uses startTimestamp approach (not decrement) to avoid drift (research pitfall 2)
      - Store startTime = Date.now() on start
      - Update every 100ms: remainingTime = totalTime - Math.floor((Date.now() - startTime) / 1000)
      - When remainingTime <= 0: game over
    - Game mode: shows definition, player types word (same as spelling but faster-paced)
    - `submitAnswer(input: string)` -> { correct: boolean }
      - Case-insensitive, trimmed comparison
      - If correct: increment combo, increment wordsFound, move to next word
      - If incorrect: reset combo, move to next word (no reveal in blitz — speed matters)
    - Combo tracking: combo (current), maxCombo (session high), comboMultiplier for display
    - Score: wordsFound * BLITZ_WORD_FOUND + maxCombo * BLITZ_COMBO_BONUS + BLITZ_COMPLETION
    - `startGame()` — begins timer, shuffles words
    - `isGameOver` when timer reaches 0
    - Returns: { currentWord, remainingTime, combo, maxCombo, wordsFound, wordsAttempted, isGameOver, isStarted, submitAnswer, startGame, score }

    Test cases (useBlitzGame):
    - Timer starts at 60, decreases over time
    - submitAnswer correct: combo increments, wordsFound increments
    - submitAnswer incorrect: combo resets to 0, wordsAttempted increments
    - 3 correct in a row: combo === 3, maxCombo === 3
    - Correct, incorrect, correct: combo === 1, maxCombo === 1
    - After all words cycled: wraps back to beginning (shuffled differently)
    - isGameOver when remainingTime <= 0
    - Score calculated correctly: wordsFound * 10 + maxCombo * 3 + 40

    **TimedBlitzPractice component:**
    - 3-2-1 countdown intro before game starts (build anticipation)
    - Top section: CircularTimer component (existing, size="lg")
    - Combo display: flame icon + "Xn Combo!" with scale-in animation (AdaptiveMotion)
    - Center: definition card (large text, readable quickly)
    - Bottom: text input (autoFocus, autoComplete off) + submit button
    - Submit on Enter
    - Feedback: brief green flash on correct (100ms, not full animation — speed matters)
    - No feedback pause on incorrect in blitz (just move to next word immediately)
    - Timer urgency: background pulse at 20s, red tint at 10s
    - Score counter in top-right: running total
    - On time up:
      - Brief "TIME'S UP!" animation
      - Then show results: words found, max combo, accuracy, XP earned
      - Use PracticeResultsCard or custom blitz results (with combo highlight)
    - Neo-brutalist: bold timer display, chunky combo badge, shadow-hard cards
    - RTL: layout respects language direction
    - All text via t()

    **Visual design notes:**
    - Combo badge: neo-orange background, grows with scale on increment
    - Timer: existing CircularTimer with remainingTime and totalTime=60
    - Background: subtle urgency gradient shift as time decreases
    - Score: neo-yellow text, increments with +N animation
  </behavior>

    useBlitzGame:

    - Shuffle words with Fisher-Yates (or sort(() => Math.random() - 0.5))

    - Don't use heavy animations during gameplay (performance on mobile)
