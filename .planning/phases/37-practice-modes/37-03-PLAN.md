  <behavior>
    **useSpellingGame hook:**
    - Input: VocabularyWord[] (words with definitions)
    - Sorts words by length (shortest first = progressive difficulty)
    - Tracks currentWordIndex, currentStreak, maxStreak, attempts, correctCount
    - Provides hint system:
      - `getHint()` returns next unrevealed letter of the current word
      - First hint is free (first letter always shown)
      - Additional hints reset streak to 0
      - `hintsUsed` counter per word
    - `submitAnswer(input: string)` -> { correct: boolean, correctWord: string }
      - Case-insensitive comparison
      - Trim whitespace
      - For Hebrew: use normalizeForStorage from education/types.ts
      - If correct: increment streak, correctCount
      - If incorrect: reset streak to 0
      - Auto-advance to next word after brief delay
    - `isComplete` when all words attempted
    - Returns: { currentWord (definition only), wordIndex, totalWords, submitAnswer, getHint, currentHint, hintsUsed, currentStreak, maxStreak, isComplete, accuracy, correctCount, attempts, resetGame }

    Test cases (useSpellingGame):
    - Given words ['cat', 'elephant', 'dog'] -> sorts to ['cat', 'dog', 'elephant'] (by length)
    - submitAnswer('cat') for word 'cat' -> { correct: true }
    - submitAnswer('Cat') for word 'cat' -> { correct: true } (case insensitive)
    - submitAnswer('kat') for word 'cat' -> { correct: false, correctWord: 'cat' }
    - After correct: streak increments
    - After incorrect: streak resets to 0
    - getHint() for 'elephant': first call returns 'e', second 'el', third 'ele'
    - Hint after first: resets streak
    - After all words: isComplete === true, accuracy = correctCount / totalWords

    **SpellingChallengePractice component:**
    - Shows definition card prominently (neo-brutalist card with shadow-hard-lg)
    - Text input below for typing the word
    - Submit on Enter key or submit button
    - Feedback:
      - Correct: input border turns green, checkmark icon appears, word shown briefly
      - Incorrect: input border turns red, shake animation, correct word revealed for 2s
    - Hint button: shows revealed letters as placeholder text (e.g., "e _ _ _ _ _ _ _")
    - Progress bar: X / Y words completed
    - Streak indicator: shows current streak count with fire icon (reuse pattern from ComboDisplay)
    - On completion: PracticeResultsCard with accuracy, streak, XP
    - Neo-brutalist: border-neo, shadow-hard, font-neo-display for word, font-neo-body for definition
    - RTL: input direction follows language, definition card respects dir
    - All text via t()
    - `autoFocus` on input, `autoComplete="off"` to prevent browser suggestions

    **Progressive difficulty visual:**
    - Show difficulty indicator: "Easy", "Medium", "Hard" based on word length thresholds
    - Easy: <= 4 letters, Medium: 5-7 letters, Hard: 8+ letters
  </behavior>

    useSpellingGame:
    - Sort words by word.word.length ascending (progressive difficulty)
    - Store currentHintIndex (how many letters revealed)
    - On init: first letter always revealed (hint index = 1)
    - getHint: increment hintIndex, return word.substring(0, hintIndex)
    - submitAnswer: normalize both input and correct word before comparison
    - Track per-word data: { word, correct, hintsUsed, timeTaken }

    SpellingChallengePractice:
    - Props: { words: VocabularyWord[], onComplete: (results) => void, onBack: () => void }
    - Controlled input with useState
    - On correct: setTimeout 1000ms, then advance to next word, clear input
    - On incorrect: show correct word for 2000ms, then advance
    - AdaptiveMotion for feedback animations
    - Streak display: only visible when streak >= 2

    AVOID:
