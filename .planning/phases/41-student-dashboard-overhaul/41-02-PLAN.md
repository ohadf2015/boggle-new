    **useClassroomActivity.ts** - Hook that fetches recent classroom activity by combining data from multiple tables.

    Interface:
    ```typescript
    export interface ActivityItem {
      id: string;
      type: 'duel_completed' | 'achievement_unlocked';
      actorId: string;
      actorName: string;
      actorAvatar?: string;
      timestamp: Date;
      metadata: Record<string, unknown>;
    }

    export function useClassroomActivity(classroomId: string | null, limit?: number): {
      activities: ActivityItem[];
      isLoading: boolean;
      error: string | null;
    }
    ```

    Implementation:
    - Accept classroomId and optional limit (default 20)
    - If !supabase or !classroomId, return empty activities with isLoading=false
    - Fetch in parallel:
      1. student_duels: status='completed', matching classroom_id, ordered by completed_at DESC, range(0, limit-1). Select: id, completed_at, winner_id, challenger_id, opponent_id. Join profiles for challenger (display_name, avatar_emoji) and opponent (display_name, avatar_emoji).
      2. student_achievements: Join with achievement_definitions for key and icon. Join profiles for student (display_name, avatar_emoji). Order by unlocked_at DESC, range(0, limit-1). Filter by classroom membership: The student_achievements table doesn't have classroom_id, so we need to filter by students who are members of the classroom. Use a subquery or fetch classroom_members first, then filter. Simpler approach: fetch classroom_members ids first, then filter achievements by those student_ids.
    - Merge results into ActivityItem[], sort by timestamp DESC, slice to limit
    - For duel_completed: actorId = winner_id, actorName = winner's display_name. If draw (winner_id null), use challenger as actor.
    - For achievement_unlocked: actorId = student_id, actorName = student's display_name
    - Use try/catch, log errors via logger, set error state
    - Dependency array: [classroomId, limit]
