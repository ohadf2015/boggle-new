Follow RED-GREEN-REFACTOR cycle. Write tests FIRST in `__tests__/realtime.test.ts`, then implement in `realtime.ts`.

**Test cases to write (RED phase):**

1. `duel:submit-word` handler:
   - Rejects invalid payload (missing duelId or word)
   - Rejects word not in dictionary
   - Rejects word not on board (using isWordOnBoardAsync)
   - Rejects duplicate word (already found by this player)
   - Rejects if duel not active
   - Rejects if user not a participant
   - Accepts valid word: emits `duel:word-accepted` to submitter with word, points, totalScore, wordCount
   - Broadcasts `duel:opponent-progress` to opponent via room emit (excluding sender) with opponentId, totalScore, wordCount
   - Updates duel_turns or in-memory word tracking

2. `duel:started` flow (registerRealtimeHandlers sets up timer):
   - After accepting a realtime duel, server emits `duel:started` to room with boardState, startTime (ISO), timeLimit (180s), players array
   - Server starts setTimeout for timeLimit seconds
   - When timer fires, duel is completed atomically (`.eq('status', 'active')` to prevent race)
   - Winner determined by comparing scores
   - XP awarded using DUEL_WIN_REALTIME / DUEL_LOSS_REALTIME / DUEL_DRAW values
   - `duel:completed` emitted to room with final scores

**Implementation (GREEN phase):**

Create `realtime.ts` with `registerRealtimeHandlers(namespace, socket)`:

1. **In-memory game state** (Map<duelId, RealtimeGameState>):
   ```typescript
   interface RealtimeGameState {
     challengerId: string;
     opponentId: string;
     boardState: string[][];
     language: string;
     timeLimit: number;
     startTime: string;
     timer: NodeJS.Timeout | null;
     challengerWords: string[];
     opponentWords: string[];
     challengerScore: number;
     opponentScore: number;
   }
   ```
   Export `realtimeGames` Map for testing access.

2. **`duel:submit-word` handler:**
   - Validate payload with `submitWordSchema`
   - Look up game state from `realtimeGames` Map
   - Check word not already found by player
   - Validate word: `isDictionaryWord(word, language)` and `await isWordOnBoardAsync(word, boardState)`
   - Calculate score: `calculateWordScore(word, 0)`
   - Update in-memory state (add word, increment score)
   - Emit `duel:word-accepted` to socket
   - Emit `duel:opponent-progress` to opponent via `socket.to(duelRoom).emit(...)` (excludes sender)

3. **`startRealtimeDuel(namespace, duelId, duel)` function** (called from lifecycle when accepting realtime duel):
   - Initialize game state in `realtimeGames` Map
   - Fetch lesson language from DB
   - Emit `duel:started` to room with board, startTime, timeLimit, players
   - Start server-side timer: `setTimeout(() => completeRealtimeDuel(...), timeLimit * 1000)`

4. **`completeRealtimeDuel(namespace, duelId)` function:**
   - Get game state from Map
   - Atomic DB update: `.update({ status: 'completed', ... }).eq('id', duelId).eq('status', 'active')`
   - Determine winner by comparing scores
   - Award XP using `DUEL_WIN_REALTIME` / `DUEL_LOSS_REALTIME` / `DUEL_DRAW`
   - Insert duel_turns for both players
   - Emit `duel:completed` to room
   - Clean up: delete from `realtimeGames` Map, clear timer

Mock patterns: Follow `__tests__/gameplay.test.ts` mocking strategy for supabase, isDictionaryWord, isWordOnBoardAsync, calculateWordScore, logger.

IMPORTANT: Use `socket.to(room).emit()` (not `namespace.to(room).emit()`) for opponent-only broadcasts. `socket.to()` excludes the sender.
