  <files>fe-next/components/education/duels/RealTimeDuelGame.tsx, fe-next/components/education/duels/__tests__/RealTimeDuelGame.test.tsx, fe-next/components/education/duels/index.ts</files>
  <action>
1. **RealTimeDuelGame.tsx:**
   Props: `{ duelId: string; studentId: string; opponentName: string; onBackToLobby?: () => void }`

   **Game phases:** `'waiting' | 'playing' | 'completed'`

   **Waiting phase** (before duel:started received):
   - Show loading spinner with "Waiting for opponent..." text
   - Use `onDuelStarted` listener from useDuelSocket

   **Playing phase** (after duel:started received):
   - Layout: header with timer (center), my score (left), opponent score (right)
   - Timer: Calculate from `startTime` (server timestamp) + `timeLimit`. Update every 100ms via setInterval. Display MM:SS format. When <= 10s, text turns red.
   - Board grid: 4x4 grid of letters from boardState (same pattern as DuelGameView)
   - Word input: text input + "Add" button (same pattern as DuelGameView)
   - Word list: found words displayed as chips (accepted = green, rejected = red, pending = gray)
   - OpponentProgressBar component below header
   - Forfeit button (bottom corner, small, muted) → opens ForfeitConfirmDialog
   - DuelDisconnectOverlay shown when opponent disconnects, hidden on reconnect

   **Socket wiring (all from useDuelSocket):**
   - `onDuelStarted` → set boardState, startTime, timeLimit, transition to 'playing'
   - `onWordAccepted` → update word status to accepted, update myScore, myWordCount
   - `onWordRejected` → update word status to rejected
   - `onOpponentProgress` → update opponentScore, opponentWordCount
   - `onOpponentDisconnected` → show disconnect overlay
   - `onOpponentReconnected` → hide disconnect overlay
   - `onDuelCompleted` → transition to 'completed', show results
   - `onStateSynced` → reconcile local state with server state (for reconnection)

   **Word submission flow:**
   - User types word, presses Enter or clicks Add
   - Word appears in list as "pending" (gray chip)
   - Call `submitWord(duelId, word)`
   - On `duel:word-accepted`: update chip to green, add points
   - On `duel:word-rejected`: update chip to red with reason tooltip

   **Forfeit flow:**
   - Click "Forfeit" → ForfeitConfirmDialog opens
   - Confirm → call `forfeitDuel(duelId)`
   - On `duel:completed` with forfeit reason → show results

   **Completed phase:**
   - Reuse similar results layout as DuelGameView (win/loss/draw with XP)
   - Add forfeit-specific messaging if applicable
   - "Back to Lobby" button calls onBackToLobby

   **Important:**
   - Use `t()` for ALL text strings
   - Neo-brutalist styling throughout
   - Keep component under 300 lines. Extract sub-components if needed.
   - data-testid on key elements: `realtime-duel-game`, `duel-timer`, `my-score`, `opponent-score`, `word-input`, `submit-word-btn`, `forfeit-btn`
