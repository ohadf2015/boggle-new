    Create migration file `20260215100000_assignment_tracking.sql` with:

    1. `teacher_assignments` table:
       - id UUID PK DEFAULT gen_random_uuid()
       - classroom_id UUID REFERENCES classrooms(id) ON DELETE CASCADE NOT NULL
       - lesson_id UUID REFERENCES vocabulary_lessons(id) ON DELETE CASCADE NOT NULL
       - teacher_id UUID REFERENCES profiles(id) NOT NULL
       - assignment_type TEXT NOT NULL CHECK (assignment_type IN ('practice', 'duel')) DEFAULT 'practice'
       - due_date TIMESTAMPTZ (nullable - no deadline if null)
       - title TEXT (nullable - auto-generated from lesson name if null)
       - instructions TEXT (nullable - optional teacher notes)
       - created_at TIMESTAMPTZ DEFAULT now()
       - updated_at TIMESTAMPTZ DEFAULT now()
       - UNIQUE(classroom_id, lesson_id, assignment_type) to prevent duplicate assignments

    2. `assignment_completions` table:
       - id UUID PK DEFAULT gen_random_uuid()
       - assignment_id UUID REFERENCES teacher_assignments(id) ON DELETE CASCADE NOT NULL
       - student_id UUID REFERENCES profiles(id) NOT NULL
       - completed_at TIMESTAMPTZ DEFAULT now()
       - score INTEGER DEFAULT 0
       - accuracy NUMERIC(5,2) DEFAULT 0
       - time_spent_seconds INTEGER DEFAULT 0
       - UNIQUE(assignment_id, student_id)

    3. Indexes on classroom_id, lesson_id, student_id, due_date
    4. RLS policies following existing simplified patterns from migration 057:
       - Teachers can CRUD their own assignments (via vocabulary_lessons.teacher_id)
       - Students can view assignments for their classrooms (via classroom_memberships)
       - Students can insert/update their own completions

    Add types to `types.ts`:
