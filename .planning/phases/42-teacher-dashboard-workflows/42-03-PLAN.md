    **CompletionTracker** - Shows per-student completion AND struggling words for one assignment:

    Props:
    ```typescript
    interface CompletionTrackerProps {
      assignmentId: string;
      totalStudents: number;
    }
    ```

    Implementation:
    1. Fetch completions via getAssignmentCompletions(assignmentId) on mount
    2. Show overall progress bar: completions.length / totalStudents with percentage
    3. List each student with status:
       - Completed: green checkmark + score + accuracy
       - Not completed: gray circle
    4. Sort: completed students first (by score DESC), then not-completed alphabetically
    5. **Struggling Words Section** (TEACH-03 requirement):
       - Below the student list, add a collapsible "Struggling Areas" section with AlertTriangle icon
       - Aggregate word-level accuracy from completion data: each completion record includes `incorrectWords` array (words the student got wrong or missed)
       - Count how many students got each word wrong across all completions
       - Display top 5 most-struggled words sorted by error count DESC:
         - Word text, error count as "N/M students missed", red intensity bar (proportional to error rate)
       - If no completion data yet or no incorrect words, show "No struggling areas identified yet" message
       - Use t() keys: teacher.completion.strugglingAreas, teacher.completion.studentsMissed, teacher.completion.noStrugglingAreas
    6. Compact layout for embedding in assignment cards
