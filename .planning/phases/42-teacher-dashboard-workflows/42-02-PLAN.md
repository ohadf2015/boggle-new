  <action>
    Create BulkImportEnhanced - an upgraded version of BulkWordImporter with better validation feedback.

    Key improvements over existing BulkWordImporter:
    1. **Row-level validation feedback**: Show row numbers with errors (e.g., "Row 3: 'xyz' cannot be integrated into board")
    2. **Hebrew niqqud warning**: Detect words with niqqud using containsHebrew() from types.ts, show warning: "N words contain niqqud (vowel points will be removed)"
    3. **Definition column detection**: Same delimiter pattern as existing BulkWordImporter but with explicit mode toggle (auto-detect vs manual)
    4. **Summary stats before import**: Show integrable count, warning count, error count in a stats bar
    5. **CSV file upload**: Add file input for CSV besides textarea. Parse with native FileReader API (no external library needed for simple CSV).

    Props (same interface as BulkWordImporter for drop-in replacement):
    ```typescript
    interface BulkImportEnhancedProps {
      isOpen: boolean;
      onClose: () => void;
      onImport: (words: VocabularyWord[]) => void;
      language: Language;
    }
    ```

    Implementation:
    1. Keep existing textarea input from BulkWordImporter
    2. Add file upload area above textarea: "Drop CSV file here or click to browse" with Upload icon
    3. On file upload, read contents and populate textarea
    4. Parse words using same logic as BulkWordImporter (newline > comma > space detection)
    5. Add validation pipeline:
       - For each parsed word, check canIntegrate via useWordIntegration
       - For Hebrew words, check containsHebrew(original) to detect niqqud
       - Track row numbers for error display
    6. Display validation results in 3 sections:
       - Green section: "N words ready" with checkmark icons
       - Yellow section: "N warnings" (niqqud, long words) - collapsible
       - Red section: "N errors" (can't integrate) with row numbers - collapsible
    7. Import button text shows count: "Import N words"
    8. Use existing sanitizeWord for Hebrew before validation

    Test file:
    - Renders textarea and file upload area
    - Parses newline-separated words correctly
    - Shows niqqud warning for Hebrew words with vowel points
    - Shows row-level errors for non-integrable words
    - Calls onImport with validated words on submit
    - File upload populates textarea
  </action>
