Follow RED-GREEN-REFACTOR. Write tests first, then implement.

**lifecycle.ts exports `registerLifecycleHandlers(namespace, socket)`** which registers:

1. **duel:create** handler:
   - Validate payload with createDuelSchema
   - Call `generateRandomTable(4, 4, language)` from `backend/utils/gameUtils` to create frozen board
   - Insert duel into student_duels via Supabase (status='pending', board_state=board, expires_at=24h from now)
   - Emit `duel:created` to creator socket with { duelId }
   - Find opponent socket in namespace and emit `duel:challenge-received` with { duelId, challengerName, lessonId }
   - Also emit to `duel:lobby:${classroomId}` room for lobby updates

2. **duel:accept** handler:
   - Validate payload with acceptDuelSchema
   - Fetch duel from DB, verify status='pending' AND opponent_id matches socket.data.userId
   - Update status to 'active', set started_at
   - Both players join `duel:${duelId}` room
   - Emit `duel:accepted` to duel room with { duelId, boardState, startedAt }

3. **duel:decline** handler:
   - Validate payload with declineDuelSchema
   - Fetch duel from DB, verify status='pending' AND opponent_id matches socket.data.userId
   - Update status to 'declined'
   - Emit `duel:declined` to challenger (find their socket)

4. **duel:cancel** handler:
   - Validate payload with cancelDuelSchema
   - Fetch duel from DB, verify status='pending' AND challenger_id matches socket.data.userId
   - Update status to 'cancelled'
   - Emit `duel:cancelled` to opponent (find their socket)

**Test patterns:**
- Mock Supabase with jest.mock (return controlled data for .from().select().eq().single())
- Mock Socket.IO namespace with mock .to().emit(), .sockets for finding opponent
- Mock generateRandomTable to return predictable board
- Test state validation: accept on non-pending duel should emit error
- Test ownership: non-opponent accepting should emit error
- Test happy paths for all 4 handlers

**Important:** Use `socket.emit('duel:error', { message })` for error responses. Follow existing handler pattern from wordHandler.ts.
