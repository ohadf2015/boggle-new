**DuelGameView.tsx** ('use client'):
Props: `{ duelId: string; studentId: string }`

This is the async duel gameplay screen. Student plays a frozen board and submits their final score.

**Flow:**
1. On mount, fetch duel record via `getDuelById(duelId)` to get board_state and opponent info
2. Render the board grid using the frozen board_state (reuse existing BoardGrid component or build a simplified grid renderer)
3. Student finds words on the board (reuse existing word-finding UI patterns from the game):
   - Show letter grid (4x4)
   - Word input area (type or tap letters to form words)
   - Found words list with scores
   - Timer or untimed (async duels are untimed -- student plays at their own pace)
4. "Submit Score" button when student is ready
   - Calls `submitScore(duelId, wordsFound)` via useDuelSocket
   - Shows loading state while server validates
   - On `duel:score-submitted` event: show validated score, words accepted/rejected
   - On `duel:completed` event: show results (winner, scores, XP awarded)
5. Results screen: winner announcement, score comparison, XP earned, "Back to Lobby" button

**State management:**
- `duel: DuelRow | null` (fetched on mount)
- `wordsFound: string[]` (accumulated during play)
- `currentWord: string` (being formed)
- `gamePhase: 'loading' | 'playing' | 'submitting' | 'waiting' | 'completed'`
- `result: DuelCompletedData | null`

**Important design notes:**
- Board grid should render the frozen board_state exactly (string[][])
- Do NOT regenerate the board -- load from duel.board_state
- Word selection can be simplified for async duels: text input + submit button (no drag required)
- Show opponent info (name, avatar) in header
- Show "Score to beat: [challenger_score]" if student is the opponent (can see challenger's score after their own submission)

ALL text via `t()`. Keys: `playDuel`, `findWords`, `submitScore`, `waitingForOpponent`, `youWin`, `youLose`, `draw`, `xpEarned`, `backToLobby`, `wordsAccepted`, `wordsRejected`, `scoreToBeat`.

Neo-brutalist styling: dark bg, border-3 around board, shadow-hard on cards, neo-yellow for primary actions.

**Test:**
- Renders loading state initially
- Renders board grid from frozen board_state
- Submit button calls submitScore with accumulated words
- Shows results when duel:completed received
- Mock getDuelById and useDuelSocket
