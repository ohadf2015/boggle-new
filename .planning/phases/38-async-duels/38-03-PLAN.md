Follow RED-GREEN-REFACTOR. Write tests first.

**gameplay.ts exports `registerGameplayHandlers(namespace, socket)`** which registers:

1. **duel:submit-score** handler:
   - Validate payload: `{ duelId: string, wordsFound: string[] }` with Zod
   - Fetch duel from DB, verify status='active' AND socket user is challenger or opponent
   - Load frozen board_state from duel record
   - **Server-side word validation** (CRITICAL anti-cheat):
     - For each word in wordsFound:
       - Check word exists in dictionary using `isDictionaryWord(word, language)`
       - Check word path exists on frozen board using `isWordOnBoardAsync(word, boardState)`
       - Filter out invalid words
     - Calculate score from validated words using `calculateWordScore` from scoringEngine
   - Insert duel_turn record: { duel_id, player_id, score: serverCalculatedScore, words_found: validatedWords }
   - Update student_duels: set challenger_score or opponent_score based on who submitted
   - Emit `duel:score-submitted` to duel room: { playerId, score: serverCalculatedScore, wordsValidated: validatedWords.length, wordsRejected: rejected count }

2. **Completion check** (called after score submission):
   - After updating score, check if BOTH challenger_score > 0 AND opponent_score > 0 (both have submitted)
   - If both submitted, call `completeDuel(duelId)`:
     - Determine winner: higher score wins. Equal scores = draw.
     - **Race condition protection**: Update student_duels SET status='completed', winner_id, completed_at, xp_awarded=true WHERE id=duelId AND xp_awarded=false. If update returns 0 rows, XP was already awarded -- skip.
     - Award XP using EDUCATION_XP_CONFIG: winner gets DUEL_WIN_ASYNC (200), loser gets DUEL_LOSS_ASYNC (120), draw gets DUEL_DRAW (175) each
     - XP award: call Supabase RPC or direct update to student progress (follow educationXpManager pattern)
     - Emit `duel:completed` to duel room: { winnerId (null for draw), challengerScore, opponentScore, xpAwarded: { winner: amount, loser: amount } }

**Test cases:**
- Submit score with valid words: server validates, calculates score, stores turn
- Submit score with some invalid words: only valid words counted in score
- Submit score when not a participant: error emitted
- Submit score on non-active duel: error emitted
- Both players submit: winner determined, XP awarded
- Tie game: both get DUEL_DRAW XP, winner_id is null
- Double XP prevention: second completion attempt skips XP award (xp_awarded flag)
- Edge case: player submits empty words array (score = 0)

**Mocking strategy:**

- Mock `isWordOnBoardAsync` to return true/false per word
- Mock `isDictionaryWord` to return true/false per word
- Mock `calculateWordScore` to return predictable scores
- Mock EDUCATION_XP_CONFIG values (import directly, they're constants)
