**DuelLobby.tsx** ('use client'):
Props: `{ classroomId: string; studentId: string; lessons: Array<{ id: string; name: string }> }`

Sections:
1. **Pending Challenges** (incoming): List of duels where student is opponent, status='pending'. Each card shows challenger name, lesson name, created time, Accept/Decline buttons. Use neo-brutalist card style (border-3, shadow-hard-sm, rounded-neo).
2. **Available Opponents**: Grid of online students from lobby. Each card shows avatar placeholder (colored circle), display name, online indicator (green dot). Click opens DuelChallengeModal.
3. **Quick Match**: Button that picks random available opponent and opens challenge modal. Styled as primary action (bg-neo-yellow, text-black, shadow-hard).

Uses `useDuelSocket` hook:
- `joinLobby(classroomId)` on mount, `leaveLobby(classroomId)` on unmount
- `onLobbyUpdate` to update opponents list
- `onChallengeReceived` to add to pending challenges
- `acceptChallenge(duelId)` and `declineChallenge(duelId)` for pending challenge actions

State: `opponents: OpponentInfo[]`, `pendingChallenges: ChallengeReceivedData[]`, `selectedOpponent: OpponentInfo | null`

Also fetch initial pending duels from DB via `getPendingDuelsForStudent` on mount (don't rely only on socket for initial state).

ALL text via `t()` function from LanguageContext. Key patterns: `duelLobbyTitle`, `pendingChallenges`, `availableOpponents`, `quickMatch`, `accept`, `decline`, `noPendingChallenges`, `noOpponentsOnline`, `challengeFrom`.
