**Types to define** (in duels.ts):
- `DuelStatus = 'pending' | 'active' | 'completed' | 'cancelled' | 'expired' | 'declined'`
- `DuelType = 'async' | 'realtime'`
- `DuelRow` - matches student_duels table columns (id, classroom_id, challenger_id, opponent_id, lesson_id, duel_type, status, board_state, challenger_score, opponent_score, winner_id, xp_awarded, created_at, started_at, completed_at, expires_at)
- `DuelTurnRow` - matches duel_turns table columns (id, duel_id, player_id, score, words_found, board_state_snapshot, started_at, completed_at)
- `CreateDuelData` - { challengerId, opponentId, classroomId, lessonId, boardState: string[][], expiresAt?: string }
- `DuelHistoryEntry` - extends DuelRow with challenger/opponent profile info (display_name, avatar_url) and computed isWin field
- `DuelStatsResult` - { wins, losses, draws, winStreak, currentStreak, opponentStats: Map<string, { wins, losses }> }

**Functions to implement** (follow practice.ts pattern - server-side Supabase client):
1. `createDuel(data: CreateDuelData)` - Insert into student_duels with status='pending', duel_type='async', expires_at default 24h
2. `getDuelById(duelId: string)` - Select single duel with challenger/opponent profile joins
3. `updateDuelStatus(duelId: string, status: DuelStatus, updates?: Partial<DuelRow>)` - Update status + optional fields (winner_id, scores, timestamps)
4. `getDuelHistory(studentId: string, limit?: number)` - Select completed duels where student is challenger or opponent, join profiles, order by completed_at desc
5. `getDuelStats(studentId: string)` - Compute win/loss/draw counts, current win streak, per-opponent stats from completed duels
6. `submitDuelTurn(duelId: string, playerId: string, score: number, wordsFound: string[])` - Insert into duel_turns, return turn row
7. `getPendingDuelsForStudent(studentId: string)` - Duels where student is opponent and status='pending'
8. `getActiveDuelsForStudent(studentId: string)` - Duels where student is participant and status='active'

**Test patterns** (mock Supabase client like practice tests):

- Test each function with happy path + error cases
- Test getDuelHistory returns isWin computed correctly
- Test getDuelStats computes streaks correctly (this is the key business logic)
