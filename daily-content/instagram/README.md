# Daily LexiClash Instagram Content

This folder holds ready-to-post Instagram content (feed + stories) designed to drive real engagement (comments, saves, shares).

## How it works (for daily delivery to TG bot)
- Every day a new post idea + image + caption is generated.
- The content is optimized for the LexiClash neo-brutalist + kawaii mascot + electric color style.
- Images are word-puzzle style challenges that beg for comments ("how many did you get?", "longest word?", "I got X").

## To get today's / tomorrow's post
Run in chat: "generate today's LexiClash IG post" or the scheduler will push one daily.

## Current assets
- `ig-puzzle-grid-challenge.jpg` — 3:4 grid challenge (good for feed)
- `ig-puzzle-anagram-story.jpg` — 9:16 story version
- `ig-puzzle-word-count.jpg` — 1:1 word count bait

## Engagement principles used
- Specific ask ("comment your count")
- Easy to participate (no login needed in mind)
- Mascot personality for charm
- Visual puzzle that screenshots well
- Scarcity / daily ("today's grid")

## Caption formula (EN)
Hook + visual puzzle description + clear CTA for comments + light brand + emoji.

Multi-lang versions should be added (he, es, sv, ja) for Stories or localized posts.
