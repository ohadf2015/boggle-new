# UX Writer Skill

**Purpose:** Create authentic, human-sounding content that doesn't feel AI-generated. Prevent generic, templated copy that readers recognize as artificial.

## Auto-Activation

This skill automatically activates when you're:
- Writing blog articles or marketing content
- Creating translations for multiple languages
- Writing product descriptions or landing pages
- Creating social media posts
- Any user-facing copy that represents the brand

## Core Principles

### 1. **Anti-AI Detection Rules**

**NEVER:**
- ❌ Use listicle formats ("10 Surprising Benefits", "7 Ways to...")
- ❌ Start with "Think X is just Y? Think again."
- ❌ Use predictable transitions like "Here are X reasons..."
- ❌ Include "Recent studies from 2024-2025" (sounds future-dated)
- ❌ End sections with generic CTAs like "Ready to transform your life?"
- ❌ Use marketing clichés ("game-changer", "unlock", "transform")
- ❌ Write in perfect, polished prose with no casual elements
- ❌ Include "Sources" lists at the end (screams AI)

**ALWAYS:**
- ✅ Break templates - use unexpected structures
- ✅ Add personal voice (anecdotes, opinions, questions)
- ✅ Vary sentence structure (mix short & long, formal & casual)
- ✅ Use specific examples instead of generic claims
- ✅ Include imperfections (digressions, admissions, uncertainty)
- ✅ Add conversational elements (parenthetical asides, questions)

### 2. **Human Voice Checklist**

Before finalizing any content, verify:

- [ ] **Personal Element**: Contains at least one personal anecdote or opinion
- [ ] **Imperfection**: Includes admission of uncertainty or limitation
- [ ] **Variation**: Sentence lengths vary significantly (3-word to 30-word sentences)
- [ ] **Questions**: Asks reader questions or poses rhetorical questions
- [ ] **Digression**: Contains at least one aside or tangent
- [ ] **Specificity**: Uses concrete numbers/examples instead of vague claims
- [ ] **Casual Elements**: Includes parenthetical asides or informal language
- [ ] **Unique Structure**: Doesn't follow predictable template

### 3. **Language-Specific Authenticity**

Each language should sound **native**, not **translated**:

#### **Hebrew (עברית)**
- Use **colloquial phrases**: "בואו נהיה כנים" (let's be honest), "רגע" (wait)
- **Personal pronouns**: Use 2nd person plural "אתם" for engagement
- **Casual connectors**: "אז" (so), "הנה מה" (here's what)
- **Questions**: "למה זה משנה?" (why does this matter?)
- **Cultural references**: Local examples, Israeli context
- **Avoid**: Literal translations from English structures

#### **English**
- Use **contractions**: "you're", "don't", "it's"
- **Informal tone**: "Here's the thing", "Wait, there's more"
- **Personal voice**: "I thought", "I was wrong"
- **Rhetorical questions**: "Why does this matter?"
- **Parenthetical asides**: "(I still don't understand how)"
- **Casual language**: Occasional mild profanity where appropriate ("bullshit")

#### **Swedish (Svenska)**
- Use **everyday Swedish**: "Tänk på det så här" (think of it this way)
- **Personal tone**: "Jag trodde" (I thought), "Vi säger" (let's say)
- **Questions**: "Varför spelar det roll?" (why does it matter?)
- **Avoid**: Formal business Swedish - use conversational tone
- **Cultural fit**: Swedish pragmatism, directness

#### **Japanese (日本語)**
- Use **natural Japanese**: Not textbook-formal
- **Casual particles**: "ね" (ne), "よ" (yo) where appropriate
- **Personal pronouns**: Consider context (私は less formal contexts)
- **Questions**: "なぜ？" (why?), "どうして？" (how come?)
- **Cultural sensitivity**: Japanese humility vs Western confidence
- **Avoid**: Direct translations of Western idioms

#### **Spanish (Español)**
- Use **informal tú**: Not formal usted
- **Colloquialisms**: "La verdad es que" (truth is), "Mira" (look)
- **Personal voice**: "Yo pensaba" (I thought)
- **Questions**: "¿Por qué importa?" (why does it matter?)
- **Cultural warmth**: Spanish expressiveness, emotion
- **Regional awareness**: Neutral Spanish, not region-specific slang

### 4. **Content Structure Anti-Patterns**

**AVOID These AI-Typical Structures:**

❌ BAD (AI-Generated):
```
# 10 Surprising Benefits of X

Think X is just Y? Think again. Recent studies from 2024-2025 reveal...

Here are 10 science-backed reasons to make X part of your daily routine.

1. **Benefit One**
   Research shows...

2. **Benefit Two**
   Studies indicate...
```

✅ GOOD (Human-Written):
```
# Why I Was Wrong About X (And What Changed My Mind)

I used to think X was just Y. Then I read a study that completely changed my perspective.

## What the Research Actually Found

Here's the interesting thing: most people assume...

[Personal anecdote about specific experience]

Wait, there's something surprising here:
[Concrete example with specific numbers]
```

### 5. **Specific Number Usage**

**Generic (AI):**
- "Recent studies show significant improvement"
- "Research indicates better results"

**Specific (Human):**
- "A 2023 study from Tel Aviv University found 23% improvement"
- "Participants improved by 1.3 seconds on average"

### 6. **Translation Philosophy**

**NEVER:**
- Literal word-for-word translation
- Maintain English idioms in other languages
- Use Google Translate phrasing

**ALWAYS:**
- Rewrite for target language
- Use native idioms and expressions
- Adapt cultural references
- Match natural speaking patterns

## Quality Checks

Before submitting ANY content:

### The "AI Detector" Test
Read it aloud. Does it sound like:
- [ ] A human speaking naturally?
- [ ] Someone you'd want to have a conversation with?

If no - **REWRITE**.

### The "Template" Test
- [ ] Would this structure work for any topic by just swapping words?

If yes - **RESTRUCTURE**.

### The "Boring" Test
- [ ] Would you actually read this if you found it online?
- [ ] Would you share this with a friend?

If no - **ENHANCE**.

## Common Mistakes to Avoid

1. **Over-Polishing**: Too perfect = AI-sounding
2. **Generic Enthusiasm**: "Amazing!", "Incredible!"
3. **No Contractions**: "Do not" → "Don't"
4. **Emoji Overuse**: One 💡 is fine. Five 🎉✨🚀💪🔥 is AI-territory
5. **Perfect Grammar**: Occasional fragments? Fine.

**Your goal:** Write like a knowledgeable human sharing something interesting, NOT like an AI summarizing research.

**The test:** Would you text this to a friend? If not, rewrite it.
