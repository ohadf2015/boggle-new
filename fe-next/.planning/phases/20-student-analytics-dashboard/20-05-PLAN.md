    ```typescript
    export type MasteryLevel = 'mastered' | 'practicing' | 'struggling' | 'not-started';

    export interface HeatmapCell {
      studentId: string;
      studentName: string;
      word: string;
      masteryLevel: MasteryLevel;
      accuracy: number;           // 0-100
      attempts: number;
    }

    export interface VocabularyHeatmapData {
      students: Array<{ id: string; name: string }>;
      words: string[];
      cells: HeatmapCell[];
    }

    export async function getVocabularyHeatmapData(
      classroomId: string,
      lessonId?: string
    ): Promise<{ data: VocabularyHeatmapData; error: { message: string } | null }>
    ```

    Mastery level calculation:
    - 'mastered': accuracy >= 80% AND attempts >= 3
    - 'practicing': accuracy 50-79% AND attempts >= 1
    - 'struggling': accuracy < 50% AND attempts >= 1
    - 'not-started': attempts = 0

    Implementation:
    1. Get classroom students via classroom_memberships + profiles
    2. Get student_lesson_progress for students
    3. Extract unique words from all words_attempted JSON
    4. Build cells array from words_attempted data
    5. Calculate mastery level per cell

    Tests:
    - returns empty data for classroom with no students
    - calculates mastery level correctly for each threshold
    - returns all unique words across students
    - filters by lessonId when provided
  </action>
