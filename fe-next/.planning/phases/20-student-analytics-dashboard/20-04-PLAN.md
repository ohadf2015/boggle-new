    ```typescript
    export interface LessonEffectivenessData {
      lessonId: string;
      lessonName: string;
      totalStudents: number;        // Students who attempted lesson
      averageXpGain: number;        // Mean XP earned from this lesson
      completionRate: number;       // % students who finished (has completed_at)
      averageAccuracy: number;      // Mean accuracy across all students
      avgTimeToMastery: number;     // Days from started_at to 80%+ accuracy (0 if none)
    }

    export async function getLessonEffectiveness(
      classroomId: string
    ): Promise<{ data: LessonEffectivenessData[]; error: { message: string } | null }>
    ```

    Implementation:
    1. Get all lessons assigned to this classroom via lesson_assignments
    2. Join with vocabulary_lessons for lesson name
    3. Get student_lesson_progress for all classroom students
    4. Aggregate per lesson:
       - totalStudents: count distinct students with progress record
       - averageXpGain: mean total_xp for that lesson
       - completionRate: count(completed_at not null) / totalStudents
       - averageAccuracy: calculate from words_attempted

    Tests:
    - returns empty array when no lessons assigned
    - calculates averageXpGain correctly
    - calculates completionRate as percentage
    - returns lesson name from vocabulary_lessons
