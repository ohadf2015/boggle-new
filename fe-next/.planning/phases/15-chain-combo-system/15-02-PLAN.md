  <files>components/animations/ComboTierBadge.tsx, components/animations/__tests__/ComboTierBadge.test.tsx</files>
  <action>
Create ComboTierBadge.tsx following patterns from ComboIntensityBadge.tsx:

**Component requirements:**

1. **Tier thresholds (exported as COMBO_TIERS):**
   - threshold: 0 → no badge
   - threshold: 2 → 'adventure.combo.nice', color: neo-lime, animate-neo-pop
   - threshold: 4 → 'adventure.combo.great', color: neo-cyan, animate-neo-wobble
   - threshold: 7 → 'adventure.combo.amazing', color: neo-orange, animate-neo-shake
   - threshold: 10 → 'adventure.combo.legendary', color: neo-pink, animate-neo-press

2. **Exported getComboTier(comboCount) helper:**
   - Returns tier config object for given combo count
   - Used by other components to determine current tier

3. **Visual design (Neo-Brutalist):**
   - Use rounded-neo, border-neo, shadow-hard classes
   - AnimatePresence mode="wait" for tier transitions
   - Spring animation on scale (stiffness: 300, damping: 20)
   - Exit animation: scale: 1.5, opacity: 0

4. **Device performance adaptation:**
   - Use useDevicePerformance hook
   - Skip animations for prefersReducedMotion
   - Fallback to static text for reduced motion

5. **RTL support:**
   - Use logical properties (ms-*, me-*, start, end)
   - Shadow flips handled by shadow-hard-* classes

**Props interface:**
```typescript
interface ComboTierBadgeProps {
  comboCount: number;
  position?: { x: number; y: number };
  className?: string;
  onTierChange?: (tier: ComboTier) => void;
}
```

**Test file requirements (ComboTierBadge.test.tsx):**
1. Renders nothing when comboCount < 2
2. Renders "Nice!" at comboCount = 2
3. Renders "Great!" at comboCount = 4
4. Renders "Amazing!" at comboCount = 7
5. Renders "LEGENDARY!" at comboCount = 10
6. Calls onTierChange when tier changes
7. Respects reduced motion preferences
8. Test getComboTier helper function directly
