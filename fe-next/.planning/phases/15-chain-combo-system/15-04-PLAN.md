Create a reusable hook for calculating cascade animation delays:

**Interface definitions:**
```typescript
export interface CascadeConfig {
  origin: { row: number; col: number };  // Chain tile position
  affectedIndices: number[];             // Tile indices to animate
  gridSize: number;                      // Grid dimension (4, 5, 6, or 7)
  staggerMs?: number;                    // Delay per tile (default: 50ms for chain, 30ms regular)
  animationType?: 'wave' | 'burst';      // Pattern type
}

export interface CascadeResult {
  delays: Map<number, number>;           // tileIndex -> delay in ms
  totalDuration: number;                 // Total animation time
  maxDelay: number;                      // Maximum individual delay
}
```

**Exported functions:**

1. **calculateCascadeDelays(config: CascadeConfig): CascadeResult**
   - Wave pattern: Distance-based from origin (Manhattan distance)
   - Burst pattern: Sequential timing for all affected tiles
   - Returns Map of tileIndex → delay
   - Handles grid edge cases (clamp to valid indices)

2. **useCascadeAnimation hook:**
   - Manages cascade state (isAnimating, currentDelays)
   - Accepts trigger function to start cascade
   - Returns: { startCascade, delays, isAnimating, reset }
   - Auto-clears delays after animation completes

**Wave calculation (for chain reactions):**
```typescript
if (config.animationType === 'wave') {
  for (const idx of config.affectedIndices) {
    const row = Math.floor(idx / config.gridSize);
    const col = idx % config.gridSize;
    // Manhattan distance from origin
    const distance = Math.abs(row - config.origin.row) + Math.abs(col - config.origin.col);
    delays.set(idx, distance * (config.staggerMs ?? 50));
  }
}
```

**Edge case handling:**
- Origin at (0,0): Only 3 adjacent tiles valid
- Origin at edge: 5 adjacent tiles valid
- Origin at center: All 8 adjacent tiles valid
