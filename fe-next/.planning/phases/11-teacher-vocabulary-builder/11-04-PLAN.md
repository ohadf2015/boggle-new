  <name>Vocabulary Word Selection Socket Events</name>
  <files>backend/handlers/vocabularyHandler.ts, backend/handlers/__tests__/vocabularyHandler.test.ts</files>
  <behavior>
Socket events for host vocabulary word selection:

Test cases:
1. Host emits 'selectVocabularyWord' {word: "CAT", include: true} in finished state
   -> Word added to game.selectedVocabulary Set
   -> Socket receives 'vocabularySelectionUpdated' with selectedWords array
   -> Each word includes canIntegrate boolean

2. Non-host emits 'selectVocabularyWord'
   -> Error emitted: "Only host can select vocabulary words"

3. Host emits in non-finished state (playing, waiting)
   -> Error emitted: "Can only select words after game ends"

4. Host emits {word: "CAT", include: false} to remove
   -> Word removed from selectedVocabulary
   -> Updated list emitted

5. Host emits 'saveVocabularyLesson' {name: "Lesson 1", classroomId: "uuid"}
   -> Lesson saved to database with all selected words
   -> 'vocabularyLessonSaved' emitted with lesson data

6. Invalid word (empty, undefined)
   -> Error emitted: "Invalid word"
  </behavior>
  <implementation>
1. Create test file following backend test patterns (mock socket, game state)
2. Write tests for each scenario using Jest
3. Implement vocabularyHandler.ts:
   - selectVocabularyWord: Toggle word in/out of selection
   - saveVocabularyLesson: Persist selection as lesson
   - getVocabularySelection: Return current selection
4. Extend Game type with selectedVocabulary: Set<string>
5. Register handler in socketSetup.ts
  </implementation>
</feature>
