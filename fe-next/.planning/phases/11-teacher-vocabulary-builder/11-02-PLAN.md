<feature>
  <name>Word Integration Check</name>
  <files>hooks/useWordIntegration.ts, hooks/__tests__/useWordIntegration.test.ts</files>
  <behavior>
Given a word and language, determine if it can be integrated into future game grids.

Test cases:
- "CAT" + "en" -> { canIntegrate: true, reason: undefined }
- "DOG" + "en" -> { canIntegrate: true, reason: undefined }
- "XYZABC" + "en" -> { canIntegrate: false, reason: "word_not_in_dictionary" }
- "SUPERCALIFRAGILISTIC" + "en" -> { canIntegrate: false, reason: "word_too_long" }
- "AB" + "en" -> { canIntegrate: false, reason: "word_too_short" }
- "שלום" + "he" -> { canIntegrate: true, reason: undefined } (if in Hebrew dictionary)
- Empty string -> { canIntegrate: false, reason: "word_empty" }
  </behavior>
  <implementation>
1. Create test file with Given-When-Then structure
2. Test each behavior case (empty, too short, too long, not in dictionary, valid)
3. Implement checkWordIntegration function that:
   - Normalizes word (lowercase, trim)
   - Validates length (3-12 chars)
   - Checks dictionary using existing isDictionaryWord from backend/dictionary
   - Returns { word, canIntegrate, reason? }
4. Create React hook wrapper useWordIntegration for batch checking
  </implementation>
</feature>
