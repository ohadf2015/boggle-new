  <action>
Create a new migration file with the following schema:

1. **user_role enum** (extend profiles):
   - CREATE TYPE user_role AS ENUM ('student', 'teacher', 'admin')
   - ALTER TABLE profiles ADD COLUMN user_role user_role DEFAULT 'student'
   - Migrate existing is_admin=true to user_role='admin'
   - Create index on user_role

2. **classrooms table**:
   - id UUID PRIMARY KEY DEFAULT gen_random_uuid()
   - teacher_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE
   - name TEXT NOT NULL (max 100 chars)
   - join_code TEXT UNIQUE NOT NULL (6 chars, auto-generated)
   - language TEXT DEFAULT 'en'
   - created_at, updated_at TIMESTAMPTZ
   - Create index on teacher_id, join_code

3. **classroom_memberships table**:
   - id UUID PRIMARY KEY DEFAULT gen_random_uuid()
   - classroom_id UUID NOT NULL REFERENCES classrooms(id) ON DELETE CASCADE
   - student_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE
   - joined_at TIMESTAMPTZ DEFAULT NOW()
   - UNIQUE(classroom_id, student_id)
   - Create indexes on classroom_id, student_id

4. **vocabulary_lessons table**:
   - id UUID PRIMARY KEY DEFAULT gen_random_uuid()
   - teacher_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE
   - classroom_id UUID REFERENCES classrooms(id) ON DELETE SET NULL
   - name TEXT NOT NULL (max 100 chars)
   - description TEXT (max 500 chars)
   - language TEXT NOT NULL DEFAULT 'en'
   - words JSONB NOT NULL DEFAULT '[]' (array of {word, definition?, canIntegrate})
   - is_public BOOLEAN DEFAULT FALSE
   - source_game_code TEXT (nullable - for lessons created from games)
   - created_at, updated_at TIMESTAMPTZ
   - Create indexes on teacher_id, classroom_id

5. **lesson_assignments table**:
   - id UUID PRIMARY KEY DEFAULT gen_random_uuid()
   - lesson_id UUID NOT NULL REFERENCES vocabulary_lessons(id) ON DELETE CASCADE
   - classroom_id UUID NOT NULL REFERENCES classrooms(id) ON DELETE CASCADE
   - due_date TIMESTAMPTZ (nullable)
   - created_at TIMESTAMPTZ DEFAULT NOW()
   - UNIQUE(lesson_id, classroom_id)

6. **student_lesson_progress table**:
   - id UUID PRIMARY KEY DEFAULT gen_random_uuid()
   - student_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE
   - lesson_id UUID NOT NULL REFERENCES vocabulary_lessons(id) ON DELETE CASCADE
   - assignment_id UUID REFERENCES lesson_assignments(id) ON DELETE SET NULL
   - words_attempted JSONB DEFAULT '{}' (map of word -> {attempts, correct, lastAttemptAt})
   - words_mastered TEXT[] DEFAULT '{}'
   - started_at TIMESTAMPTZ DEFAULT NOW()
   - completed_at TIMESTAMPTZ (nullable)
   - UNIQUE(student_id, lesson_id)

7. **Helper functions**:
   - is_teacher_of_student(p_student_id UUID) RETURNS BOOLEAN - checks classroom membership
   - generate_join_code() RETURNS TEXT - generates 6-char alphanumeric code

8. **RLS Policies** (CRITICAL - follow existing patterns from adventure_mode.sql):
   - classrooms: Teachers can CRUD own classrooms
   - classroom_memberships: Teachers can manage own classroom members, students can join/leave
   - vocabulary_lessons: Teachers can CRUD own lessons, students can view assigned lessons
   - lesson_assignments: Teachers can CRUD assignments for own lessons
   - student_lesson_progress: Students can view/update own progress, teachers can view students in their classrooms

9. **Triggers**:
   - update_updated_at for classrooms, vocabulary_lessons
   - Auto-generate join_code on classroom insert

Follow the exact formatting and comment patterns from 049_adventure_mode.sql.
