  <action>
    Create hook that returns appropriate particle budget based on device performance.

    Interface:
    ```typescript
    const PARTICLE_BUDGETS = {
      low: { max: 30, combo: 5, levelUp: 20, word: 3 },
      medium: { max: 60, combo: 10, levelUp: 40, word: 6 },
      high: { max: 100, combo: 15, levelUp: 60, word: 10 },
    } as const;

    type ParticleTier = 'low' | 'medium' | 'high';

    interface ParticleBudget {
      tier: ParticleTier;
      max: number;
      combo: number;
      levelUp: number;
      word: number;
    }

    function useParticleBudget(): ParticleBudget;
    ```

    Implementation:
    - Use useDevicePerformance to get device tier
    - Map device capabilities to particle tier:
      - isLowEnd || prefersReducedMotion -> 'low' (0 if reducedMotion)
      - reduceParticles -> 'medium'
      - else -> 'high'
    - Return appropriate budget object

    Tests (write first, TDD):
    - Returns 'high' budget for high-end devices
    - Returns 'medium' budget for mid-range devices
    - Returns 'low' budget for low-end devices
    - Returns 0 particles for reduced motion preference
  </action>
