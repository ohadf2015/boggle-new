  <behavior>
    Gold economy with sources and sinks:

    Sources:
    - calculateLevelGold(level, difficulty, stars) -> number
      - Base: 50 * 1.2^level
      - Difficulty multiplier: easy(0.8), normal(1.0), hard(1.5)
      - Star bonus: +10% per star (1-3 stars)

    Sinks:
    - STAT_UPGRADES config:
      - timeBonus: +10% time per stack, base cost 500, max 5 stacks
      - scoreBonus: +5% score per stack, base cost 750, max 5 stacks
      - xpBonus: +10% XP per stack, base cost 1000, max 5 stacks

    - getUpgradeCost(upgradeId, currentStacks) -> number
      - Exponential: baseCost * 1.5^currentStacks

    - purchaseUpgrade(upgradeId, currentGold, currentStacks) -> PurchaseResult
      - Returns { success: true, newGold, newStacks } or { success: false, error }
      - Validates: sufficient gold, under max stacks
  </behavior>
