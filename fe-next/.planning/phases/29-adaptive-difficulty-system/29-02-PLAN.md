  <name>Tier Assigner Logic</name>
  <files>lib/adaptiveDifficulty/tierAssigner.ts, lib/adaptiveDifficulty/__tests__/tierAssigner.test.ts</files>
  <behavior>
    Pure function to determine difficulty tier from recent attempt history.

    **Types (in tierAssigner.ts or types/difficulty.ts):**
    - TierDecision: { tier: DifficultyTier, reason: string }

    **Constants (add to constants.ts if needed):**
    - FAILURE_THRESHOLD: 2 (failures in window to trigger downgrade)
    - HIGH_SCORE_THRESHOLD: 0.8 (combined score for mastery)
    - WINDOW_SIZE: 3 (matches ROLLING_WINDOW_SIZE)

    **Function: determineTier(recentAttempts: LevelAttemptWithScore[]): TierDecision**

    Logic (in order of priority):
    1. If fewer than 3 attempts: return { tier: 'normal', reason: 'insufficient_data' }
    2. Count failures: attempts.filter(a => !a.isCompletion).length
       - If failureCount >= 2: return { tier: 'easy', reason: 'high_failure_rate' }
    3. Check for mastery: all 3 completed AND all 3 have combinedScore > 0.8
       - If mastery: return { tier: 'hard', reason: 'consistent_mastery' }
    4. Default: return { tier: 'normal', reason: 'balanced_performance' }

    Test Cases:
    - Empty array -> normal (insufficient_data)
    - [win, win] -> normal (insufficient_data, only 2 attempts)
    - [win, fail, fail] -> easy (high_failure_rate)
    - [fail, fail, win] -> easy (high_failure_rate)
    - [win(0.9), win(0.85), win(0.82)] -> hard (consistent_mastery)
    - [win(0.9), win(0.85), win(0.75)] -> normal (one score below threshold)
    - [win(0.6), win(0.7), win(0.65)] -> normal (completed but low scores)
    - [win(0.9), win(0.9), fail] -> easy (failure trumps high scores)
  </behavior>
