<task type="checkpoint:human-verify" gate="blocking">
  <what-built>
    Complete adaptive difficulty system integrated into AdventureGame:
    - Invisible tier assignment based on rolling window performance
    - Easy tier: +20% timer, -20% score targets
    - Hard tier: -15% timer, +50% power-up cooldowns
    - Boss levels excluded from adjustments
    - Progressive hints after 3+ failures on same level
    - Hint messages displayed using translations
  </what-built>
  <how-to-verify>
    1. Start dev server: `npm run dev`
    2. Open http://localhost:3000/adventure

    **Test Easy Tier (simulate struggles):**
    1. Clear localStorage: `localStorage.removeItem('lexiclash_difficulty_tier')`
    2. Start World 1 Level 1
    3. Fail intentionally 2-3 times (let timer run out)
    4. Start another level
    5. Check localStorage: `localStorage.getItem('lexiclash_difficulty_tier')`
       - Should show tier: 'easy'
    6. Note the timer duration (should be ~20% longer than base 90s = ~108s)

    **Test Hard Tier (simulate mastery):**
    1. Set tier manually: `localStorage.setItem('lexiclash_difficulty_tier', '{"tier":"hard","updatedAt":"2026-01-31"}')`
    2. Start a level
    3. Note timer duration (should be ~15% shorter than base)
    4. Activate a power-up, note cooldown duration (should be 90s, not 60s)

    **Test Boss Exclusion:**
    1. Navigate to World 1 Level 7 (boss level)
    2. Even with easy/hard tier, timer should be base duration
    3. Boss battles should feel consistent regardless of tier

    **Test Hint Escalation:**
    1. Start any level
    2. Fail 3 times on SAME level (refresh doesn't count - must be consecutive attempts)
    3. On 4th attempt, look for hint UI showing word length
    4. On 5th attempt, look for highlighted starting tile
    5. Verify hint message is displayed (translated text)

    **Test Hint UI Rendering:**
    1. Trigger hint by failing 3+ times
    2. Verify hint message appears on screen
    3. Test in Hebrew locale (?locale=he) - verify RTL and translated text
    4. Verify hint styling matches neo-brutalist theme

    **Critical checks:**
    - [ ] No "Easy Mode" or tier indicator visible in UI
    - [ ] Tier changes are completely invisible to player
    - [ ] Boss levels feel consistent (not easier/harder)
    - [ ] Power-up cooldowns visibly longer on hard tier
    - [ ] Hints appear after multiple failures on same level
    - [ ] Hint messages are displayed and translated
    - [ ] Hint highlighting visible on grid (if implemented)
  </how-to-verify>
  <resume-signal>Type "approved" if all checks pass, or describe issues found</resume-signal>
