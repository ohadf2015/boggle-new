  <behavior>
    Pure functions for calculating combined performance score and managing rolling window.

    **Types (types/difficulty.ts):**
    - PerformanceMetrics: { completionRate: number (0-1), timeEfficiency: number (0-1), wordAccuracy: number (0-1) }
    - DifficultyTier: 'easy' | 'normal' | 'hard'
    - LevelAttemptWithScore: Extends LevelAttempt with combinedScore field

    **Constants (lib/adaptiveDifficulty/constants.ts):**
    - COMBINED_SCORE_WEIGHTS: { completion: 0.5, time: 0.3, accuracy: 0.2 }
    - ROLLING_WINDOW_SIZE: 3
    - HIGH_SCORE_THRESHOLD: 0.8

    **Functions (lib/adaptiveDifficulty/performanceTracker.ts):**

    1. calculateCombinedScore(metrics: PerformanceMetrics): number
       - Weighted sum: (completionRate * 0.5) + (timeEfficiency * 0.3) + (wordAccuracy * 0.2)
       - Returns 0-1 range
       - Cases:
         - Perfect level (1, 1, 1) -> 1.0
         - Failed level (0, 0.5, 0.8) -> 0.31 (0 + 0.15 + 0.16)
         - Average level (1, 0.5, 0.6) -> 0.77 (0.5 + 0.15 + 0.12)

    2. calculateMetrics(attempt: { isCompletion: boolean, timeRemaining: number, timerSeconds: number, score: number, words: number }): PerformanceMetrics
       - completionRate: isCompletion ? 1 : 0
       - timeEfficiency: timeRemaining / timerSeconds (clamped 0-1)
       - wordAccuracy: words > 0 ? Math.min(score / (words * 100), 1) : 0
       - Cases:
         - Completed with 30s left of 90s, 450 score, 5 words -> { 1, 0.33, 0.9 }
         - Failed with 0s left, 200 score, 3 words -> { 0, 0, 0.67 }

    3. getRecentAttempts(attempts: LevelAttemptWithScore[], excludeBossLevels: boolean): LevelAttemptWithScore[]
       - Returns last ROLLING_WINDOW_SIZE (3) attempts
       - If excludeBossLevels=true, filters out attempts where level === 7 (boss levels)
       - Sorted by timestamp descending, returns most recent first
  </behavior>
