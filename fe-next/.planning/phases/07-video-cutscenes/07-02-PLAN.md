Create the WorldTransition composition with sequenced phases:

**types.ts:**
```typescript
import { z } from 'zod';

export const WorldTransitionSchema = z.object({
  fromWorldId: z.enum(['meadows', 'springs', 'caverns']),
  toWorldId: z.enum(['meadows', 'springs', 'caverns']),
  locale: z.enum(['en', 'he', 'sv', 'ja']),
});

export type WorldTransitionProps = z.infer<typeof WorldTransitionSchema>;
```

**index.tsx:**
- Import `AbsoluteFill`, `Sequence`, `useCurrentFrame`, `staticFile` from 'remotion'
- Import PortalAnimation from './PortalAnimation'
- Import fadeIn, fadeOut from shared utils
- Duration: 360 frames (12 seconds at 30fps)

Three-phase sequence structure:
1. **Phase 1: Old world fades out** (frames 0-90, 3s)
   - Show fromWorld background at full opacity
   - Fade out from frame 60-90

2. **Phase 2: Portal animation** (frames 60-300, 8s, overlaps)
   - PortalAnimation component centered
   - Starts after old world begins fading
   - Portal grows and rotates

3. **Phase 3: New world fades in** (frames 240-360, 4s)
   - Show toWorld background
   - Fade in from frame 240-270
   - Hold at full opacity until end

World background helper:
```typescript
const WorldBackground = ({ worldId, opacity }: { worldId: string; opacity: number }) => (
  <AbsoluteFill style={{ opacity }}>
    <div
      style={{
        width: '100%',
        height: '100%',
        backgroundImage: `url(${staticFile(`images/adventure/backgrounds/${worldId}.webp`)})`,
        backgroundSize: 'cover',
        backgroundPosition: 'center',
      }}
    />
  </AbsoluteFill>
);
```

Neo-navy fallback background: `#1a1a2e`
No text overlays for transitions (purely visual as per CONTEXT.md).
