  <action>
Create the tutorial step component with highlight and text:

**TutorialStep.tsx:**
Props:
- `text: string` - instruction text
- `locale: string` - for RTL detection
- `highlightType: 'swipe' | 'word' | 'score'` - determines highlight style

Uses `useCurrentFrame()` for animations:
1. Text fade in: frames 0-20 (opacity 0 -> 1)
2. Highlight box pulse: continuous sine wave animation
   - `pulseScale = 1 + 0.05 * Math.sin(frame * 0.1)` (subtle 5% pulse)

Visual elements:
1. **Highlight box** (centered)
   - Width: 400px, Height: 200px
   - Border: 4px solid neo-yellow (#FFE135)
   - Border radius: 4px (rounded-neo)
   - Shadow: '4px 4px 0px black' (shadow-hard)
   - Transform: scale(pulseScale)

2. **Instruction text** (below or inside highlight)
   - Font: Fredoka for LTR, Rubik for Hebrew
   - Font size: 48px
   - Color: white (#FFFFFF)
   - Text shadow: '4px 4px 0px black'
   - RTL: `dir="rtl"` and `textAlign: 'right'` when locale is 'he'

3. **Visual icon** (optional, inside highlight box)
   - swipe: arrow gesture icon (simple SVG or emoji)
   - word: checkmark icon
   - score: plus/points icon

Keep icons simple - can be CSS shapes or basic SVG paths.
