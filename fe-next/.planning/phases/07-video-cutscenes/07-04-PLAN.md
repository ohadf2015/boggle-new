<task type="auto">
  <name>Task 2: Create render-cutscenes.sh script</name>
  <files>
    scripts/render-cutscenes.sh
  </files>
  <action>
Create comprehensive batch rendering script:

**Script requirements:**
- Exit on error (set -e)
- Configuration variables for FPS, dimensions, CRF quality, output directory
- Arrays for worlds (meadows, springs, caverns) and locales (en, he, sv, ja)
- Valid transitions array (meadows:springs, springs:caverns)
- Progress counter showing current/total

**Render loops:**
1. Level intros: 3 worlds x 4 locales = 12 videos
   - Output: `level-intro-${world}-${locale}.mp4`
2. World transitions: 2 transitions x 4 locales = 8 videos
   - Output: `transition-${from}-${to}-${locale}.mp4`
3. Tutorials: 4 locales = 4 videos
   - Output: `tutorial-${locale}.mp4`

**Render command template:**
- Use `npx remotion render` with remotion/index.ts entry
- Pass composition ID and props as JSON
- Use H.264 codec (--codec=h264) for iOS Safari compatibility
- Use CRF 23 for quality/size balance
- Use --log=error for cleaner output

**Summary output:**
- Total file count
- Total size of rendered videos
- List all generated files

Make script executable with chmod +x.
  </action>
  <verify>
```bash

```
  </verify>
