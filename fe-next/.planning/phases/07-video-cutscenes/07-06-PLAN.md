  <name>Task 1: Create useTutorialState hook</name>
  <files>
    hooks/useTutorialState.ts
  </files>
  <action>
Create hook for tracking cutscene viewed state:

**Storage keys:**
- `lexiclash:tutorial:viewed` - boolean for tutorial
- `lexiclash:world-intro:viewed` - JSON array of viewed world IDs
- `lexiclash:world-transition:viewed` - JSON array of transition pairs

**useTutorialState hook:**
- Returns: `{ hasViewedTutorial: boolean, markTutorialViewed: () => void }`
- On mount: check localStorage for TUTORIAL_VIEWED
- `markTutorialViewed`: set localStorage, update state
- Handle SSR: return false during hydration, read on client

**useWorldIntroState hook:**
- Signature: `useWorldIntroState(worldId: string)`
- Returns: `{ hasViewedIntro: boolean, markIntroViewed: () => void }`
- Storage: JSON array of viewed world IDs (e.g., ["meadows", "springs"])

**useWorldTransitionState hook:**
- Signature: `useWorldTransitionState(fromWorldId: string, toWorldId: string)`
- Returns: `{ hasViewedTransition: boolean, markTransitionViewed: () => void }`
- Storage: JSON array of transition pairs (e.g., ["meadows->springs", "springs->caverns"])

All hooks must:
- Handle SSR gracefully (no localStorage access during SSR)
- Use useEffect for initial localStorage read
- Memoize callbacks with useCallback
- Export types for external use

Implement world unlock detection mechanism for transition cutscenes:

2. Detect world unlock condition:
   - Calculate if completing this level unlocks a new world
   - Use existing `isWorldUnlocked` from '@/lib/adventure'
   - Compare current stars + new stars against next world's requirement
   - World unlock mapping:
     - World 1 (meadows) complete -> World 2 (springs) unlocks
     - World 2 (springs) complete -> World 3 (caverns) unlocks

3. In LevelCompleteModal, when onContinue is called:
   - Check if this completion unlocks a new world
   - If yes, call `onWorldUnlock(currentWorldId, nextWorldId)` before `onContinue()`
   - Pass world IDs as strings: 'meadows', 'springs', 'caverns'

**Step 2: Handle world unlock in WorldMap**

1. Import useWorldTransitionState from '@/hooks/useTutorialState'
2. Add state: `pendingTransition: { from: string, to: string } | null`

3. Add handler for world unlock (passed down to LevelCompleteModal via context or prop drilling):
   ```
   handleWorldUnlock(fromWorldId, toWorldId):
     - Check if transition has been viewed via hasViewedTransition
     - If not viewed, set pendingTransition = { from, to }
     - If viewed, skip directly to new world
   ```

4. Render CutscenePlayer when pendingTransition is set:
   - type: "transition"
   - fromWorldId: pendingTransition.from
   - toWorldId: pendingTransition.to
   - onComplete: markTransitionViewed(), setPendingTransition(null), navigate to new world
   - onSkip: markTransitionViewed(), setPendingTransition(null), navigate to new world
   - allowSkipAfterMs: 2000

**Step 3: Wire up the callback chain**

The callback flow:
1. Player completes level 10 (last level in meadows)

4. WorldMap receives callback, checks if transition viewed
5. If not viewed, shows transition cutscene
6. After cutscene, navigates to springs world

Note: The exact callback mechanism depends on how WorldMap and LevelCompleteModal
