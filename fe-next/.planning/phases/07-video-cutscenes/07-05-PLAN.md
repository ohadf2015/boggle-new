  <name>Task 1: Create CutscenePlayer component</name>
  <files>
    components/video/CutscenePlayer.tsx
  </files>
  <action>
Create the CutscenePlayer component:

**Props interface:**
- `type: 'level-intro' | 'transition' | 'tutorial'` - cutscene type
- `worldId?: 'meadows' | 'springs' | 'caverns'` - for level-intro
- `fromWorldId?: 'meadows' | 'springs' | 'caverns'` - for transition
- `toWorldId?: 'meadows' | 'springs' | 'caverns'` - for transition
- `onComplete?: () => void` - called when video ends naturally
- `onSkip?: () => void` - called when user skips
- `allowSkipAfterMs?: number` - delay before skip button appears (default: 2000 for intros, 0 for tutorial)
- `testMode?: boolean` - shows video path instead of playing

**Video path construction:**
- level-intro: `/videos/cutscenes/level-intro-${worldId}-${locale}.mp4`
- transition: `/videos/cutscenes/transition-${fromWorldId}-${toWorldId}-${locale}.mp4`
- tutorial: `/videos/cutscenes/tutorial-${locale}.mp4`

**Skip button behavior:**
- Default: 2000ms delay for level-intro and transition
- Tutorial: 0ms (immediately skippable per CONTEXT.md requirement)
- Use `allowSkipAfterMs` prop to override

**iOS Safari compatibility (CRITICAL):**
- Video element must have: `autoPlay`, `muted`, `playsInline` attributes
- All three required for automatic playback on iOS

**State management:**
- `canSkip: boolean` - controlled by timer based on allowSkipAfterMs
- `isSkipped: boolean` - prevents double callback invocation

**Event handlers:**
- `handleEnded`: calls `onComplete()` if not skipped
- `handleSkip`: sets `isSkipped`, calls `onSkip()`

**UI layout:**
- Full-screen overlay: fixed positioning, z-50, neo-navy background
- Video: full width/height with object-cover
- Skip button: top-right corner (RTL: top-left), neo-brutalist styling
  - Neo-yellow background, black text, hard shadow
  - Animate in with neo-pop animation

**RTL support:**
- Skip button position flips in RTL mode (Hebrew)
- Use locale from LanguageContext or detect from locale prop

**Reduced motion:**
- Check `prefers-reduced-motion` media query
- If reduced motion preferred, show static image fallback or skip video entirely
