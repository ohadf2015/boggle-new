2. Import useDevicePerformance hook for adaptive animation
3. Convert tile div elements to motion.div with enhanced spring animations

**Spring animation parameters (from research):**
- Stiffness: 300 (quick response)
- Damping: 20 (slight overshoot for bounce feel)
- Mass: 0.5 (light, punchy feel)

**Animation states:**
- **Default:** scale: 1, rotate: 0
- **Selected:** scale: 1.1, y: -2, rotate: [0, -2, 2, 0] (subtle wobble)
- **Just selected (entry):** scale: [0.95, 1.15, 1.1] (pop effect)

Replace the current static `scale-105` class with dynamic Framer Motion animation:

```tsx
<motion.div
  key={tile.id}
  data-row={tile.row}
  data-col={tile.col}
  role="gridcell"
  // ... existing props
  animate={{
    scale: isSelected ? 1.1 : 1,
    y: isSelected ? -2 : 0,
    rotate: isSelected ? [0, -2, 2, 0] : 0,
  }}
  transition={{
    type: 'spring',
    stiffness: 300,
    damping: 20,
    mass: 0.5,
    rotate: { duration: 0.3 }
  }}
  whileTap={{ scale: 0.95 }}
  // ... children
/>
```

4. For reduced motion: skip animation, use immediate state change
5. Remove the static `scale-105` class from selected state (Framer handles it)
