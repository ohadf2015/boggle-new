## Goal

Auto-promote Wikipedia word candidates with score ≥80 to the game dictionary (`community_words`) during the validation pipeline, making them immediately available for gameplay.

## Context

**Current State:**
- `populateWikipediaWords()` validates top 10 candidates with AI
- `validateWordWithAI()` calls `gameAIService.validateAndSaveWord()` which DOES save to `community_words`
- BUT: Only top 10 candidates get validated; the rest remain stuck in staging table
- High-scoring candidates (≥80) that pass validation should auto-promote without admin intervention

**Key Insight from Research:**
The `validateAndSaveWord()` function already saves valid words to `community_words`. The problem is:
1. Only top 10 candidates are validated
2. Remaining candidates stay in `wikipedia_word_candidates` with status='pending' forever

**Solution:**
After AI validation in `validateTopCandidates()`, explicitly promote validated high-scoring candidates to ensure they reach `community_words`.

## Requirements Coverage

- **FIX-01**: Wikipedia word extraction pipeline working (partial: completes the pipeline)
- **FIX-02**: Words sync from admin dashboard to game dictionary (partial: enables auto-sync)

## must_haves

Derived from phase goal "Wikipedia word extraction pipeline reliably syncs curated words to game dictionary":

1. Validated words with score ≥80 automatically appear in `community_words` table
2. Words in `community_words` are recognized during gameplay validation
3. Auto-promotion only occurs for words that pass AI validation
4. Duplicate words (already in dictionary) are handled gracefully without errors
5. Auto-promotion has logging for monitoring/debugging

```typescript
// Minimum score threshold for auto-promotion to dictionary
// Words >= this score that pass AI validation are automatically added to community_words
const AUTO_PROMOTION_SCORE_THRESHOLD = 80;

/**
 * Check if a word already exists in the game dictionary (community_words)
 * to avoid duplicate insertion errors
 */
async function isWordInDictionary(
  word: string,
  language: Language
): Promise<boolean> {
  try {
    const { gameAIService } = await import('@/lib/ai-service');
    const result = await gameAIService.checkDatabaseOnly(word, language);
    return result.source === 'database' && result.isValid;
  } catch (error) {
    console.warn(`[WikiPopulator] Dictionary check failed for ${word}:`, error);
    return false;
  }
}
```

<task id="08-01-03" type="implement">
**Modify validateTopCandidates to auto-promote high-scoring words**

Update `validateTopCandidates()` in `backend/services/wikipediaWordPopulator.ts`:

```typescript
async function validateTopCandidates(
  candidates: Array<{ word: string; score: number; source: string; url?: string }>,
  language: Language,
  dateStr: string
): Promise<Array<{ word: string; score: number; source: string; url?: string }>> {
  const validated: Array<{ word: string; score: number; source: string; url?: string }> = [];

  // Validate top 10 candidates
  for (const candidate of candidates.slice(0, 10)) {
    try {
      const result = await validateWordWithAI(candidate.word, language);

      if (result.valid) {
        validated.push(candidate);
        await updateWordValidationStatus(language, candidate.word, dateStr, 'valid', candidate.score);

        // AUTO-PROMOTION: High-scoring validated words go directly to dictionary
        if (candidate.score >= AUTO_PROMOTION_SCORE_THRESHOLD) {
          // Check if word already exists to avoid duplicate errors
          const alreadyInDict = await isWordInDictionary(candidate.word, language);

          if (!alreadyInDict) {
            try {
              const { gameAIService } = await import('@/lib/ai-service');
              await gameAIService.validateAndSaveWord(candidate.word, language);
              console.log(`[WikiPopulator] Auto-promoted ${candidate.word} (score: ${candidate.score}) to dictionary`);
            } catch (promoError) {
              // Log but don't fail - word is still validated
              console.warn(`[WikiPopulator] Auto-promotion failed for ${candidate.word}:`, promoError);
            }
          } else {
            console.log(`[WikiPopulator] Word ${candidate.word} already in dictionary, skipping promotion`);
          }
        }
      } else {
        await updateWordValidationStatus(language, candidate.word, dateStr, 'invalid');
      }

    } catch (error) {
      // On AI validation error, assume valid if it passed basic validation
      console.warn(`[WikiPopulator] AI validation failed for ${candidate.word}, assuming valid`);
      validated.push(candidate);
    }
  }

  return validated;
}
```

## Edge Cases Handled

1. **Duplicate words**: Check before promotion, skip if already exists
2. **AI validation timeout**: Word still validated but promotion skipped
3. **Database errors**: Logged but don't break the pipeline
4. **Low-scoring words**: Not promoted even if they pass validation

## Rollback Plan

If issues discovered:
1. Lower threshold to 85 or 90 (more conservative)
2. Or disable by setting threshold to 101 (nothing qualifies)
3. Words already promoted remain valid (no harm)
