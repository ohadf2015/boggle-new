Create the LevelUpCelebration component following existing modal patterns:

**Component Interface:**
```typescript
interface LevelUpPayload {
  oldLevel: number;
  newLevel: number;
  newTitles?: string[];  // Titles unlocked at this level
}

interface LevelUpCelebrationProps {
  levelUpData: LevelUpPayload | null;  // null = hidden
  onClose: () => void;
}
```

**Implementation Details:**

1. Modal overlay with AnimatePresence:
   ```typescript
   <AnimatePresence>
     {levelUpData && (
       <motion.div
         className="fixed inset-0 z-[300] flex items-center justify-center bg-neo-black/80"
         initial={{ opacity: 0 }}
         animate={{ opacity: 1 }}
         exit={{ opacity: 0 }}
         onClick={onClose}
       >
   ```

2. Modal card (neo-brutalist):
   ```typescript
   <motion.div
     className="bg-neo-navy border-4 border-neo-black rounded-neo shadow-hard-lg p-8 max-w-md mx-4"
     initial={{ scale: 0, rotate: -5 }}
     animate={{ scale: 1, rotate: 0 }}
     exit={{ scale: 0, rotate: 5 }}
     transition={{ type: 'spring', stiffness: 300, damping: 20 }}
     onClick={(e) => e.stopPropagation()}
   >
   ```

3. Content structure:
   - Celebration emoji (animated): Party popper (🎉) with scale/rotate animation
   - Title: t('education.xp.levelUp') in neo-yellow
   - Level display: "You reached level X" with newLevel highlighted in neo-orange
   - Title unlock section (if newTitles.length > 0):
     - Background: `bg-neo-orange/20 border-2 border-neo-orange`
     - Text: t('education.xp.newTitleUnlocked')
     - Title name displayed prominently
   - Continue button (neo-brutalist):
     - `bg-neo-yellow hover:bg-neo-orange border-3 border-neo-black`
     - `shadow-hard hover:shadow-hard-pressed active:shadow-hard-pressed`

4. Confetti integration:
   ```typescript
   useEffect(() => {
     if (levelUpData) {
       fireConfetti({
         particleCount: 100,
         spread: 70,
         origin: { y: 0.6 },
         colors: ['#FFE135', '#FF6B35', '#00FFFF', '#FF1493'], // Neo-brutalist palette
       });
     }
   }, [levelUpData]);
   ```

5. Accessibility:
   - Focus trap within modal
   - Escape key closes modal
   - aria-modal="true"
   - aria-labelledby for title

6. i18n:
   - Use t('education.xp.levelUp') for title
   - Use t('education.xp.newLevel') for level text
   - Use t('education.xp.newTitleUnlocked') for title unlock
   - Use t('education.xp.continue') or t('common.continue') for button
