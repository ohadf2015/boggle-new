**Hook Interface:**
```typescript
interface UseEducationXpOptions {
  studentId: string;
  lessonId: string;
  initialXp?: number;
  initialLevel?: number;
  initialStreak?: number;
}

interface UseEducationXpReturn {
  // State
  totalXp: number;
  currentLevel: number;
  xpProgress: XpProgress;  // from xpManager.ts
  streak: DailyStreak;     // from streaks.ts

  // Actions
  awardPracticeXp: (session: PracticeSessionXp) => Promise<{
    totalXp: number;
    breakdown: Record<string, number>;
    masteryMessage: string;
    leveledUp: boolean;
  }>;

  // Loading/error state
  isLoading: boolean;
  error: Error | null;
}
```

**Implementation Details:**

1. State management:
   - Use useState for totalXp, currentLevel, streak
   - Use useMemo for xpProgress (derived from totalXp via getXpProgress)
   - Track pending XP (batched updates pattern from research)

2. awardPracticeXp function:
   - Call calculatePracticeXp from educationXpManager
   - Update streak using updateDailyStreak from streaks.ts
   - Apply streak bonus to XP calculation
   - Check for level up using checkLevelUp from xpManager.ts
   - Return result with leveledUp flag

3. Database persistence (optimistic update pattern):
   - Update local state immediately (optimistic)
   - Queue Supabase update in background
   - Rollback on error
   - NOTE: Actual Supabase calls will be wired in Plan 05 (integration)
         For now, export the pending update for external persistence

4. Streak milestone detection:
   - Call getStreakMilestone from streaks.ts
   - Include milestone in return if hit

**Tests to write:**
- Initial state from options
- awardPracticeXp updates totalXp correctly
- Level up detected when XP crosses threshold
- Streak bonus applied correctly
- XpProgress recalculated when totalXp changes
- Error handling for invalid session data

IMPORTANT: Keep hook focused on state management. Database persistence will be wired in integration plan (18-05).
