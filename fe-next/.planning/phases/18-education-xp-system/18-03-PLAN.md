**Component Interface:**
```typescript
interface XpProgressBarProps {
  totalXp: number;
  recentXpGain?: number;  // Highlight recent XP gain with pulse effect
  showLevel?: boolean;     // Default true - show level number
  showNextLevel?: boolean; // Default true - show "Next Level" preview
  size?: 'sm' | 'md' | 'lg'; // Default 'md'
}
```

**Implementation Details:**

1. Use getXpProgress from xpManager.ts for calculations:
   - currentLevel
   - xpInCurrentLevel
   - xpNeededForNextLevel
   - progressPercent
   - isMaxLevel

2. Neo-brutalist styling (CRITICAL - follow design system):
   - Container: `bg-neo-navy border-3 border-neo-black rounded-neo shadow-hard`
   - Progress fill: `bg-neo-yellow border-r-3 border-neo-black`
   - Text: `font-neo-display` for level, `font-neo-body` for XP text
   - Height: sm=24px, md=32px, lg=40px

3. Framer Motion animations:
   - Progress bar fill: `initial={{ width: 0 }}` `animate={{ width: progressPercent% }}`
   - Transition: `duration: 0.8, ease: 'easeOut'`
   - Recent XP gain pulse: `animate={{ opacity: [1, 0] }}` over 1.2s

4. Layout structure:
   ```
   [Level display row]
   Level: X                          Y / Z XP

   [Progress bar container]
   ████████████░░░░░░░░░░░░  45%

   [Next level preview]
   Next Level: X+1
   ```

5. RTL support:
   - Use `dir="auto"` or check language context
   - Progress bar should fill right-to-left for Hebrew
   - Use `rtl:` Tailwind variants where needed

6. Reduced motion:
   - Check `prefers-reduced-motion`
   - Skip animations if reduced motion preferred
