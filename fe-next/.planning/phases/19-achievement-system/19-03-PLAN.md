Create useAchievementUnlock hook:

**Interface:**
```typescript
interface UnlockPayload {
  achievementKey: string;
  tier: 'bronze' | 'silver' | 'gold' | 'platinum';
  icon: string;
  isNew: boolean; // First time earning this achievement
  isUpgrade: boolean; // Upgraded to higher tier
  nameKey: string; // Translation key
  descriptionKey: string; // Translation key
}

interface UseAchievementUnlockOptions {
  studentId: string;
  enabled?: boolean; // Default: true
}

interface UseAchievementUnlockReturn {
  pendingUnlocks: UnlockPayload[];
  currentUnlock: UnlockPayload | null;
  acknowledgeUnlock: () => void; // Dismiss current, show next
  checkForUnlocks: (newProgress: StudentProgressData) => void;
  isChecking: boolean;
}
```

**Implementation:**
1. Store queue of pending unlocks (multiple can unlock at once)
2. currentUnlock = first item in queue (FIFO)
3. acknowledgeUnlock() removes current from queue, shows next
4. checkForUnlocks() compares current progress with stored, finds new unlocks
5. Uses calculateNewUnlocks from achievementManager.ts

**Tests (14+ tests):**
- Returns empty queue initially
- checkForUnlocks detects new bronze unlock
- checkForUnlocks detects tier upgrade (silver -> gold)
- Queues multiple unlocks in order earned
- acknowledgeUnlock removes current, advances queue
- currentUnlock is null when queue empty
- Handles disabled state (enabled: false)
- Does not re-trigger for already acknowledged unlocks
- Persists unlock state to prevent re-showing on refresh
