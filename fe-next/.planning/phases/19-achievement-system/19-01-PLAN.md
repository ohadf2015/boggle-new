  <action>
Create achievement database schema with:

1. **achievement_definitions table** (reference table, seeded with achievement data):
   - id: UUID primary key
   - key: VARCHAR(50) unique (e.g., "word_master", "streak_champion")
   - category: VARCHAR(20) (progress, skill, consistency, exploration)
   - base_name_key: VARCHAR(100) (translation key for name)
   - base_description_key: VARCHAR(100) (translation key for description)
   - icon: VARCHAR(10) (emoji)
   - is_secret: BOOLEAN DEFAULT false (5-10% secret badges)
   - created_at: TIMESTAMPTZ

2. **achievement_tiers table** (thresholds per badge):
   - id: UUID primary key
   - achievement_id: UUID FK to achievement_definitions
   - tier: VARCHAR(10) (bronze, silver, gold, platinum)
   - threshold: INTEGER (e.g., 50, 150, 500, 1000 for word_master)
   - tier_order: INTEGER (1-4 for sorting)
   - UNIQUE(achievement_id, tier)

3. **student_achievements table** (earned badges):
   - id: UUID primary key
   - student_id: UUID FK to users
   - achievement_id: UUID FK to achievement_definitions
   - current_tier: VARCHAR(10) (bronze, silver, gold, platinum)
   - progress_value: INTEGER (current progress toward next tier)
   - is_pinned: BOOLEAN DEFAULT false (max 3 pinned)
   - unlocked_at: TIMESTAMPTZ
   - last_tier_unlock: TIMESTAMPTZ
   - UNIQUE(student_id, achievement_id)

4. **Seed 18 achievement definitions** (within 15-20 per CONTEXT.md):

   - xp_collector: "XP Collector" (thresholds: 500/2000/10000/50000 XP)
   - practice_veteran: "Practice Veteran" (thresholds: 10/50/200/500 sessions)

   Skill-Based (4):
   - speed_demon: "Speed Demon" (10/25/50/100 words in single game)
   - perfect_streak: "Perfect Streak" (5/10/25/50 perfect accuracy games)
   - boss_slayer: "Boss Slayer" (1/5/15/30 bosses defeated)
   - combo_master: "Combo Master" (5/15/50/100 combos achieved)

   Consistency (5):
   - streak_starter: "Streak Starter" (3/7/14/30 day streaks)
   - early_bird: "Early Bird" (5/15/30/60 morning practices before 9am)
   - dedicated_learner: "Dedicated Learner" (5/10/20/30 days in a month)
