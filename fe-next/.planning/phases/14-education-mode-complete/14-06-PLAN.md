<task type="checkpoint:human-verify" gate="blocking">
  <what-built>
Complete education mode with:
1. Education landing page at /education with Teacher/Student role selection
2. Student join classroom flow at /student/join
3. Teacher lesson assignment dialog
4. Enhanced student dashboard showing assigned lessons
5. Teacher student list view per classroom
  </what-built>
  <how-to-verify>
**Step 1: Education Landing Page**
1. Navigate to http://localhost:3000/en/education
2. Verify you see two cards: "I'm a Teacher" and "I'm a Student"
3. If NOT signed in: Teacher card should show locked state with "Sign in required"
4. Click the locked Teacher card - auth modal should appear
5. Student card should be accessible (not locked)

**Step 2: Student Join Flow**
1. Sign in as a regular user (not admin/teacher)
2. Navigate to http://localhost:3000/en/student/join
3. Verify join code input appears with paste button
4. Try entering an invalid code (e.g., "XXXXXX") - should show error toast
5. If you have a valid classroom code, enter it - should redirect to /student

**Step 3: Teacher Lesson Assignment**
1. Sign in as a teacher/admin user
2. Navigate to http://localhost:3000/en/teacher
3. Go to "Lessons" tab
4. Find a lesson and click "Assign" button
5. Verify assignment dialog opens with classroom list
6. Select a classroom and click "Assign Lesson"
7. Verify success toast appears

**Step 4: Student Assigned Lessons**
1. Sign in as a student who is in a classroom with assigned lessons
2. Navigate to http://localhost:3000/en/student
3. Verify you see assigned lessons (even if not started)
4. New/unstarted lessons should show "NEW" badge and "Start Lesson" button
5. Started lessons should show progress bar and "Continue" button

**Step 5: Teacher Student List**
1. Sign in as teacher
2. Navigate to http://localhost:3000/en/teacher
3. Go to "Classrooms" tab
4. Click on a classroom's student count or expand button
5. Verify student list appears with names, emails, join dates
6. Empty classroom should show "No students yet" message

**Step 6: RTL Verification (Hebrew)**
1. Switch language to Hebrew (he)
2. Verify /he/education page layout is RTL-correct
3. Verify /he/student/join has paste button on correct side
4. Verify student dashboard and teacher dashboard are RTL-correct

**Expected Result:**
All 6 steps complete successfully with no visual bugs or errors.
