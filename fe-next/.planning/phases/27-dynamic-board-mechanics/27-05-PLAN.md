    **CRITICAL TIMING: Explosion fires at cascade REMOVING phase START**
    - Explosion triggers BEFORE Framer Motion exit animation begins
    - This creates visual sequence: explosion flash -> tiles scale down -> tiles fade out
    - Use onPhaseChange callback from useCascadeLoop to trigger explosion

    1. Import ExplosionEffect component
    2. Track pending explosions in state: `pendingExplosions: Array<{id, position, intensity}>`
    3. Subscribe to cascade.onPhaseChange callback
    4. On REMOVING phase start (when phase changes TO 'removing'):
       a. Calculate center position of cleared tiles
       b. Calculate intensity from word length (3-4=1, 5-6=2, 7-9=3, 10+=4)
       c. Add explosion to pendingExplosions (only for 3+ tile words)
    5. Render ExplosionEffect for each pending explosion
    6. Remove from pending when onComplete fires

    Key implementation:
    ```typescript
    const [pendingExplosions, setPendingExplosions] = useState<ExplosionData[]>([]);

    // Subscribe to phase changes
    useEffect(() => {
      const unsubscribe = cascade.onPhaseChange((phase, context) => {
        if (phase === 'removing' && context.removedTiles.length >= 3) {
          const center = calculateCenter(context.tilePositions);
          const intensity = getIntensityFromLength(context.removedTiles.length);
          setPendingExplosions(prev => [
            ...prev,
            { id: `exp-${Date.now()}`, position: center, intensity }
          ]);
        }
      });
      return unsubscribe;
    }, [cascade]);

    // In render
    {pendingExplosions.map(exp => (
      <ExplosionEffect
        key={exp.id}
        position={exp.position}
        intensity={exp.intensity}
        onComplete={() => removeExplosion(exp.id)}
      />
    ))}
    ```

    Position calculation: Use getBoundingClientRect on tile elements or grid math.
