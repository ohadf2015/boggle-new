  <behavior>
    Three special tile mechanics to implement:

    1. FROZEN TILES (ice type with isFrozen=true)
       - Start frozen (unusable in words)
       - Thaw when adjacent tile is used in a valid word
       - Set activationEffect='melt' when thawing
       - After thaw, tile becomes usable (isFrozen=false)
       - **CASCADE BEHAVIOR: Frozen tiles SKIP gravity (stay in place)**

    2. LOCKED TILES (new: type='locked')
       - Cannot be used until unlocked
       - Unlock when a word containing the SAME letter is formed nearby
       - Set activationEffect='unlock' when unlocking
       - After unlock, becomes standard tile
       - **CASCADE BEHAVIOR: Locked tiles BLOCK spawning in their position**

    3. MULTIPLIER TILES (new: type='multiplier')
       - When used in a word, multiply that word's score by 2x
       - Can stack with gold tiles (gold 3x + multiplier 2x = 6x)
       - Set activationEffect='multiply' when activated
       - Single use: becomes standard after activation

    Pure Functions (exported for testing):
    ```typescript
    checkFrozenThaw(
      frozenTile: TileState,
      adjacentIndices: number[],
      wordTileIndices: number[]
    ): boolean

    checkLockedUnlock(
      lockedTile: TileState,
      gridTiles: TileState[][],
      wordTileIndices: number[]
    ): boolean

    applyMultiplier(
      wordScore: number,
      wordTiles: TileState[]
    ): { finalScore: number; multiplierUsed: boolean }

    getAdjacentIndices(
      tileIndex: number,
      gridSize: number
    ): number[]
    ```

    Hook API:
    ```typescript
    const {
      processWordSubmission,  // Main function: handles all tile activations for a word
      activatedTiles,         // Set<number> of tiles that activated this turn
      multiplierBonus,        // Total multiplier from multiplier tiles
    } = useSpecialTileActivation();
    ```

    Test Cases:
    - Frozen tile thaws when adjacent tile used in word
    - Frozen tile does NOT thaw when no adjacent tile in word
    - Frozen tile skips gravity (stays in place during cascade)
    - Locked tile unlocks when word contains same letter
    - Locked tile does NOT unlock for different letters
    - Locked tile blocks new tile spawning in its position
    - Multiplier tile applies 2x to word score
    - Multiple multiplier tiles stack (2x * 2x = 4x)
    - Multiplier + gold stacks correctly (3x * 2x = 6x)
    - activationEffect is set correctly for each type
    - Activated tiles marked in activatedTiles set
  </behavior>
