## Gap Being Closed

**Verification Finding (2026-01-30):**
> POWER-01 failed: "Handler receives new time but doesn't update timer state - effect is not wired"
> - `handleFreezeTime` calculates `cappedTime` but never applies it to `timeRemaining`
> - `useAdventureGame` hook does not expose `addTime` method for power-ups

The Freeze Time power-up is **75% complete** - UI, state machine, cooldown, and visual effects all work, but the actual timer extension is broken because there's no way to modify `timeRemaining` from outside the hook.

## Root Cause

1. `useAdventureGame` hook manages `timeRemaining` via reducer, but exposes no mutation method
2. `handleFreezeTime` in AdventureGame.tsx receives the calculated new time but has no way to update state
3. Integration test is a stub with comments only - no assertions verify the actual effect

```typescript
describe('Freeze Time - Full Integration', () => {
  it('should extend timer by 10 seconds when Freeze Time is activated', async () => {
    // This test uses minimal mocking to verify actual integration
    jest.useFakeTimers();
    const user = userEvent.setup({ delay: null });

    render(
      <AdventureGame
        levelConfig={{ ...mockLevelConfig, timerSeconds: 60 }}
        initialGrid={mockInitialGrid}
        onLevelComplete={jest.fn()}
        onExit={jest.fn()}
      />
    );

    // Fast-forward through entry sequence
    act(() => {
      jest.advanceTimersByTime(5000);
    });

    await waitFor(() => {
      expect(screen.getByTestId('freeze-time-button')).toBeInTheDocument();
    });

    // Get initial time from timer display
    const getTimerValue = () => {
      const timerElement = screen.getByTestId('adventure-timer');
      return parseInt(timerElement.textContent || '0', 10);
    };

    // Record initial time
    const initialTime = getTimerValue();

    // Activate Freeze Time
    const freezeButton = screen.getByTestId('freeze-time-button');
    await user.click(freezeButton);

    // Verify timer increased (or stayed at max if already full)
    const newTime = getTimerValue();
    expect(newTime).toBeGreaterThanOrEqual(initialTime);
    expect(newTime).toBeLessThanOrEqual(60); // Capped at max

    jest.useRealTimers();
  });
});
```
