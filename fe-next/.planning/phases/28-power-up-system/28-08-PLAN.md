## Gap Being Closed

**Verification Finding (2026-01-30):**
> POWER-06 failed: "usePowerUpInventory hook exists but is never called in AdventureGame"
> - Hook is 100% implemented with localStorage persistence and 10 passing tests
> - But it's completely orphaned - never imported or called anywhere
> - PowerUpBar uses `usePowerUpState` (ephemeral) instead of `usePowerUpInventory` (persistent)

The inventory hook is **fully implemented and tested** but disconnected from the component tree.

## Root Cause

1. `usePowerUpInventory` was implemented but never wired into `AdventureGame` or `PowerUpBar`
2. `PowerUpBar` currently creates fresh `usePowerUpState` instances on every mount
3. No mechanism exists to reset cooldowns on level transitions
4. No integration test verifies persistence behavior

```
[x] Cooldown state is restored when AdventureGame remounts (level change)

```

```typescript
interface UsePowerUpStateOptions {
  /** Initial cooldown timestamp for persistence restoration */
  initialCooldownTimestamp?: number;
}

export function usePowerUpState(
  type: PowerUpType,
  options: UsePowerUpStateOptions = {}
): UsePowerUpStateReturn {
  const { initialCooldownTimestamp = 0 } = options;

  // Calculate initial state based on timestamp
  const getInitialState = (): PowerUpState => {
    if (initialCooldownTimestamp === 0) {
      return 'ready';
    }

    const elapsed = (Date.now() - initialCooldownTimestamp) / 1000;
    const remaining = Math.max(0, COOLDOWN_DURATION - elapsed);

    return remaining > 0 ? 'cooldown' : 'ready';
  };

  const getInitialCooldown = (): number => {
    if (initialCooldownTimestamp === 0) {
      return 0;
    }

    const elapsed = (Date.now() - initialCooldownTimestamp) / 1000;
    return Math.max(0, COOLDOWN_DURATION - elapsed);
  };

  const [state, setState] = useState<PowerUpState>(getInitialState);
  const [remainingCooldown, setRemainingCooldown] = useState(getInitialCooldown);
  // ... rest of hook
}
```
