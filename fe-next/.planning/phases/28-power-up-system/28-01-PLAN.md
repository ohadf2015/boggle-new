<feature>
  <name>Power-Up Cooldown State Machine</name>
  <files>types/adventure.ts, hooks/usePowerUpState.ts, hooks/__tests__/usePowerUpState.test.ts</files>
  <behavior>
    State machine lifecycle:
    - ready -> activate() -> active (effect duration runs)
    - active -> (after effect duration) -> cooldown (60s countdown)
    - cooldown -> (after 60s) -> ready

    Timestamp-based cooldown (avoid setInterval drift):
    - Store activatedAt timestamp
    - Calculate remainingCooldown from Date.now() - activatedAt
    - UI updates via requestAnimationFrame or 100ms interval for display only

    Test cases:
    - usePowerUpState('freezeTime') -> returns { powerUp, activate, isReady: true }
    - activate() when ready -> state becomes 'active', activatedAt set
    - activate() when cooldown -> returns false, state unchanged
    - After effect duration -> state becomes 'cooldown', remainingCooldown = 60
    - After 60s cooldown -> state becomes 'ready'
    - Reduced motion users still get state changes (visual feedback only differs)
  </behavior>
  <implementation>
    1. Add types to adventure.ts:
       - PowerUpType = 'freezeTime' | 'hint' | 'scoreMultiplier'
       - PowerUpState = 'ready' | 'active' | 'cooldown'
       - PowerUp interface with type, state, remainingCooldown, totalCooldown, activatedAt, effectDuration
       - POWER_UP_CONFIG constant with effect durations (freezeTime: 0, hint: 0, scoreMultiplier: 30)

    2. Create usePowerUpState.ts:
       - Accept PowerUpType parameter
       - Return { powerUp: PowerUp, activate: () => boolean, isReady: boolean }
       - Use useRef for activatedAt timestamp (not state, avoids re-renders)
       - Use useEffect with 100ms interval for UI cooldown display updates
       - Calculate remainingCooldown from timestamp: Math.max(0, totalCooldown - elapsedSeconds)
       - activate() checks state === 'ready', sets activatedAt, transitions to 'active'
       - Instant power-ups (freeze, hint): immediate transition to cooldown
       - Duration power-ups (multiplier): setTimeout for effect duration, then cooldown
  </implementation>
</feature>
