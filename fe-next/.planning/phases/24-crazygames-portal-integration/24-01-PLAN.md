<task type="auto">
  <name>Task 1: Create lazy audio loading utilities</name>
  <files>lib/audio/audioLoader.ts</files>
  <action>
Create a new utility file for lazy audio loading with Howler.js:

1. Export `createLazyHowl(src: string, options?: Partial<HowlOptions>): Howl` function:
   - Always set `preload: false` to prevent automatic loading
   - Always set `html5: true` to enable streaming (reduces memory footprint)
   - Accept optional overrides for volume, loop, etc.
   - Return the configured Howl instance

2. Export `preloadAudioOnDemand(howl: Howl): Promise<void>` function:
   - Calls `howl.load()` if not already loaded
   - Returns promise that resolves when 'load' event fires or rejects on 'loaderror'
   - Safe to call multiple times (no-op if already loaded)

3. Export `AUDIO_LOAD_PRIORITY` enum:
   - `CRITICAL` - Core game sounds (word accepted, invalid)
   - `HIGH` - Common gameplay (combo, timer warning)
   - `NORMAL` - Background music
   - `LOW` - Rare sounds (achievements, earthquake)

4. Export `preloadByPriority(sounds: Map<string, Howl>, priority: AUDIO_LOAD_PRIORITY): Promise<void>`:
   - Loads sounds matching the priority level
   - Used for progressive loading during idle time

Type-safe: Full TypeScript with proper Howl type imports from 'howler'.
  </action>
