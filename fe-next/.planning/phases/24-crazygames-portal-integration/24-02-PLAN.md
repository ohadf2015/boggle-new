Add CSS rules to ensure visual consistency in iframe embedding:

1. Add CSS isolation for .crazygames-embed class (already applied by CrazyGamesProvider):
```css
/* CrazyGames iframe embedding styles */
.crazygames-embed {
  /* Prevent any parent frame styles from bleeding in */
  all: initial;
  /* Re-apply our base styles */
  font-family: var(--font-neo-body), system-ui, sans-serif;
  color: var(--neo-white);
  background: var(--neo-navy);

  /* Force our viewport to fill iframe exactly */
  width: 100%;
  height: 100%;
  min-height: 100vh;
  min-height: 100dvh; /* Dynamic viewport height for mobile */

  /* Prevent scrollbars at page level */
  overflow: hidden;

  /* Ensure box-sizing is correct */
  box-sizing: border-box;
}

.crazygames-embed *,
.crazygames-embed *::before,
.crazygames-embed *::after {
  box-sizing: inherit;
}
```

2. Fix any 100vh issues (common iframe problem):
   - 100vh in iframe = parent viewport height (wrong)
   - Use 100% height with explicit container sizing
   - Add fallback: `min-height: 100vh; min-height: 100dvh;`
