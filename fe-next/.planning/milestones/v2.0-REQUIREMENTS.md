## v2.0 Requirements

Requirements for Adventure Overhaul milestone. Each maps to roadmap phases.

### Meta-Progression Foundation

- [x] **META-01**: User earns XP from adventure level completion
- [x] **META-02**: User sees XP progress bar toward next level
- [x] **META-03**: User levels up based on XP accumulation
- [x] **META-04**: User earns gold currency from level completion
- [x] **META-05**: User can spend gold on permanent stat upgrades (+10% time, +5% score)
- [x] **META-06**: User sees persistent player level across all worlds

### Game Juice & Visual Feedback

- [x] **JUICE-01**: User sees screen shake (0.1-0.3s, 2-8px intensity) on combo completion
- [x] **JUICE-02**: User sees particle effects with adaptive budget (50-100 particles max)
- [x] **JUICE-03**: User sees combo scaling animations (Nice! → Great! → Amazing! → LEGENDARY!)
- [x] **JUICE-04**: User sees score popup animations with arc trajectory to counter
- [x] **JUICE-05**: Animations respect reduced-motion preference (accessibility)

### UI Framework

- [x] **UI-01**: User sees HUD with clear visual hierarchy (timer, score, objectives)
- [x] **UI-02**: User sees determinate progress bars for objectives
- [x] **UI-03**: User sees floating score animations during gameplay
- [x] **UI-04**: User sees clear focus on board during gameplay (streamlined interface)
- [x] **UI-05**: User sees cooldown visualization (radial progress) for power-ups

### Dynamic Board Mechanics

- [x] **BOARD-01**: User sees tiles cascade (Candy Crush pattern: collapse → fall → refill, 0.25s per step)
- [x] **BOARD-02**: User sees smooth tile movement (quadratic/elastic easing)
- [x] **BOARD-03**: User sees explosion effects for multi-tile clearing
- [x] **BOARD-04**: User sees special tile types (frozen, locked, multiplier)
- [x] **BOARD-05**: Cascades trigger automatically when words removed
- [x] **BOARD-06**: Board transformations animate at 60fps on mobile (iPhone 12 baseline)

### Power-Up System

- [x] **POWER-01**: User can activate "Freeze Time" power-up (extends timer by 10s)
- [x] **POWER-02**: User can activate "Hint" power-up (reveals valid word on board)
- [x] **POWER-03**: User can activate "Score Multiplier" power-up (2x score for 30s)
- [x] **POWER-04**: User sees power-up cooldown timers (60s between uses)
- [x] **POWER-05**: User sees activation animations (0.25s burst effect)
- [x] **POWER-06**: Power-ups inventory persists across levels
- [x] **POWER-07**: Every level is beatable without power-ups (skill-based balance)

### Adaptive Difficulty

- [x] **DIFF-02**: System selects pre-game difficulty based on performance (3-state: easy/normal/hard)
- [x] **DIFF-03**: System provides gradual unlock hints after 3 failures
- [x] **DIFF-04**: Difficulty adjustments are invisible to user (no rubber-banding perception)
- [x] **DIFF-05**: Boss fights have fixed difficulty (learnable patterns)

**Note:** DIFF-01 (explicit difficulty selection) removed per CONTEXT.md - system is invisible, no player selection.

### Boss Battle Overhaul

- [x] **BOSS-01**: User battles bosses with 5-phase state machine (intro → phase1 → phase2 → enraged → victory/defeat)
- [x] **BOSS-02**: User sees segmented HP bar with phase indicators
- [x] **BOSS-03**: User sees telegraphed boss attacks (2s visual warning before activation)
- [x] **BOSS-04**: User sees 5-10s cinematic intro (skippable after 2s)
- [x] **BOSS-05**: Bosses have 2-3 unique abilities per boss
- [x] **BOSS-06**: Boss abilities registered in extensible ability system
- [x] **BOSS-07**: Boss entrance and defeat have cinematic sequences
- [x] **BOSS-08**: User sees unique graphics per boss (Image MCP + rembg pipeline)

### Skill Tree & Progression Depth

- [x] **SKILL-01**: User can unlock skills in branching tree (3 paths: Power, Strategy, Utility)
- [x] **SKILL-02**: User earns skill points on level up
- [x] **SKILL-03**: User sees skill tree visualization with locked/unlocked states
- [x] **SKILL-04**: Skills provide horizontal progression (enable strategies, not just +10% stats)
- [x] **SKILL-05**: User unlocks power-up slots via skill tree
- [x] **SKILL-06**: User unlocks advanced power-ups via skill progression
