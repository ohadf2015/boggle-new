# Word Vault Round-2 Critique Synthesis (2026-05-03)

Source: 4 external LLM critiques of `word-vault-2026-05-03-external-critique-brief-round2.md` (A/B/C/D below).

---

## Headline

Critics agree more than round 1. Three things land 4/4 — **brass-key over-spoils**, **1.1 is still the weakest**, **Word Vault lost the "Word"** (spelling gone from climax). One emergent issue 3/4 critics independently spotted: cross-room teaching is now **inconsistent** — broom teaches inference (subtle), brass-key teaches answer-reveal (loud). Two patterns contradict; will haunt Book 2.

## Emergent insight (NEW — none said in round 1)

**Cross-room teaching is incoherent.** Broom (1.2→1.3): subtle inference, no announcement, hidden payoff. Brass-key (1.3→1.4): loud answer-reveal whisper. The game now teaches **two contradictory patterns** for "what does an item from the previous room do here":
- Broom says: "your tools quietly help; observe the difference"
- Brass-key says: "your tools tell you the answer"

A player can't form a stable mental model. Book 2 design has to pick one or unify them.

Scope D + address the emergent inconsistent-teaching issue + revisit content delta.
- All of Scope D
- Cross-room consistency: pick ONE pattern. Recommendation = brass-key becomes a SUBTLE perk (auto-snaps the "fire" valve to correct position when key is in inventory) instead of an answer-whisper. Both items now teach "tools quietly help, observe the difference." [1-2 hr]
- M3: Revisit content delta — one altered line per solved room when revisiting (e.g., 1.4 stove gives a new whisper "כבר אכלנו פה" / "we already ate here" if revisited after 1.5; 1.3 carvings show the answers but the wipe gesture is now contemplative not puzzling) [2-3 hr]

**What you get:** No issues left from round 2. Cross-room teaching consistent. Revisit has emotional weight. Ready for Book 2.
