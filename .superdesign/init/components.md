# Shared UI Components — LexiClash

## Button (`components/ui/button.tsx`)
- Variants: default, success, destructive
- Sizes: sm, default, lg
- Neo-brutalist styling with hard shadows and borders

## Avatar (`components/Avatar.tsx`)
- Displays custom avatar or fallback letter
- Sizes: sm, md, lg, xl
- Rounded with border and optional ring

## Checkbox (`components/ui/checkbox.tsx`)
- Radix UI based
- Neo-styled with borders

## Alert / AlertDialog (`components/ui/alert-dialog.tsx`)
- Radix-based dialogs
- Neo-brutalist card styling

## QRCodeSVG (from `qrcode.react`)
- Used in InviteCard for room sharing

## Icons: Lucide React
- Swords, Crown, Bot, Plus, Minus, LogOut, Pencil, Check, X, Share2, Copy, Monitor, etc.
